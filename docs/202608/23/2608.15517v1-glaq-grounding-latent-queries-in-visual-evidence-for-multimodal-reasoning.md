## 摘要
思维链推理已显著提升了多模态大语言模型的问题解决能力。然而，细粒度的视觉证据在基于文本的推理步骤中仍难以保留和复用。为解决这一局限，带图像的增强工具思维方法通过重新查看或操作图像来外部维持视觉访问，但需要预定义工具和额外的推理时处理。作为一种内部替代方案，连续视觉潜在推理在隐藏状态中保留中间计算。然而，其主流的自回归构建使得每个潜在状态依赖于其前驱，因此后续状态可能重复潜在序列中已存在的信息，而非捕获互补的视觉细节。我们提出GLaQ，一种锚定潜在查询框架，用一组固定数量的、基于上下文条件且锚定于原始视觉标记的查询替换顺序潜在展开。这些锚定查询被重新注入用于答案生成，从而提供对源视觉证据的直接且协调的访问。我们通过局部视图监督训练GLaQ，随后在任务级奖励下进行强化学习。在五个细粒度视觉理解和感知基准上，GLaQ-7B相对于其基础模型提升了5.99–9.66%，并领先所有对比的视觉潜在方法，表明直接的查询到图像锚定可以在无需外部视觉操作或自回归潜在展开的情况下从完整图像中恢复局部证据。

## Abstract
Chain-of-thought reasoning has substantially improved the problem-solving capabilities of multimodal large language models. Fine-grained visual evidence, however, remains difficult to preserve and reuse across text-based reasoning steps. To address this limitation, tool-augmented thinking-with-images methods maintain visual access externally by revisiting or manipulating the image, but require predefined tools and additional inference-time processing. As an internal alternative, continuous visual latent reasoning retains intermediate computation in hidden states. However, its prevailing autoregressive construction makes each latent state depend on its predecessors, so later states may repeat information already present in the latent sequence rather than capture complementary visual details. We introduce GLaQ, a grounded latent-query framework that replaces sequential latent rollout with a fixed set of context-conditioned queries grounded in the original visual tokens. The grounded queries are reinjected for answer generation, providing direct and coordinated access to source visual evidence. We train GLaQ with localized-view supervision followed by reinforcement learning under task-level rewards. Across five benchmarks for fine-grained visual understanding and perception, GLaQ-7B gains 5.99--9.66\% over its base model and leads all compared visual latent methods, suggesting that direct query-to-image grounding can recover localized evidence from the full image without external visual operations or autoregressive latent rollouts.

## 1. 论文的核心问题与整体含义

- **研究动机**：多模态大语言模型（MLLM）依赖思维链（Chain-of-Thought）推理来提升复杂视觉推理能力，但标准 CoT 将中间决策“言语化”为文本 rationale，形成信息瓶颈——细粒度视觉属性、空间关系等证据在文本化过程中容易被压缩或丢失，难以在后续推理步骤中保留和复用。
- **既有方案的局限**：
  - **Thinking-with-images**（如 ZoomEye、Thyme、DeepEyes）：通过裁剪、缩放、标注等外部图像操作来重新获取视觉证据，但需要预定义工具和额外推理时处理。
  - **连续视觉潜在推理**（如 LVR、HyLaR、Monet）：将中间计算保留在隐藏状态中，避免了文本化损失；但现有方法普遍采用**自回归式潜在序列构建**，每个潜在状态依赖前驱，导致后续状态趋向重复已有信息，而非补充互补视觉细节——作者用相似度热力图（图 1）证明这一“信息增益坍缩”问题。
- **核心问题**：能否在保持潜在推理紧凑性的同时，让每个潜在状态**直接、独立地锚定于原始视觉标记**，并以并行、协调的方式工作，从而避免自回归依赖链带来的信息冗余？
- **论文整体含义**：提出 GLaQ（Grounded Latent Queries），用一组固定数量的、由当前上下文条件化的查询（queries）直接对原始视觉 token 进行接地（grounding），再将接地后的查询重新注入生成过程。这提供了一种无需外部工具、无需自回归潜在展开的内部视觉证据访问新范式。

## 2. 论文提出的方法论

### 核心思想
- 放弃“逐 token 生成潜在序列”的做法，改为在解码流中一次性实例化一个 **K 槽查询块**。
- 遵循 **contextualize–ground–reinject**（上下文化—接地—重新注入）的两遍前向过程：
  1. **第一遍**：MLLM 在收到 `<latent_start>` 后插入 K 个可学习查询槽 Q，利用当前图像-文本前缀对它们进行上下文化，得到 U_Q。
  2. **接地**：轻量模块 LQFormer（Latent Query Former）以 U_Q 为 query、原始视觉 token V 为 key/value，通过交叉注意力+自注意力+FFN 得到接地后的查询 Z_Q。
  3. **第二遍**：将 Z_Q 替换回原查询槽位置，作为软视觉提示（soft visual prompt）继续自回归文本生成。
- 图中热力图显示：GLaQ 的接地查询对之间的相似度呈现异构结构，更接近原始辅助图像 token，而不像自回归潜在状态那样形成高相似度块，说明其能保持互补的视觉信息。

### 关键技术细节
- **LQFormer 结构**：堆叠 L=2 层 Q-Former 风格模块；每层依次为：
  - Cross-Attention：从视觉 token 检索证据；
  - Self-Attention：查询槽间交换互补信息；
  - FFN：精化接地状态。
  - 输出经 RMSNorm，保持轻量，不修改视觉编码器或 MLLM 解码器。
- **固定 K 槽**：默认 K=16，一次前向完成上下文化，避免 K 次自回归步骤，并保持槽身份稳定以便对齐。

### 训练方法：两阶段监督 + 强化学习
1. **监督微调（SFT）**：
   - **局部视图自蒸馏（Latent Query Self-Distillation）**：学生 LQFormer 锚定全图，EMA 教师 LQFormer 锚定 ROI（region-of-interest）局部视图；两者接收相同的上下文化查询 U_Q，从而槽位一一对应，用余弦距离损失（公式 6）对齐，将局部证据迁移到全图推理路径。
   - **联合文本-潜变量监督**：总损失为 L = λ_latent·L_latent + L_ntp，λ_latent=0.3。L_ntp 为标准的下一 token 预测，但排除连续查询槽内部，只监督文本和边界标记。
   - 分两阶段：Stage 1 使用 80K Visual-CoT 样本（短答案）；Stage 2 使用 30K Zebra-CoT 轨迹（交错推理视图），让模型学会在文本推理步骤间插入接地查询块。
2. **强化学习（RL）**：
   - 采用 **DePO（Decoupled Policy Optimization）**（HyLaR 提出的方法），将接地后的查询 Z_Q 视为连续动作，文本 token 视为类别动作，联合优化。
   - 对文本位置用类别似然比，对潜位置用 von Mises–Fisher 密度比和缩放余弦 KL 项，分别设置 clipping 范围。
   - 奖励为加权 R = (1−λ_fmt)R_acc + λ_fmt·R_fmt，λ_fmt=0.1，检查答案正确性和 `\boxed{}` 格式，未加额外潜在推理奖励。
   - RL 数据集：10K 条来自 DeepEyes 和 Thyme，剔除主观/开放题和无明确可提取答案的样本。

## 6. 论文的主要结论与发现

1. **直接查询-图像接地有效**：用固定上下文条件查询替代自回归潜在展开，可在无需外部工具或额外图像操作的情况下，从全图恢复局部证据。
2. **监督与 RL 互补**：SFT 中局部视图自蒸馏建立“该检索什么”的先验；DePO 进一步优化“如何利用检索结果”的连续动作，二者结合带来最大收益。
3. **信息冗余问题的缓解**：GLaQ 的查询块呈现异构相似度结构，表明查询槽间保持互补而非重复，验证了设计的核心动机。
4. **效率与精度同步提升**：相比 DeepEyes 和 HyLaR，GLaQ 在 V* 上准确率更高且吞吐量更大；固定查询块保证了接地开销有界，优于可变长度潜在展开。
5. **局限性确认**：跨实例推理（HRBench 跨实例问题）仍是难点，分辨率提升时收益增长受限。

## 7. 优点

- **方法创新性强**：将“视觉潜在推理”从自回归序列范式重构为“并行、接地、上下文条件化的查询块”，概念清晰，有理论动机（相似度分析）支持。
- **轻量且优雅**：LQFormer 仅 2 层，不修改视觉编码器或 LLM 解码器，作为软提示注入，易于适配现有 MLLM。
- **训练策略完整**：结合自蒸馏（EMA 教师 + ROI 视图）与 DePO 强化学习，既提供局部监督又允许任务级优化，训练信号层次分明。
- **消融设计扎实**：能精确剥离每个组件的贡献，特别是“无 LQFormer”对照有力地证明了连续查询状态本身不足，必须依赖源视觉 token 的重新接地。
- **实验覆盖全面**：5 个互补 benchmark 覆盖细粒度属性、高分辨率、真实世界、细微差异；基线包括专有、开源、工具增强和潜在推理四类模型。
- **效率分析直观**：吞吐量-准确率散点图直观展示了 GLaQ 在精度-效率前沿上的优势。

## 8. 不足与局限

- **骨干规模单一**：仅评估 7B 模型，未验证在更大模型（如 14B、32B）上的可扩展性或迁移性。
- **查询容量固定**：K=16 是经验选择，但表 4 显示 K=8/32 在某些任务上效果更差，说明查询槽存在覆盖-冗余权衡，缺乏自适应分配机制。
- **依赖局部视图监督**：训练需要 ROI 视图，可能限制在无此类标注或无法生成局部视图的领域中的应用；作者在结论中也承认这一点。
- **RL 奖励过于简化**：仅用答案正确性和格式（`\boxed{}`），未加入过程性奖励，可能无法充分引导复杂多跳推理中的逐步证据捕获。
- **评估基准的分布风险**：训练数据来自 Visual-CoT 和 Zebra-CoT，其中 Visual-CoT 与 V* 任务高度相关，可能高估模型在 V* 上的泛化能力；MMVP/MME 收益仍存在但相对较小。
- **未披露算力和统计信息**：缺少 GPU 数量、训练时间、方差分析等，复现成本与结果可靠性难以完全评估。
- **跨实例推理薄弱**：HRBench 8K 下跨实例问题提升仅 +3.25%，明显弱于单实例问题（+10.00%），说明多实例间证据整合仍未被充分解决。
