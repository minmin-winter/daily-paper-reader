## 摘要
视觉-语言模型（VLM）结合了图像和文本，但当两者发生冲突且其中一个变得难以读取时，尚不清楚模型如何在它们之间转移依赖。我们通过一个受控设置来研究这种模态重新分配：我们在四个可读性级别上对图像或文本进行降级，同时保持另一个清晰，并跟踪模型偏好的变化。我们通过将一道算术问题的渲染图像与另一道问题的文本配对来构建GSM8K和SVAMP中的冲突，使得两个来源支持不同的答案。我们还引入了ChartQA-Conflict，这是一个经过人工审查的基准，包含229个图表-报告冲突，并配对的图表和表格图像表示。我们使用生成的答案和长度归一化的条件对数似然边际来评估六个开放权重的VLM。在GSM8K和SVAMP上，六个模型中有五个对降级文本的转移比对降级图像的转移更强烈。在ChartQA-Conflict上，所有六个基于似然评分的模型都表现出相反的模式，对降级视觉来源的转移更强烈。在针对单模态准确性损失进行校准以及将图表替换为普通表格图像后，这种反转仍然存在。两个前沿API模型GPT-5.6-Luna和Gemini-3.5-Flash在行为上复制了ChartQA-Conflict的反转，其中GPT-5.6-Luna也匹配了算术方向。这些结果表明，VLM中的模态依赖不是固定的，而是随任务、证据结构、模型和评估设置而变化。源代码可在https://github.com/Ro-netizen004/multimodal-arbitration-artifact获取。

## Abstract
Vision-language models (VLMs) combine images and text, but when the two conflict and one becomes harder to read, it is unclear how a model shifts its reliance between them. We study this modality reallocation with a controlled setup: we degrade either the image or the text across four levels of legibility while keeping the other clean, and track how the model's preference changes. We build conflicts from GSM8K and SVAMP by pairing the rendered image of one arithmetic problem with the text of another, so the two sources support different answers. We also introduce ChartQA-Conflict, a manually reviewed benchmark of 229 chart-report conflicts with matched chart and table-image representations. We evaluate six open-weight VLMs using both generated answers and a length-normalized conditional log-likelihood margin. On GSM8K and SVAMP, five of six models shift more strongly away from degraded text than from degraded images. On ChartQA-Conflict, all six likelihood-scored models exhibit the opposite pattern, shifting more strongly away from the degraded visual source. This reversal persists after calibrating for unimodal accuracy loss and after replacing charts with plain table images. Two frontier API models, GPT-5.6-Luna and Gemini-3.5-Flash, behaviorally replicate the ChartQA-Conflict reversal, with GPT-5.6-Luna also matching the arithmetic direction. These results show that modality reliance in VLMs is not fixed, but varies across tasks, evidence structures, models, and evaluation settings. The source code is available at https://github.com/Ro-netizen004/multimodal-arbitration-artifact.

## 1. 论文的核心问题与整体含义

**研究动机与背景：** 视觉-语言模型（VLM）在推理时同时接收图像与文本两种模态的输入。以往研究大多将视觉输入与文本输入**隔离评估**，或者仅在单一冲突级别下观察模型行为，无法回答一个关键问题：**当图像与文本同时存在且互相冲突、其中一种模态又变得难以读取时，VLM 是否会重新分配它对两种模态的依赖？** 这种重新分配是否在不同任务间保持一致？

**核心含义：** 本文通过受控实验，系统性地测量了 VLM 在"图文冲突 + 单侧模态降级"条件下的偏好转移方向与幅度，发现模态依赖并非固定不变的偏好，而是**随任务类型、证据结构、模型个体与评估设置动态变化**。这一结论挑战了"VLM 普遍偏向文本"或"普遍偏向视觉"的简单二元论断，为理解多模态模型的仲裁机制提供了新视角。

## 2. 论文提出的方法论

### 2.1 核心思想：模态再分配（Modality Reallocation）
- 构建**冲突对**：同一模型中同时输入两个信息源（Source A 与 Source B），两者支持不同的答案。
- **单侧降级**：分别在图像降级臂（文本保持清晰）与文本降级臂（图像保持清晰）中，按四种可读性级别逐步恶化其中一个来源。
- **测量偏好转移**：比较模型在降级前后对两个候选答案的偏好如何变化，以量化它"离开被降级源、转向清晰源"的强度。

### 2.2 两种冲突构造设置
1. **渲染文本冲突（GSM8K / SVAMP）**：将一道算术题的文本渲染为图片，与另一道题的纯文本配对，使两者支持不同答案。
2. **自然视觉冲突（ChartQA-Conflict）**：将真实图表（支持答案 aI）与经过扰动、支持另一答案 aT 的文字报告配对，回答同一问题。

### 2.3 降级阶梯
- 统一使用四级：**L0（干净）、L2（轻度）、L4（中度）、L5（重度）**。
- **图像降级**：高斯模糊 + 像素噪声 + 对比度调整（L5 最强）。
- **文本降级**：按概率随机删除或替换非空白字符，保留空白以维持词边界可见。
- 每次降级确定性执行（固定随机种子），确保所有模型收到完全相同的降级输入。

### 2.4 偏好度量
- **行为源选择**：解析模型生成答案，归因于图像支持答案或文本支持答案。
- **条件对数似然（CLL）边际**：作为连续度量，对长度归一化的候选答案对数概率求差：

  m(c) = (1/|aT|) log p(aT|c) − (1/|aI|) log p(aI|c)

  正边际偏向文本答案，负边际偏向图像答案。

- **配对不对称性（Ai）**：对每个条目计算 Ai = RT,i − RI,i，衡量文本降级臂与图像降级臂中偏好转移强度的差异。

### 2.5 关键实验设计
- 使用**角色中立提示**，以 Source A/B 标签呈现两种模态并在条目间**对抗平衡**，避免提示框定偏向。
- CLL 评分仅覆盖 `####` 分隔符之后的答案 token，不纳入思维链推理痕迹。

## 6. 论文的主要结论与发现

1. **算术任务中文本降级引发更强偏好转移**：在 GSM8K 与 SVAMP 上，六个模型中的五个在文本降级时比图像降级时更强烈地转向清晰源（中位不对称性 A 为正且置信区间排除零）；Qwen2.5-VL-7B 是例外（GSM8K 上接近零、SVAMP 上反转为负）。
2. **图表任务上发生方向反转**：在 ChartQA-Conflict 上，**全部六个 CLL 评分模型的 A 均为负值**（区间全部低于零），即模型对图表降级的反应强于对报告降级的反应。
3. **反转在一系列"备择解释"排除后依然成立**：
   - 用单模态精度损失校准后的斜率差异 D 在 ChartQA-Conflict 上仍全部为负；
   - 将图表替换为同信息表格图像后反转仍然存在（A 仍全部为负）；
   - 前沿 API 模型（GPT-5.6-Luna 与 Gemini-3.5-Flash）在行为上复现 ChartQA-Conflict 反转，GPT-5.6-Luna 还在 GSM8K 上匹配了算术方向。
4. **提示框定只调节效应大小，不决定方向**：角色中立提示改变部分模型的效应幅度，但不消除五模型算术不对称模式。
5. **总体结论**：VLM 的模态依赖不是固定偏向，而是**任务、证据结构、模型架构与评估设置共同塑造的语境依赖行为**。

## 7. 优点

- **问题设定新颖**：首次系统提出"模态再分配"（modality reallocation）概念，并将"哪一侧降级"作为自变量。
- **受控因果设计**：逐步降级 + 单侧保持清晰 + 角色中立提示 + Source A/B 对抗平衡，设计干净、可复现。
- **双重度量互为印证**：行为选择（离散）与 CLL 边际（连续）互补，CLL 还能捕捉行为上已饱和时的潜在偏好变化。
- **同时构建两种冲突类型**：渲染文本冲突与自然图表冲突，使结果显示更强的任务依赖性，而非单一场景的偶然发现。
- **ChartQA-Conflict 人工审核**：双人独立审核 230 个条目，事后审计再剔除 1 个不合格条目。
- **稳健性分析全面**：校准单模态精度损失、替换图表为表格、变换 CLL 归一化指数、对比提示框定，逻辑闭环。
- **数据与代码开源**：冲突数据集、降级元数据、完整输出均已发布至 Hugging Face 与 GitHub。

## 8. 不足与局限

- **模型覆盖受限**：CLL 分析需要 token 级概率访问，因此仅覆盖 2B–8B 开源模型；前沿 API 模型无法进入主分析，只能提供行为证据。
- **任务结构未完全解耦**：算术冲突中视觉源是"渲染文本"，ChartQA-Conflict 中视觉源是"图表+报告"，两者在问题结构、证据可及性和冲突构建方式上同时存在差异，无法唯一归因反转的因果机制。
- **ChartQA-Conflict 存在潜在的可及性偏差**：报告中的答案相关数值以明文列出，而图表值需视觉定位与解析；审查者为作者本人且未对反事实设计设盲，缺乏独立标注。
- **降级阶梯仅名义对齐**：图像降级与文本降级同为 L0/L2/L4/L5，但绝对严重度并未做心理物理校准（虽以单模态精度损失做了事后调整，但仍为近似）。
- **外推性受限**：文本降级仅限英文字母数字字符，不涉及其他语言/文字系统；数值答案型任务设计无法直接迁移至多选题、自由生成等场景。
- **不测冲突意识**：实验机制强制模型输出单一答案，未测量模型是否能检测矛盾、表达不确定性或弃权；CLL 与行为选择一致性仅 75.4%，其作为行为依赖代理仍有不确定性。
