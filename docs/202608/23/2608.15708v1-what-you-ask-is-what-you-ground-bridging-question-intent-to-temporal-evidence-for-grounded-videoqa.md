## 摘要
我们研究了接地视频问答中一个关键但常被忽视的失败模式：问题不变的接地，即模型对同一视频的不同问题预测出几乎相同的时间片段。我们将这种表现追溯至先前常见设计中的两个结构性局限：（i）模态隔离，在视频表示接收问题语义之前就将其固定；（ii）接地模块内部的问题注入力度不足。为解决此问题，我们提出了GroundFormer，它通过可学习的通信标记在定位之前将视频特征以问题意图为条件，这些标记调解有方向的视觉-语言交互。在问题条件化的特征之上，分解的多实例学习交叉注意力将答案选择与候选级监督下的时间证据相结合，而高斯平滑将集中注意力转换为时间上连贯的片段。我们进一步引入了一种层次化的多模态对比损失，通过两遍训练流程对齐视频、问题和答案嵌入。GroundFormer在NExT-GQA和STAR上实现了最先进的接地视频问答性能，显著改善了问题判别性的时间接地。

## Abstract
We study a critical yet overlooked failure mode in Grounded Video Question Answering: question-invariant grounding, where models predict nearly identical temporal segments for different questions about the same video. We trace this behavior to two structural limitations in prior common designs: (i) modality isolation that fixes video representations before they receive question semantics, and (ii) weak question injection inside the grounding module. To address this, we propose GroundFormer, which conditions video features on question intent before localization via learnable communication tokens that mediate directed visuo-lingual interaction. On top of the question-conditioned features, a factorized MIL cross-attention couples answer selection with temporal evidence under candidate-level supervision, while Gaussian smoothing converts peaked attention into temporally coherent segments. We further introduce a hierarchical multi-modal contrastive loss that aligns video, question, and answer embeddings across a two-pass training pipeline. GroundFormer achieves state-of-the-art grounded VideoQA performance on NExT-GQA and STAR, substantially improving question-discriminative temporal grounding.

### 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：VideoQA 是评估视觉-语言模型多模态推理能力的重要基准。然而，BlindQA 实验表明，不带视频输入的模型也能达到与最先进方法相当的性能，说明模型可能依赖语言先验而非真正的视觉理解。为此，Grounded VideoQA 要求模型不仅给出正确答案，还需输出支撑答案的时间片段（temporal segment），以强制答案建立在视觉证据之上。
- **核心问题**：论文发现现有 Grounded VideoQA 方法存在一个关键且常被忽视的失败模式——**问题不变接地（question-invariant grounding）**：对于同一视频中指向不同时间事件的不同问题，模型预测出几乎相同的时间片段（如图 1 所示）。量化结果（表 1）显示，NG+ 和 CRA-GQA 的 PIoU 分别高达 85.7 和 88.9（远超真实标注的 21.3），而 GT-Pred Corr. 接近零（0.005/0.006），说明其接地结果与问题意图几乎无关。
- **原因分析**：论文将这一问题归因于两个结构性缺陷：
  1. **模态隔离（modality isolation）**：视频表示在接收到任何问题语义之前就被固定，视觉编码器独立运行，跨模态交互只在后期发生；
  2. **接地模块内问题注入不足**：问题仅作为一个 token 与 T 个视觉 token 拼接（1:T 的不平衡），随后立即被池化操作吸收，问题信号被主导的视觉流淹没。

### 2. 方法论：核心思想、关键技术细节

**核心思想**：在定位（grounding）之前，先让视觉特征以问题语义为条件，建立“问题意图 → 时间证据”的显式通路，从而打破问题不变接地的僵局。

**总体架构**（GroundFormer）以两遍流水线（two-pass pipeline）为核心：

- **第一遍（问题遍）**：将真实问题与批次内其他视频的问题配对作为候选，识别与视频最相关的问题，编码视觉对问题语义的判别力。
- **第二遍（答案遍）**：接收答案候选，产出答案预测和接地信号。
- 两遍共享权重，**推理时仅执行答案遍，无额外计算开销**。

**关键组件**：

1. **可学习通信 Token（Communication Tokens）**：
   - 包含一个 `[TYPE]` token（编码粗粒度问题类别，受辅助损失监督）和 N 个 query tokens（捕获细粒度问题语义）。
   - 通过两步不对称掩码自注意力建立视觉-语言通路：
     - **Linguistic Transfer**：通信 token 关注语言 token 以吸收候选语义（`¯z = SA₁([z; x_l], M_l)|_z`），语言 token 只关注自身，防止污染。
     - **Visual Refinement**：视频 token 关注通信 token 以接收问题语义（`˜x_v = SA₂([x_v; ¯z], M_v)|_{x_v}`），此时每个帧特征都编码了候选相关信息，模块隔离得以缓解。

2. **弱监督接地：MIL 交叉注意力**：
   - 将 Grounded VideoQA 建模为多实例学习（MIL）问题。
   - 以更新后的 query tokens 作为查询（query），问题条件化的视觉 token 作为键/值（key/value），计算交叉注意力 logits。
   - 将 logits 分解为时间分布 `˜ℓ_time`（帧上的概率）与候选分布 `˜ℓ_cand`（候选上的概率），二者逐元素乘积后按时间求和，得到 MIL 分数 `˜ℓ_mil`。
   - 这种因子化设计将候选分数与其支撑帧绑定，使时间分布直接由答案监督推导而来。

3. **高斯平滑（Gaussian Smoothing）**：MIL 注意力常集中于最具判别力的帧，导致信号尖锐、片段碎片化。使用一维高斯核卷积平滑原始接地信号（`g_gauss = G_σ * g_attn`），产出时间上连续的片段。

4. **层次化多模态对比学习**：沿 V→Q→A 路径渐进式对齐视频、问题、答案嵌入。第一遍对齐视频与问题（V→Q），第二遍对齐问题与答案（Q→A），使用批内候选作为负样本。

5. **训练目标**：
   - 答案分类损失和 MIL logits 上的交叉熵损失；
   - 层次化多模态对比损失（`L_mcl = L_vq + L_qa`）；
   - `[TYPE]` token 的问题类型分类辅助损失；
   - 总损失：`L = L_ans + L_qns + L_mcl + L_type`。

- GroundFormer 在 **NExT-GQA** 上取得 Acc@GQA 21.5，优于最佳 FrozenBiLM 基线（18.8），mIoP 34.0 vs 26.5，mIoU 17.5 vs 13.5，参数量仅为后者的 17.6%。

- **方法设计有针对性**：两大结构缺陷分别对应两个解决方案——通信 token 解决模态隔离、MIL 交叉注意力解决弱问题注入，动机与设计高度闭环。
- **训练-推理效率设计巧妙**：两遍训练带来判别性表征，但推理只执行一遍，无额外开销，实用性强。

### 8. 不足与局限

- **单间隔预测限制**：当证据在视频中重复出现于多个不相交的区间时（如鸭子反复潜水），模型只能预测一个片段，无法覆盖全部相关实例（补充材料图 12 明确承认此局限）。
- **稀疏时间采样**：T=32 帧均匀采样可能丢失细微运动线索（如减速、快速动作等），导致对细粒度时间判断（如 Q3 的减速问题）表现不佳；自认“common practice of uniform sparse sampling can discard fine-grained temporal cues”。
- **Prediction 类问题在 STAR 上表现偏弱**：IoU 指标相对较低，说明前向预测类推理在证据分散或微妙时仍具挑战性。
- **对比公平性问题**：GroundFormer 参数量（211M）介于 TempCLIP（130–145M）和 FrozenBiLM（1.2B）之间，与 FrozenBiLM 的对比虽然展示了效率优势，但两者基座差异较大，不太适合直接比较；缺少与同量级方法的更多对比。
- **可复现信息不完整**：未公布 GPU 数量和总训练时间；未提供多次运行的方差或显著性检验。
- **诊断指标过滤策略**：PIoU 剔除了真实重叠较高的问对（τ=0.5），这在避免低估塌缩方面合理，但也可能丢失一些信息。阈值选择的影响未做敏感性分析。
