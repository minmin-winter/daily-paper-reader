## 摘要
思维链推理已大幅提升多模态大语言模型的问题解决能力。然而，细粒度的视觉证据在基于文本的推理步骤中仍难以保留和复用。为应对这一局限，具工具增强的“带图像思考”方法通过重新访问或操作图像来保持外部视觉访问，但需要预定义工具并增加推理时的额外处理。作为一种内部替代方案，连续视觉潜在推理将中间计算保留在隐藏状态中。然而，其主流的自回归构造使得每个潜在状态依赖于其先前状态，因此后续状态可能重复潜在序列中已有的信息，而非捕获互补的视觉细节。我们提出GLaQ，一种锚定潜在查询框架，用一组固定的、基于原始视觉令牌的上下文条件查询替代顺序潜在展开。这些锚定查询被重新注入以生成答案，从而提供对源视觉证据的直接且协调的访问。我们使用局部视图监督训练GLaQ，随后在任务级奖励下进行强化学习。在五个用于细粒度视觉理解和感知的基准上，GLaQ-7B相比其基础模型提升了5.99–9.66%，并领先所有对比的视觉潜在方法，表明直接的查询到图像锚定可以从完整图像中恢复局部证据，而无需外部视觉操作或自回归潜在展开。

## Abstract
Chain-of-thought reasoning has substantially improved the problem-solving capabilities of multimodal large language models. Fine-grained visual evidence, however, remains difficult to preserve and reuse across text-based reasoning steps. To address this limitation, tool-augmented thinking-with-images methods maintain visual access externally by revisiting or manipulating the image, but require predefined tools and additional inference-time processing. As an internal alternative, continuous visual latent reasoning retains intermediate computation in hidden states. However, its prevailing autoregressive construction makes each latent state depend on its predecessors, so later states may repeat information already present in the latent sequence rather than capture complementary visual details. We introduce GLaQ, a grounded latent-query framework that replaces sequential latent rollout with a fixed set of context-conditioned queries grounded in the original visual tokens. The grounded queries are reinjected for answer generation, providing direct and coordinated access to source visual evidence. We train GLaQ with localized-view supervision followed by reinforcement learning under task-level rewards. Across five benchmarks for fine-grained visual understanding and perception, GLaQ-7B gains 5.99--9.66\% over its base model and leads all compared visual latent methods, suggesting that direct query-to-image grounding can recover localized evidence from the full image without external visual operations or autoregressive latent rollouts.

# GLaQ（Grounded Latent Queries）论文详细总结

## 1. 核心问题与研究动机

- **背景**：思维链（Chain-of-Thought）推理显著提升了多模态大语言模型（MLLM）的问题解决能力，但标准的"多模态思维链"将中间决策**文字化**为图像条件下的文本理由，形成信息瓶颈——细粒度视觉细节（如空间关系、微小属性差异）在压缩和转换过程中容易丢失或失真。
- **现有方案的缺陷**：
  - **Thinking-with-images（带图像思考）**：通过定位、裁剪、缩放、标注等外部视觉操作重新获取证据（如 Visual CoT、V*、ZoomEye、DeepEyes、Thyme 等），效果虽好但**需要预定义工具**和**额外推理时处理**，且受限于支持的操作集合。
  - **连续视觉潜在推理（Continuous Visual Latent Reasoning）**：将中间计算保留在隐藏状态中，无需文本转换或外部图像操作（如 LVR、HyLaR、Monet、SkiLa）。但其主流构造是**自回归式**的——每个潜在状态依赖前一个状态，导致后续状态与已有状态高度相似、信息重复（作者用 Figure 1 的相似度热力图证明：自回归潜在 token 在序列后期形成高相似度区块），无法捕获互补的细粒度视觉信息。
- **核心挑战**：如何在保留潜在推理紧凑性的同时，让每个潜在状态**直接锚定于源视觉表征**，并**在不借助自回归依赖链的情况下协调各状态**。

## 2. 方法论：GLaQ 框架

### 2.1 核心思想

GLaQ（Grounded Latent Queries）用**一组固定的上下文条件查询块（query block）**取代自回归潜在展开。其基本流程为"**上下文化—锚定—重注入**"（contextualize–ground–reinject）：

1. MLLM 解码至 `<latent_start>` 标记时，向解码流中插入 K 个可学习的查询槽（K=16）。
2. **第一遍前向**：MLLM 在当前图像-文本前缀条件下对查询块进行上下文化，得到 U_Q。
3. 轻量模块 **LQFormer** 将 U_Q 直接锚定到原始视觉 token V 上，得到锚定后的查询 Z_Q。
4. **第二遍前向**：用 Z_Q 替换原查询块，重新注入为软视觉提示（soft visual prompts），随后恢复标准自回归文本生成。

这种方式避免了 K 次自回归潜在生成步骤，保留了稳定的槽位身份用于对齐，使查询槽之间可以协调互补而非重复。

### 2.2 关键技术细节

- **Grounded Latent Query 定义**：
  - 输入图像 I 经冻结视觉编码器得到视觉 token V ∈ R^{N×d}。
  - 潜在段为 `<latent_start>, q1,...,qK, <latent_end>`，其中查询槽为可学习连续嵌入，边界标记为普通文本目标。
- **两遍前向机制**：
  - U_Q = M_θ^(1)(x, V; Q)（上下文化）
  - Z_Q = F_ϕ(U_Q, V)（LQFormer 锚定）
  - p_θ(y_t | y<t, x, V, Z_Q) = M_θ^(2)(... )（重注入后生成答案）
  - 若有多个锚定块，则在每个位置对已有前缀执行相同的两遍操作。
- **LQFormer 结构**（类 Q-Former，2 层）：
  - 交叉注意力：查询槽从视觉 token 检索图像证据
  - 自注意力：K 个槽之间交换互补证据
  - FFN + RMSNorm 精化
  - 只有查询槽与 N 个视觉 token 交互，因此只引入轻量适配器，不改动视觉编码器和 MLLM 解码器。

### 2.3 训练策略（两阶段监督 + 强化学习）

- **总体目标**：L = λ_latent · L_latent + L_ntp（λ_latent = 0.3）
- **L_latent（潜在查询自蒸馏）**：
  - 学生 LQFormer 在全图上锚定上下文化查询 U_Q；
  - EMA 教师 LQFormer 在配对的 ROI（region-of-interest）辅助视图上锚定**同一组 U_Q**；
  - 因两路径共享相同查询槽顺序，可实现槽级对齐（cosine 距离/均方误差）；
  - 目标是把局部视图暴露的证据迁移到全图推理路径，推理时移除教师和辅助视图。
- **L_ntp（文本下一词预测）**：监督周围文本和潜在边界标记（内部连续查询槽不参与词汇监督）；两阶段 SFT：Stage 1 用 80K Visual-CoT 短答案样本，Stage 2 用 30K Zebra-CoT 交错视觉搜索轨迹，教会模型何时在文本推理步之间穿插锚定查询块。
- **强化学习（DePO）**：
  - 将文字 token 视为分类动作、锚定后的查询 Z_Q 视为连续动作，联合优化；
  - 采用 von Mises–Fisher 密度比和 scaled-cosine KL 项，带独立裁剪范围；
  - 奖励 R = 0.9·R_acc + 0.1·R_fmt（正确性 + 格式）；
  - RL 数据集为从 DeepEyes 和 Thyme 过滤出的 10K 样本（去除重复、主观/开放问题及无明确答案者）。

## 6. 主要结论与发现

1. **直接的查询到图像锚定是有效的**：GLaQ 无需外部视觉工具或自回归潜在展开，仅凭内部锚定即可从全图恢复局部证据，并在 5 个基准上全面超越现有视觉潜在方法。
2. **LQFormer 不可替代**：绕过 LQFormer（仅复用第一遍查询状态）性能甚至低于 text-only SFT，证明"持续的上下文条件查询-图像交互"是增益的关键来源，而非插入连续状态本身。
3. **局部视图自蒸馏贡献核心增益**：移除 EMA 教师会消除大部分 SFT 优势，说明从 ROI 视图迁移局部化证据对引导查询锚定至关重要。
4. **DePO 与监督对齐互补**：DePO 在全部 5 个基准上优于单纯文本 GRPO（提升 0.52–1.37%），证明锚定查询是可优化的连续潜在动作，收益集中于高视觉要求场景。
5. **固定容量带来效率优势**：GLaQ 相比基座、DeepEyes、HyLaR 分别提升 V* 准确率 8.90/2.09/4.19 点，同时吞吐量提高 7.62%/20.11%/5.70%，因计算开销有界，避免了变长潜在展开的成本。
6. **非单调超参趋势**：λ_latent=0.3 和 K=16 是最稳健的操作点，过强的对齐约束或过大的查询容量反而会损害性能。

## 9. 整体评价与展望

综合来看，GLaQ 是一项"问题诊断扎实、设计动机明确、实验支撑充分"的视觉潜在推理工作。其核心贡献在于用**固定查询块的锚定-重注入机制**替代了自回归潜在展开，从根源上缓解了潜在状态的视觉信息重复问题，并在不依赖任何外部工具的前提下，以有界计算开销取得了优于工具型与潜在型两类方法的综合表现。训练层面的两大创新——ROI 视图上的 EMA 教师自蒸馏、以及将锚定查询作为连续动作纳入 DePO 强化学习——也为"如何监督不可见的潜在计算"提供了有价值的范式参考。

不过，其适用规模仅覆盖 7B、查询容量固定、依赖局部视图配对数据、缺乏可解释性分析、算力信息不透明等局限，决定了该工作更多是"验证了方向的可行性"而非"给出了最终答案"。后续研究值得探索的方向包括：将锚定机制扩展到更大骨干以检验规模效应、设计基于任务难度动态分配查询容量的机制、减少对人工 ROI 配对的依赖（如利用弱监督或自发现线索）、以及为潜在推理设计可视化的归因工具以增强可信度。
