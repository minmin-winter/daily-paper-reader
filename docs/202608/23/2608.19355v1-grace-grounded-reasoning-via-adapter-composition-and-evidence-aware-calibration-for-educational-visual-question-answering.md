## 摘要
教育视觉问答（VQA）要求模型利用语言和视觉证据来解决面向课程的多项选择题。与传统的开放式VQA相比，教育示例通常包含结构化的评估元数据、图表或图像上下文，以及语义上接近的答案选项，这为问题-选项捷径创造了强烈机会。我们在此场景中开发并评估了一种针对冻结多模态大语言模型的参数高效适配框架。我们引入了GRACE，即基于适配器组合与证据感知校准的接地推理，该框架利用每个问题的教学状态来专门化轻量级语言和视觉适配。该状态结合了推理可见的学科、分组技能、年级、视觉上下文、问题意图和选项结构线索。GRACE使用因子特定提示和轻量级视觉适配器，然后在共享多模态上下文下应用证据感知选项校准来对所有候选进行评分。在ScienceQA上，GRACE将共享适配器基线的整体准确率从90.5%提高到93.1%，并在图像上下文问题上从88.7%提高到91.2%。移除教学组合、选项校准或视觉适配器分别使整体准确率降低1.4、1.0和1.5个百分点。这些受控结果表明，结构化教育状态是参数高效多模态适配的有效路由信号。

## Abstract
Educational visual question answering, or VQA, requires models to solve curriculum-oriented multiple-choice questions using both language and visual evidence. Compared with conventional open-ended VQA, educational examples often include structured assessment metadata, diagrams or image contexts, and semantically close answer options, creating strong opportunities for question-option shortcuts. We develop and evaluate a parameter-efficient adaptation framework for a frozen multimodal large language model in this setting. We introduce GRACE, Grounded Reasoning via Adapter Composition and Evidence-Aware Calibration, a framework that uses the pedagogical state of each question to specialize lightweight language and vision adaptation. The state combines inference-visible subject, grouped skill, grade, visual-context, question-intent, and option-structure cues. GRACE uses factor-specific prompts and lightweight visual adapters, then applies evidence-aware option calibration to score all candidates under a shared multimodal context. On ScienceQA, GRACE improves a shared-adapter baseline from 90.5 percent to 93.1 percent overall accuracy and from 88.7 percent to 91.2 percent on image-context questions. Removing pedagogical composition, option calibration, or the visual adapter reduces overall accuracy by 1.4, 1.0, and 1.5 points, respectively. These controlled results show that structured educational state is an effective routing signal for parameter-efficient multimodal adaptation.

## 1. 核心问题与整体含义

**研究动机与背景：**

- 教育视觉问答（Educational VQA）与通用开放式 VQA 有本质差异：它以**课程导向的多项选择**形式呈现，模型需要结合语言与视觉证据来解答问题。
- 教育类题目通常附带**结构化评估元数据**（如学科、年级、技能类别）、图表/图像上下文，以及**语义上高度接近的干扰选项**。这种结构容易诱导模型走"捷径"，即仅依赖问题—选项之间的语言统计规律作答，而不充分参考图像证据。
- 传统方法（如完全微调）成本高昂，通用参数高效微调（PEFT）方法则忽略了教育元数据所蕴含的丰富的结构化先验信息。
- 论文的总体主张是：教育评测数据中**推理可见的教育元数据**本身就可以作为有效的**路由信号**，用于在样本级别分配有限的训练容量，从而实现更精准、更鲁棒的参数高效多模态适配。

**核心问题：** 如何利用教育数据中特有的结构化元数据，在冻结大规模多模态模型的前提下，通过轻量级适配模块实现视觉接地推理，并缓解语言捷径学习问题。

## 2. 方法论

### 2.1 总体架构

GRACE 采用 Qwen2.5-VL-7B-Instruct 作为骨干模型。**视觉 Transformer 块和语言解码器保持冻结**，仅训练以下模块：
- 视觉-语言多模态连接器（multimodal connector）
- 因子特定提示库（factor-specific prompt bank）
- 元数据门控网络（metadata gating network）
- 视觉残差适配器（visual residual adapters）
- 选项验证器（option verifier）

总可训练参数量约为 **49.3M，约占总模型参数的 0.7%**。

### 2.2 教学状态构建

给定示例 $e_i = (I_i, q_i, O_i, y_i, m_i)$，GRACE 构造教学状态：

\[
z_i = \{s_i, t_i, c_i, g_i, u_i, v_i\}
\]

其中：
- $s_i$：学科（subject）
- $t_i$：分组技能类别（grouped skill）
- $c_i$：视觉上下文（visual context）
- $g_i$：年级（grade）
- $u_i$：问题意图类别（question intent，从问题文本推导）
- $v_i$：选项结构描述符（option structure，从选项推导）

前四个来自基准元数据，后两个由推理可见的问题和选项字段计算得出。**金标答案、解题字段、讲座、解释等后验信息均不参与状态构建**。

### 2.3 教学感知的适配器组合

将提示库分解为共享组件与因子特定组件：

\[
\mathcal{P} = \{P_0, P_s, P_t, P_c, P_g, P_{qi}, P_{os}\}
\]

最终实现包含 **93 个提示组件**，每个前缀长度为 10。组合后的前缀为：

\[
P(z_i) = P_0 + \alpha_s P_s^{s_i} + \alpha_t P_t^{t_i} + \alpha_c P_c^{c_i} + \alpha_g P_g^{g_i} + \alpha_{qi} P_{qi}^{u_i} + \alpha_{os} P_{os}^{v_i}
\]

权重 $\alpha$ 由一个小型门控网络基于元数据类别嵌入和问题-选项描述符生成；缺失字段使用显式的"未知类别"嵌入。

**设计意义：** 相比为每个联合状态训练独立专家（规模约为 $\prod_f n_f$），因子分解银行规模仅为 $1 + \sum_f n_f$，更适合教育数据中大量联合组合稀疏的情况。

### 2.4 状态条件视觉适配

在视觉 Transformer 块 4 和 8 处插入两层瓶颈适配器（bottleneck dimension = 256）：

\[
\tilde{h}_i^{(\ell)} = h_i^{(\ell)} + a_i^{(\ell)} A_\ell(h_i^{(\ell)}), \quad a_i^{(\ell)} = G_\ell(z_i) \in [0,1]
\]

门控函数 $G_\ell$ 与提示组合器共享同一教学状态，使语言路径和视觉路径在对同一教育状态的描述下联合条件化。

### 2.5 证据感知选项校准（OCAV）

首先计算长度归一化的条件对数似然：

\[
\ell_{ij} = \frac{1}{|o_{ij}|} \sum_{t=1}^{|o_{ij}|} \log p_{\theta,\Theta_A}(o_{ij,t} | I_i, q_i, O_i, z_i, o_{ij,<t})
\]

然后使用轻量级验证器 $V_\eta$ 在图像、问题、教学状态的联合条件下评估候选。最终得分为：

\[
S_{ij} = \lambda \ell_{ij} + \gamma V_\eta(I_i, q_i, o_{ij}, z_i)
\]

最终配置中 $\lambda = 1, \gamma = 1$。

**列表式训练目标（OCAV 损失）：**

\[
\mathcal{L}_{ocav} = -\log \frac{\exp(S_{iy_i})}{\sum_{j=1}^{K} \exp(S_{ij})}
\]

训练总目标为：

\[
\mathcal{L} = \mathcal{L}_{ans} + \lambda_o \mathcal{L}_{ocav}, \quad \lambda_o = 1.0
\]

其中 $\mathcal{L}_{ans}$ 为正确答案的生成损失。

## 6. 主要结论与发现

1. **结构化教育状态是有效的路由信号。** GRACE 将教育元数据转化为可操作的适配路由信号，在冻结大规模模型的前提下显著提升了多模态推理能力。
2. **大幅超越受控基线：** GRACE 相比冻结骨干提升 5.6 点（Overall，87.5%→93.1%），相比共享适配器提升 2.6 点（90.5%→93.1%），相比 LoRA 提升 3.1 点。
3. **图像上下文问题提升显著：** IMG 准确率从 88.7% 提升至 91.2%（+2.5 点 vs 共享适配器；+6.3 点 vs 冻结骨干）。
4. **三个组件均有独立贡献：**
   - 移除视觉适配器：Overall 下降 **1.5** 点（最大降幅）
   - 移除教学组合：Overall 下降 **1.4** 点
   - 移除选项校准：Overall 下降 **1.0** 点
5. **更强的视觉依赖：** GRACE 的全图—空白图准确率差距（12.8 点）显著大于共享适配器（7.8 点），说明 GRACE 的决策函数更真实地依赖图像内容，而非主要依赖语言捷径。

## 7. 方法亮点

1. **元数据驱动的路由策略：** 将教育评测中原本"天然可见"的结构化元数据（学科、年级、技能）重新利用为适配路由信号，设计简洁且符合教育场景特征。
2. **因子分解的提示组合：** 将联合状态空间分解为因子级组件，避免了对每个联合状态训练独立专家导致的组合爆炸，具有较高的参数效率。
3. **视觉与语言路径的联合条件化：** 共享同一教学状态同时控制视觉适配门控和语言前缀组合，实现跨模态一致的适配。
4. **证据感知的选项校准机制：** 通过长度归一化的条件对数似然 + 轻量验证器 + 列表式排序损失（OCAV），将训练与推理统一在有限候选集上的排序任务中，避免了生成式答案归一化误差。
5. **匹配干预的视觉依赖分析：** 采用全灰图像作为对照条件，直接度量决策函数对图像内容的依赖程度，为评估模型是否"真正在看图"提供了直观、可量化的指标。
6. **严格的受控对比：** 所有作者运行的基线共享同一骨干、处理器、提示模板和评估代码，确保结论的公平性；已发表结果仅作为参考而非受控估计。

## 8. 不足与局限

1. **评估覆盖范围有限：** 仅在 ScienceQA 一个数据集上验证，缺乏在其他教育 VQA 基准或真实课堂场景数据上的评估。论文自身也承认需要更多基准和骨干网络来验证泛化性。
2. **依赖推理可见的元数据：** GRACE 假设学科、年级等教育元数据在推理时可用。若在实际部署中元数据缺失、不完整或标注质量不佳，状态构建将受影响（尽管说明了缺失字段使用"未知"嵌入，但效果有待验证）。
3. **视觉依赖分析不够精细：** 全灰图像干预能衡量整体视觉依赖程度，但无法定位是哪个图像区域或视觉特征导致了预测变化，缺少细粒度的视觉接地分析。
4. **单一骨干验证：** 仅评估了 Qwen2.5-VL-7B，未探索不同模型规模、不同视觉编码器或不同语言解码器下的框架迁移性。
5. **消融指标的完整性稍显不足：** 表 2 中未列出 G1-6 等子指标的消融结果，无法判断各组件在不同年级或技能类别上的异质性影响。
6. **对捷径缓解机制的归因：** 虽然视觉依赖分析显示了更大的 full–blank 差距，但未直接验证 GRACE 是否显著降低了基于问题—选项统计的捷径学习（如与语言先验相关的定量分析）。
7. **超参数选择的敏感性未充分讨论：** 门控系数 $\alpha$、瓶颈维度 256、插入层选择（块 4 和 8）、权重 $\lambda_o = 1.0$ 等关键设计选择未提供敏感性分析。
