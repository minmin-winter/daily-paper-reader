## 摘要
零样本时序动作检测（ZSTAD）旨在从未修剪视频中的未见动作类别中定位并识别动作实例。尽管现有方法通过改进架构性的文本-视频对齐已展现出有效性，但它们仍难以捕捉动作类别之间的语义差异，导致预测与文本无关。为解决此问题，我们提出了一种文本-前景集中对齐的零样本时序动作检测器（TF-CADE），它显式地将文本信息与动作相关的前景区域对齐。具体而言，我们引入了动作集中聚合（ACA），它提取动作集中分数，将时间上有信息的视频片段聚合成前景加权的视频嵌入。这种前景集中的对齐增强了文本与视频特征之间的语义一致性，并提高了类间可区分性。此外，一种基于确定性的置信度重加权（CCR）策略通过利用前景感知的相似性细化每个片段的置信度分数，在推理过程中有效抑制不相关的动作类别。大量评估表明，我们的TF-CADE不仅在分布内设置下实现了最先进的性能，而且在跨数据集泛化到未见动作类别方面也表现出色。

## Abstract
Zero-Shot Temporal Action Detection (ZSTAD) aims to lo- calize and recognize action instances from unseen action categories in untrimmed videos. Although existing meth- ods have shown effectiveness by advancing architectural text-video alignment, they still struggle with capturing se- mantic distinctions between action classes, resulting in text- irrelevant predictions. To address this issue, we propose a Text-Foreground Concentrated Alignment for zero-shot temporal action DEtector (TF-CADE) that explicitly aligns textual information with action-relevant foreground regions. Specifically, we introduce Action Concentrate Aggregation (ACA), which extracts action concentrate scores to aggregate temporally informative video segments into a foreground- weighted video embedding. This foreground concentrated alignment enhances the semantic consistency between text and video features and improves inter-class discriminabil- ity. In addition, a Certainty-based Confidence Re-weighting (CCR) strategy refines per-snippet confidence scores by lever- aging foreground-aware similarity, effectively suppressing irrelevant action classes during inference. Extensive evalua- tions show that our TF-CADE not only achieves state-of-the- art performance under in-distribution settings but also excels in cross-dataset generalization to unseen action classes.

## 二、论文提出的方法论

### 1. 核心思想
基于 Ti-FAD 的交叉模态适配基线，TF-CADE 通过**显式聚焦动作相关的前景区域**来实现文本-视频对齐，避免背景信息造成的语义漂移，并利用前景感知的视频级相似性分数来细化推理过程中的片段级预测。

### 2. 关键组件一：Action Concentrate Aggregation（ACA）

ACA 用于生成前景加权的视频嵌入，分为两步：

**① 构造时序动作确定性图（Temporal Action Certainty Map）**
- 利用编码器第 l 层输出的视频特征 $v^{(l)}$ 与文本特征 $c^{(l)}$ 计算视频-文本置信度图：$P_{cls} = v^{(l)} \cdot c^{(l)\top} \in \mathbb{R}^{T_l \times N_c}$
- 对类别维取最大值后施加 softmax，得到初始动作确定性分数 $m^{(l)}_{max}$，它集中于最显著的动作帧；
- 对 $m^{(l)}_{max}$ 沿时间维应用一维高斯核 $G(\sigma)$ 卷积，得到平滑的动作确定性图 $m^{(l)}_{filter}$，以抑制噪声和过度尖锐的峰值；
- 最终确定性图为两者之和：$m^{(l)} = m^{(l)}_{max} + m^{(l)}_{filter}$，并沿时间维归一化。

**② 生成前景加权视频嵌入与视频级相似度分数**
- 通过软聚合得到前景加权视频嵌入：$v^{(l)}_{fg} = \sum_{t=1}^{T_l} m^{(l)}_t \odot v^{(l)}_t \in \mathbb{R}^D$
- 对每个类别 n，计算前景基视频级分数并跨 L 层平均：$S^{(n)}_{fg} = \frac{1}{L} \sum_{l=1}^{L} \text{sim}(v^{(l)}_{fg}, c^{(l)}_n)$
- 最终得到前景基视频级相似度向量 $S_{fg}$，用于训练时的前景-文本对齐（对应视频级分类损失 $L_{video}$）。

### 3. 关键组件二：Certainty-based Confidence Re-weighting（CCR）

CCR 是推理阶段的视频级先验机制：
- 对前景基视频级相似度 $S_{fg}$ 施加 softmax，估计每个类别出现在视频中的可能性；
- 将其与逐片段的 sigmoid 分类置信度图做逐元素相乘，生成重新加权的置信度图：

$$\tilde{P}_{cls} = \sqrt{\text{sigmoid}(P_{cls}) \odot \text{softmax}(S_{fg})}$$

- 该过程强调动作相关类别、抑制无关类别（特别是与目标类语义相似但实际无关的类）。

### 4. 训练与推理流程
- **训练**：总损失为 $L = L_{cls} + L_{loc} + L_{an}$，其中 $L_{cls} = L_{snippet} + L_{video}$（两者均使用 focal loss），$L_{loc}$ 为 DIoU 边界回归损失，$L_{an}$ 为 actionness 损失；
- **推理**：模型预测（起点、终点、类别），对重加权后的置信度图取 argmax 获得类别分数，最后使用 Soft-NMS 抑制冗余提议。

## 六、论文的主要结论与发现

1. **背景干扰是文本-视频对齐失效的关键原因**：现有 foreground-free 方法将文本与包含背景的全部视频区域对齐，导致文本特征向背景漂移，产生文本无关预测；
2. **前景集中对齐有效**：ACA 通过动作确定性图对视频特征进行前景加权聚合，显著增强了文本与视频的语义一致性和类间判别力；
3. **视频级先验可改善片段级预测**：CCR 利用前景基视频级相似度分数细化逐片段分类，有效抑制语义相似的混淆类别，减少错误标签类误报；
4. **性能全面领先**：在分布内设置（THUMOS14 和 ActivityNet v1.3）达到 SOTA；在跨数据集零样本泛化中大幅超越现有方法（如 0%-100% 划分下 THUMOS14 上 mAP 从 11.1 提升到 27.4）；
5. **方法鲁棒性好**：对高斯核超参数 σ 不敏感，跨数据集和多特征设置下均表现稳定。
