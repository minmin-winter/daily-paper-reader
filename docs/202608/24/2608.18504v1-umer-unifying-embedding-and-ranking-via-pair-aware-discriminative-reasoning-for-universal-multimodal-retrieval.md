## 摘要
通用多模态检索旨在支持多样化的指令感知检索任务，既需要高效的语料库规模匹配，也需要细粒度的语义推理。近期基于MLLM的嵌入方法通常从隐藏状态中获取表示，而思维链（CoT）推理正成为一种有前景的嵌入增强策略，通过将中间语义证据编码到表示空间中来提升效果。然而，现有的CoT方法通常对查询和候选进行孤立的逐项推理，无法为区分正例与语义上易混淆的难负例提供明确证据。此外，对比嵌入捕获全局相似性，但在需要答案验证、类别判断或细粒度推理的元任务上表现不佳。本文提出UMER，一个用于通用多模态检索的统一多模态嵌入与排序框架。UMER以成对感知判别性推理取代逐项反思，通过比较查询-候选对来识别与指令相关的匹配和差异证据。UMER在单个MLLM中联合学习用于高效全局匹配的对比嵌入和用于显式成对相关性判断的判别性排序。一种互补的相互蒸馏策略进一步在嵌入函数和排序函数之间传递可靠的成对偏好。在MMEB-V2基准上，UMER在可比较的实验设置下达到了最先进的性能，同时支持预算可调的推理。

## Abstract
Universal multimodal retrieval aims to support diverse instruction-aware retrieval tasks, demanding both efficient corpus-scale matching and fine-grained semantic reasoning. Recent MLLM-based embedding methods typically derive representations from hidden states, while Chain-of-Thought (CoT) reasoning is emerging as a promising strategy for embedding enhancement by encoding intermediate semantic evidence into the representation space. However, existing CoT methods typically use item-wise reasoning over queries and candidates in isolation, providing no explicit evidence to distinguish a positive from a semantically confusable hard negative. Moreover, contrastive embeddings capture global similarity but struggle with meta-tasks requiring answer verification, category judgment or fine-grained reasoning. In this paper, we propose UMER, a Unified Multimodal Embedding and Ranking framework for universal multimodal retrieval. UMER replaces item-wise reflection with Pair-Aware Discriminative Reasoning, which compares query--candidate pairs to identify instruction-relevant matching and discrepancy evidence. UMER jointly learns contrastive embeddings for efficient global matching and discriminative ranking for explicit pairwise relevance judgment within a single MLLM. A complementary mutual distillation strategy further transfers reliable pairwise preferences between the embedding and ranking functions. On the MMEB-V2 benchmark, UMER achieves state-of-the-art performance under comparable experimental settings while supporting budget-adjustable inference.

## 1. 论文的核心问题与研究动机

**核心问题**：通用多模态检索（Universal Multimodal Retrieval）需要在统一框架中支持跨图像、文本、视频、文档的多种指令感知检索任务，这要求模型同时具备两种看似矛盾的能力：**大规模语料高效匹配**（依赖全局嵌入、向量索引）与**细粒度语义推理**（依赖查询-候选交互、证据判断）。

**现有方法的两个关键缺陷**：

- **逐项CoT缺乏判别性证据**：现有基于MLLM的嵌入方法（如UME-R1、PLUME等）采用逐项自省式思维链（item-wise self-reflective CoT），即对查询和候选进行孤立的语义描述。这种方式无法建模查询-候选之间的交互，不能解释"为什么正例匹配"或"为什么难负例不匹配"，尤其对于视觉内容、场景结构高度相似但细粒度属性不同的难负样本，区分能力不足。
- **对比嵌入难以支撑推理密集型元任务**：对比学习得到的嵌入擅长捕获全局语义相似度，适合内容匹配类任务（图像检索、视频检索、时刻检索、视觉定位），但在需要答案验证、类别判断、细粒度推理的元任务（问答、分类）上表现受限。反之，交互式判别排序擅长推理但对全语料检索的扩展性差。**不同元任务对模型能力的需求存在系统性差异**，单一对比嵌入目标无法覆盖全部需求。

**核心论点**：通用多模态检索应将"表示驱动的检索"与"显式判别排序"统一在一个模型内，让二者互补协同。

## 2. 方法论：UMER 框架

### 2.1 核心思想

在单个共享 MLLM（Qwen2-VL）中同时学习三个能力：
1. **可独立索引的对比嵌入**（embedding function）：用于语料库规模的高效全局匹配；
2. **成对感知判别性思维链**（Pair-Aware Discriminative CoT）：显式比较查询-候选对，产出一致性与差异性证据；
3. **判别性排序**（discriminative ranking）：基于推理证据输出相关性得分。

### 2.2 统一嵌入与排序架构

- **嵌入编码阶段**：对每个输入（查询或候选）追加 M=4 个可学习嵌入 token，通过分支注意力掩码（branch-wise attention mask）保证查询和候选独立编码，互不交叉，从而支持语料库预索引和近似最近邻检索。嵌入向量为 M 个嵌入 token 隐藏状态的均值池化加 ℓ2 归一化。
- **成对推理与排序阶段**：将查询和候选编码后，拼接固定提示 P，在完全成对注意力下自回归生成成对推理轨迹；随后追加一个可学习的 `[RANK]` token 产生相关性 logit 与概率。

### 2.3 损失函数

| 损失 | 作用 |
|------|------|
| **L_emb（对比损失）** | 采用批次内对比目标并加入挖掘的难负例，学习温度缩放的余弦相似度度量空间 |
| **L_cot（CoT交叉熵）** | 监督成对判别性思维链的语言生成，使推理扎根于查询-候选联合可见证据 |
| **L_bce（二元交叉熵）** | 为正例对和难负例对提供绝对相关性标签（正例概率→1，负例→0） |
| **L_margin（成对边际损失）** | 逻辑成对目标，鼓励正例 logit 高于难负例 logit |
| **L_cmd（互补互蒸馏）** | 选择性双向 KL 蒸馏，在嵌入与排序间传递可靠偏好 |

总目标：L_all = L_emb + λ_cot·L_cot + λ_bce·L_bce + λ_margin·L_margin + λ_cmd·L_cmd，权重为 (0.2, 0.1, 0.2, 0.2)。

### 2.4 成对判别性 CoT 数据构建（三步）

1. **难负例挖掘**：用冻结的现成多模态嵌入器（Qwen3-VL-Embedding-8B）对每个查询按余弦相似度排序非相关候选，保留 Top-3 难负例，并过滤掉相似度超过正例 0.75 倍的疑似漏标正例。
2. **结构化 CoT 生成**：用 Qwen3.5-9B 对每个正例对和难负例对分别生成两个字段的 CoT：`Query Intent`（查询指令需要的证据）与`Target Observations`（候选方支持或矛盾的证据），且不输出显式 Yes/No 答案，强制从证据中推断相关性。
3. **证据充分性过滤**：用轻量级文本验证器（Qwen3.5-0.8B）仅凭 CoT 文本推断真实相关性标签，只有通过验证的 CoT 才被保留，最终构成"已验证三元组" (q, c⁺, c⁻)。

### 2.5 互补互蒸馏（CMD）

- 不是无差别强制嵌入与排序一致，而是**按元任务属性选择性单向传递**：内容匹配任务（Retrieval、Grounding/MR）以嵌入为教师，推理密集型任务（CLS、QA）以排序为教师。
- 门控机制：仅当参考模型在该三元组上正确排序时才激活对应方向的蒸馏，避免不可靠偏好传播。
- 在 Stage 3 中，冻结 Stage 2 模型作为参考模型，分别计算嵌入→排序与排序→嵌入两个方向的 KL 蒸馏。

### 2.6 三阶段渐进训练与灵活推理

- **Stage 1**：仅用 L_emb 在完整 MMEB 训练集上学习稳定的可索引嵌入空间；
- **Stage 2**：加入 L_cot、L_bce、L_margin 学习判别性证据与相关性排序；
- **Stage 3**：冻结 Stage 2 模型为参考，加入 L_cmd 跨能力传递可靠偏好。
- **推理模式**：UMER-E（仅嵌入检索）、UMER-R（仅成对排序重排）、UMER-H（混合评分，对 top-K 候选分别 z-score 归一化嵌入得分与排序得分后加权融合，默认 K=5，α=2.0）。

## 6. 主要结论与发现

1. **成对判别性推理优于逐项自省推理**：在同样可索引的嵌入设定下，UMER-E 将正例到难负例的余弦边际从 5.24 提升到 6.80（×10⁻²），且在更严格阈值下保持更多查询的分离优势。
2. **嵌入与排序确实互补**：内容匹配类任务嵌入更强，推理密集型任务排序更强，同一模型的两种能力存在系统性分工。
3. **选择性互蒸馏有效**：单向蒸馏只提升目标分支，无条件双向蒸馏收益受损，而选择性门控双向蒸馏使两个分支共同提升且不丧失特化，验证了"互补而非同化"的设计理念。
4. **统一框架兼顾效率与精度**：UMER-E 达到最佳的嵌入-only 得分 63.1 且零推理 token，查询/索引速度比 UME-R1 快约 118.6×/99.6×；UMER-H 通过 top-5 重排获得 80% 的最大增益但仅消耗 K=20 时 24% 的延迟，支持预算可调推理。

## 7. 方法优点

- **问题洞察深刻**：明确指出现有逐项 CoT 的"推理盲区"——无法为硬负例判别提供证据，以及不同元任务对嵌入/排序能力的异质性需求，并以数据驱动的能力特化分析支撑动机。
- **架构设计巧妙**：通过分支注意力掩码在同一主干中同时支持独立嵌入编码和成对交互推理，实现"一次训练、多种推理模式"，避免了传统两阶段管线中嵌入与重排器分离导致的梯度隔断。
- **数据质量把控严谨**：CoT 生成后经过"文本-only 证据验证"过滤，保证推理轨迹确实包含足以判定相关性的判别性证据，而不是流利但无效的文本。
- **蒸馏策略精细**：CMD 不强迫两个分支趋同，而是按任务属性选择教师方向并设门控，这是"互补协同"思想在训练目标上的具体实现。
- **评估全面**：从精度、消融、机制、效率、决策重叠、定性案例多维度验证了方法有效性与可解释性。

- **基线与骨干范围有限**：对比方法集中于 Qwen2-VL 系列骨干（2B/7B），未与其他架构（如 LLaVA、InternVL 等骨干）或更大规模模型（如 Qwen3-VL）对比，通用性结论受限于单一模型家族。
- **消融仅在 2B 规模**：默认超参数（K=5、α=2.0）是在 MMEB-V2 开发集上调优得到，尽管提供了灵敏度分析，仍存在对单一基准过拟合的风险；未在其他基准（如 MS MARCO、FashionIQ 等独立场景）验证泛化性。
- **难负例挖掘依赖参考模型质量**：CoT 数据由 Qwen3.5 系列生成，训练模型在蒸馏和知识上存在对 Qwen 家族能力的依赖偏差；若数据生成器存在领域盲区，证据过滤环节可能继承该偏差。
- **硬负例覆盖有限**：训练中每个查询仅取 1 个离线难负例用于重排，虽然计算效率高，但可能不足以覆盖多样化的混淆模式。
- **推理成本仍显著**：尽管支持预算可调，UMER-H 在 K=20 时单查询延迟高达 81.7 秒/查询（2B 模型），实数级部署中成对 CoT 的推理开销仍是较大瓶颈；失败案例分析也显示排序分支在空间关系类细粒度任务上可能因"显著性偏差"而忽略查询的相对位置约束，说明推理的鲁棒性仍有提升空间。
