## 摘要
联合音频视频生成旨在合成时间同步且语义连贯的视听内容。然而，现有的开源方法主要依赖于双塔设计与后对齐，或是在一个共享空间中混合文本上下文、音频和视频的全统一三模态设计。前者削弱了细粒度的音视频协同演化，而后者将语义条件与低级同步耦合在一起。为了解决这些限制，我们提出了NAVA，一个用于联合音视频生成的原生音视频对齐框架。NAVA建立在上下文条件化的原生音视频对齐之上：它首先在专用的交互空间中建立音视频对应关系，然后使用外部上下文来条件化联合去噪过程。具体来说，NAVA通过先对齐后融合的MMDiT架构实例化，该架构从模态感知的音视频对齐过渡到模态共享的联合去噪。此外，我们引入了上下文音色条件化，将参考音色线索与相应的语音片段关联起来，以实现可控的语音音色。在Verse-Bench和Seed-TTS上的实验以及用户研究表明，NAVA仅使用63亿参数就实现了卓越的视频质量、精确的音视频同步、有竞争力的音频质量和更强的参考音色可控性。

## Abstract
Joint audio-video generation aims to synthesize temporally synchronized and semantically coherent visual-acoustic content. However, existing open-source methods mainly rely on either dual-tower designs with posterior alignment or fully unified tri-modal designs that mix textual context, audio and video in one shared space. The former weakens fine-grained audio-video co-evolution, while the latter couples semantic conditioning with low-level synchronization. To address these limitations, we propose NAVA, a Native Audio-Visual Alignment framework for joint audio-video generation. NAVA is built upon context-conditioned native audio-visual alignment: it first establishes audio-video correspondence in a dedicated interaction space, and then uses external context to condition the joint denoising process. Specifically, NAVA is instantiated with an Align-then-Fuse MMDiT architecture, which transitions from modality-aware audio-video alignment to modality-shared joint denoising. Furthermore, we introduce Timbre-in-Context Conditioning to associate reference timbre cues with corresponding speech spans to achieve controllable speech timbre. Experiments on Verse-Bench and Seed-TTS, together with a user study, demonstrate that NAVA achieves superior video quality, precise audio-visual synchronization, competitive audio quality, and stronger reference-timbre controllability using only 6.3B parameters.

- **整体含义**：需要一种新的范式，将音视频对应关系从上下文条件中解耦，在专属同步空间中实现“原生”对齐，从而提升同步精度、可控性与生成质量。

### 2. 论文提出的方法论

#### 2.1 核心思想：基于上下文条件的原生音视频对齐
- 与双塔后对齐和全统一三模态不同，NAVA 先在**专用交互空间**中建立音视频对应（原生对齐），再将文本、参考音色等作为**外部条件**注入，实现解耦的联合去噪。
- 形式化表示为：
  - 双塔：$h'_a = \text{CrossAttn}(h_a, c), h'_v = \text{CrossAttn}(h_v, c)$，后期再通过 $\text{CrossModalAttn}$ 对齐。
  - 全统一：$[\tilde{h}_a, \tilde{h}_v, \tilde{c}] = \text{SelfAttn}([h_a, h_v, c])$，上下文与模态混合在同一个自注意力空间。
  - NAVA：先进行音视频联合自注意力 $[h'_a, h'_v] = \text{SelfAttn}([h_a, h_v])$ 建立原生对应，再通过交叉注意力 $[\tilde{h}_a, \tilde{h}_v] = \text{CrossAttn}([h'_a, h'_v], c)$ 注入条件。

#### 2.2 架构实例化：Align-then-Fuse MMDiT
- **分层对齐层（Hierarchical Alignment Layers）**：前 30 个块中的前 10 块。
  - 采用**模态解耦对齐投影**，音频与视频分别通过模态特定的投影层，再进入共享的音频‑视频交互空间，以稳定早期异质模态的对应学习。
  - 内部进行**音频‑视频联合自注意力与 FFN**，使声学模式与视觉动态在去噪全程协同演化。
  - 针对音视频token率不匹配，对音频 token 的位置编码进行速率感知重缩放：$\theta_{\text{rope}} = \frac{TR_v}{TR_a}$，使时序坐标更具可比性。
  - 上下文通过**上下文引导的交叉注意力与 FFN** 注入，避免上下文直接参与低级同步的自注意力。
- **统一融合层（Unified Fusion Layers）**：后 20 个块。
  - 音频与视频 token 使用**模态共享的统一投影**，并由共享的 Transformer 块更新。
  - 前置对齐层已缩小表征差距，故参数共享更稳定、高效，促进紧凑的协同去噪。
  - 上下文仍通过交叉注意力保持外部调制。

#### 2.3 上下文音色条件化（Timbre-in-Context Conditioning）
- 将参考音色编码为上下文 token：$s_i = E_{\text{tim}}(R_i)$，然后将每个语音段 $S_i$ 扩展为 $\langle S \rangle, s_i, \text{Text}(S_i), \langle E \rangle$，形成增强的上下文序列 $c$。
- 在去噪时通过上下文引导交叉注意力将音色线索绑定至特定语音段，无需额外的说话人控制分支，天然支持多说话人、多音色组合控制。

#### 2.4 训练与推理策略
