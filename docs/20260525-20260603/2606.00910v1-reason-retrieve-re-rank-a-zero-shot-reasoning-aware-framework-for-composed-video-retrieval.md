## 摘要
组合视频检索（CoVR）旨在找到将自由形式的文本修改应用于参考视频后生成的目标视频。我们参加了 CVPR 2026 VidLLMs 研讨会上的推理感知 CoVR（CoVR-R）挑战赛，该挑战要求严格零样本检索。我们提出 R3-CoVR（推理、检索、重排序），这是一个完全由冻结的基础模型构建的无训练流程。一个多模态大语言模型（Qwen3-VL-8B）推理编辑所隐含的后效应——状态转换、动作阶段、场景、镜头和节奏——并生成简洁的编辑后描述；一个对比式视频-文本编码器（SigLIP-2）将该描述和图库进行嵌入用于第一阶段检索；最后，一个约束感知的重排序阶段使用同一个多模态模型作为评判者，根据预期的编辑结果对每个候选视频进行评分。在挑战测试集上，R3-CoVR 达到了 91.9% 的 R@1 和 98.2% 的 R@10。两项发现驱动了这些结果：(i) 将描述长度匹配到对比编码器的文本窗口，将 R@1 从 67.5 提升到 72.7；(ii) 仅对候选列表进行重排序的约束感知重排序器，将 R@1 从 72.7 提升到 91.9——这是单次最大提升。我们分析了重排序器的行为、检索与重排序的混合以及候选列表深度，并发布了清晰的三层实现。

## Abstract
Composed Video Retrieval (CoVR) seeks the target video that results from applying a free-form textual modification to a reference video. We address the \emph{Reason-Aware} CoVR (CoVR-R) challenge at the CVPR~2026 VidLLMs workshop, where retrieval is strictly zero-shot. We present \textbf{R3-CoVR} (\emph{Reason, Retrieve, Re-rank}), a training-free pipeline built entirely from frozen foundation models. A multimodal large language model (Qwen3-VL-8B) reasons about the \emph{after-effects} an edit implies -- state transitions, action phases, scene, camera and tempo -- and verbalises a concise post-edit description; a contrastive video--text encoder (SigLIP-2) embeds this description and the gallery for first-stage retrieval; finally a constraint-aware re-ranking stage uses the same multimodal model as a judge that scores each shortlisted candidate against the intended edited result. On the challenge test set, R3-CoVR attains \textbf{91.9\% R@1} and \textbf{98.2\% R@10}. Two findings drive these results: (i)~matching the description length to the contrastive encoder's text window lifts \Rk{1} from $67.5$ to $72.7$; and (ii)~the constraint-aware re-ranker, which reorders only the shortlist, lifts \Rk{1} from $72.7$ to $91.9$ -- the single largest gain. We analyse the re-ranker's behaviour, the retrieve/re-rank blend, and the shortlist depth, and we release a clean three-layer implementation.

### 1. 论文的核心问题与整体含义

- **核心问题**：组合视频检索（Composed Video Retrieval, CoVR）要求系统根据一个参考视频和一段自由形式的文本修改指令，从大规模视频库中检索出反映该组合变化的目标视频。该任务的关键挑战在于，修改指令往往隐含了需要推理的视觉后效（例如“将打字改为沮丧”意味着拳头紧握、合上笔记本电脑），而非显式描述目标画面。
- **研究背景与动机**：论文针对 CVPR 2026 VidLLMs 研讨会的 **推理感知组合视频检索（Reason-Aware CoVR, CoVR-R）** 挑战赛。该挑战设定严格 **零样本**：不允许在挑战数据上进行任何训练或微调，模型必须依靠泛化能力完成检索，且推理痕迹是评分项之一。现有方法需避免简单的关键词匹配，转而理解编辑的隐含视觉后果。

### 2. 论文提出的方法论

R3-CoVR（Reason, Retrieve, Re‑rank）是一个完全基于冻结基础模型的无训练三阶段流水线。

- **整体流程**：
  1. **推理（Reason）**：冻结的多模态大模型 **Qwen3-VL-8B** 观察参考视频（1 fps 采样），推理编辑的“后效应”。它输出一个结构化的推理轨迹（包含状态转换、动作阶段、场景、镜头、节奏）和一份简洁的**编辑后目标描述**。采用 3 次采样的自一致性，最终将描述嵌入平均以增强稳定性。
  2. **检索（Retrieve）**：使用冻结的对比式视频-文本编码器 **SigLIP-2**。对每个图库视频均匀采样 8 帧，均值池化并 L2 归一化得到视频嵌入；对目标描述进行编码得到查询嵌入。通过余弦相似度检索出 **top‑K 候选列表**。
  3. **重排序（Re‑rank）**：同一 Qwen3-VL 模型作为**约束评判器**，对候选列表中的每个视频与编辑指令、目标描述进行匹配打分（整数 0 到 100，归一化到 [0,1]），然后将评判分数 \( s_j \) 与检索排名分数 \( \text{rank}_K \) 进行线性混合：\( s_{\text{final}} = \lambda s_j + (1-\lambda) \text{rank}_K \)。重排序仅作用于短列表，计算量可控。

- **关键技术细节**：
  - **描述长度匹配**：将目标描述约束为 ≤40 词的简洁陈述，以匹配 SigLIP-2 文本编码器的 64 token 窗口，防止关键信息被截断。
  - **评判器去噪**：使用 5 次采样的平均评分代替单次贪婪生成，将候选视频的独特分数值从 8 个提升到 86 个，有效解决因相同最高分造成的排序平局。
- **公式（文字描述）**：最终得分 \( s_{\text{final}}(V) = \lambda \cdot \text{judge\_score}(V) + (1-\lambda) \cdot \frac{K - i}{K} \)，其中 \( i \) 是候选在短列表中的位置，\( \lambda \) 混合权重通常设为 0.8。

### 6. 论文的主要结论与发现

- R3‑CoVR 在 CoVR‑R 挑战测试集上获得 **91.9% 的 R@1** 和 **98.2% 的 R@10**，性能源于两个关键发现：
  1. **描述长度与编码器窗口匹配**：将目标描述从段落压缩为简洁陈述，使 R@1 从 67.5% 提升到 72.7%（+5.2），R@5 从 78.4% 跃升至 95.0%（+16.5）。
  2. **约束感知重排序是最大单次增益**：对 top‑10 列表应用约束评判器重排序，将 R@1 从 72.7% 提升到 91.9%（+19.2）。
- 适当混合评判分数与检索排名（\( \lambda=0.8 \)）效果最优，纯评判或纯检索均有所不及。
- 增加候选列表深度（如 top‑20）能提升 R@5 和 R@10，但对 R@1 影响甚微。

### 7. 优点

- **完全零样本、无训练**：所有模型冻结，无过拟合风险，可直接迁移至新图库。
- **强解释性**：阶段 1 的推理轨迹和阶段 3 的评判理由使决策透明，契合挑战赛对推理轨迹的要求。
- **模块化与可复现**：设计为数据、模型、运行器三层架构，支持灵活替换编码器或评判器，且开源自述为干净实现。
- **效果突出**：两个简单而关键的工程选择（描述长度控制、短列表重排序）带来了显著性能飞跃。

### 8. 不足与局限

- **计算开销**：重排序成本随短列表深度 K 和每候选评判时间线性增长，大规模图库需要更廉价的第一遍过滤。
- **评判器能力瓶颈**：Qwen3‑VL‑8B 对部分细粒度视频对可能无法区分，导致 R@1（91.9%）与 R@10 天花板（~97%）之间存在差距，使用更大规模模型（如 72B）是直接改进方向。
- **文本窗口限制**：SigLIP‑2 的 64 token 窗口限制了阶段 1 描述信息量，改用长上下文或原生视频检索器可进一步提升初筛召回率。
- **计算与鲁棒性权衡**：自一致性和去噪评判器通过重复生成来增强鲁棒性，在大规模部署时需重新审视其性价比。
