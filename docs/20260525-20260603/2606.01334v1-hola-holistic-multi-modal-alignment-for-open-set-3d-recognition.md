## 摘要
开放集3D识别要求模型能够泛化到稀有或未见过的类别。最近的方法通过将语言-视觉知识蒸馏到3D编码器中来解决这一问题，通常依赖庞大的2D ViT，并将每个点云与单张图像或单个标题对齐，从而将表示锚定在局部视图上。我们提出将每个点云与多个图像和文本描述对齐，以捕捉对3D物体更全面的理解。为实现这一想法，必须设计一个损失函数，能够将3D实例与多个匹配信号（多视图图像和多个文本）联合对齐，同时将正样本聚合与负样本竞争解耦。我们引入了这样一个函数，称为解耦多正样本对比损失。我们的公式增强了损失对困难负样本的硬度感知聚焦，避免了当许多正样本与所有负样本共享同一softmax时出现的“聚光灯拥挤”现象。作为补充，我们提出了一种轻量级文本适配器，仅应用于网络标题，缩小了与精心标注之间的领域差距，并使得大规模无监督文本得以有效利用。我们的模型在长尾基准上展示了最先进的开放词汇性能，在保持高帧率的同时带来了显著零样本改进。

## Abstract
Open-set 3D recognition requires models that generalize to rare or unseen categories. Recent approaches address this by distilling language-vision knowledge into 3D encoders, typically relying on heavy 2D ViTs and aligning each point cloud with a single image or caption, thus anchoring representations to partial views. We propose aligning each point cloud with multiple images and textual descriptions to capture a more holistic understanding of 3D objects. To realize this idea, it is essential to design a loss function capable of jointly aligning a 3D instance with multiple matched signals, multi-view images and multiple texts, while separating positive aggregation from negative competition. We introduce such a function, termed the decoupled multi-positive contrastive loss. Our formulation enhances the loss's hardness-aware focus on challenging negatives, avoiding the "spotlight crowding" that occurs when many positives share the same softmax with all the negatives. Complementing this, we present a lightweight text adapter applied only to web captions, reducing the domain gap to curated annotations and enabling effective use of large-scale unsupervised text. Our model demonstrates state-of-the-art open-vocabulary performance on long-tail benchmarks, yielding substantial zero-shot improvements while sustaining high frame rates.

- **核心问题**：开放集 3D 识别，即让模型在推理时能泛化到训练中未见过或极少出现的类别（长尾问题）。

    - 大多数方法每次仅将点云与单张图像或单个文本描述对齐，只能捕捉物体的局部视图，丢失整体三维信息，尤其不利于长尾类别的表示。
    - 朴素的多正样本对比损失（Multi-Positive Contrastive Loss）在同时对齐多种模态信号时，会导致“聚光灯拥挤”现象：正样本过多地占据 softmax 分母，使得模型对困难负样本的梯度关注下降，削弱对比学习的硬度感知能力。

- **研究目标**：设计一个轻量、整体性的多模态对齐框架，让点云与多视角图像和多种文本描述（包括人工标注、VLM 生成文字、网络图片标题）对齐，提升长尾类别与开放词汇场景下的性能同时保持高推理帧率。

### 2. 论文提出的方法论

#### 2.1 整体三模态输入与对称对齐
- 训练三元组：每个 3D 点云对应一组多视角渲染图像和一组文本描述（三种来源混合）。
- 三个模态编码器：图像编码器和文本编码器来自冻结的 CLIP（OpenCLIP ViT-bigG-14），仅训练 3D 编码器（PointBERT 或 MinkowskiNet）和一个轻量文本适配器。
- 计算三对对齐损失：3D-Image、3D-Text、Text-Image，每对损失采用双向（对偶）求和。

#### 2.2 解耦多正样本对比损失（Decoupled Multi-Positive Contrastive Loss, DMP）
- **朴素多正比损失的缺陷**：随着正样本数增多，softmax 分母中正样本项权重上升，负样本梯度被稀释，丧失硬度感知能力（困难负样本梯度变小）。
- **解耦损失设计**：将多正对齐项与负样本分离项拆开：
  
  \[
  L_{\text{DMP}}(q_i) = -\frac{1}{\tau |P(i)|}\sum_{r\in P(i)} s_{ir}^+ + \log\sum_{j\in N(i)} \exp\left( s_{ij}^- / \tau \right)
  \]
  
  第一项强制所有匹配视图（多张图像或文本）向锚点聚集；第二项只需负样本之间竞争，梯度不受正样本数量影响，保持了硬度感知性质。
  
- **加权变体（DWMP）**：对多正对齐项引入基于实例难度的加权系数 \( w_i \)，使得与正样本相似度较低的锚点获得更大权重，进一步增强硬度感知。

#### 2.3 文本适配器（Text Adapter）
- 训练时随机采样来源于三种文本描述：标注/元数据、VLM 生成文字、检索到的网络图片标题。
- 网络标题与领域内标注/生成文字存在分布差异（领域漂移）。
- 采用一个轻量 MLP 适配器，仅作用于网络标题的 CLIP 文本嵌入，将其对齐到渲染图像嵌入，并通过 EMA 拷贝稳定训练目标，防止持续漂移。
- 选择仅适配文本而非图像，因为主要域差距来自网络标题。
