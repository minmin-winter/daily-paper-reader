## 摘要
链式思维（CoT）推理通过用自然语言表达中间推理步骤，显著提升了大型视觉语言模型（LVLMs）的推理能力。然而，这种离散的文本推理依据往往不足以编码连续的视觉证据。近期研究通过将推理转移到连续潜在空间来解决这一局限。尽管取得了可喜进展，现有方法使得潜在推理与视觉证据的组合和关系结构之间的连接不充分。为填补这一空白，我们引入了ReGuLaR，一个基于关系基底的潜在推理框架，明确将潜在状态基于这些关键但被忽视的视觉证据。ReGuLaR在训练时使用ReGFormer使潜在推理聚焦于与问题相关的对象和对象间关系，而在推理时，模型在不调用ReGFormer的情况下进行推理并生成答案。为支持ReGuLaR的训练，我们构建了RGROUNDING-351K，一个标注有关键对象边界框和对象间关系的真实世界视觉语言数据集。在多个基准上的大量实验表明，ReGuLaR始终优于现有方法，并达到了最先进的性能。我们在提交中包含代码，并将在接受后公开发布代码和训练数据。

## Abstract
Chain-of-thought (CoT) reasoning has significantly improved the reasoning ability of large vision-language models (LVLMs) by verbalizing intermediate reasoning steps in natural language. However, such discrete textual rationales are often insufficient for encoding continuous visual evidence. Recent work addresses this limitation by moving reasoning into continuous latent space. Despite promising progress, existing methods leave latent reasoning insufficiently connected to the compositional and relational structure of visual evidence. To address this gap, we introduce ReGuLaR, a relation grounded latent reasoning framework that explicitly grounds latent states in these critical yet overlooked visual evidence. ReGuLaR uses a training-time ReGFormer to focus latent reasoning on question-relevant objects and inter-object relations, while at inference time the model reasons and generates answers without invoking the ReGFormer. To support training ReGuLaR, we construct RGROUNDING-351K, a real-world vision-language dataset annotated with key object bounding boxes and inter-object relations. Extensive experiments across diverse benchmarks show that ReGuLaR consistently outperforms existing approaches and achieves state-of-the-art performance. We include our code in the submission and will release the code and training data publicly upon acceptance.

## 2. 论文提出的方法论
### 核心思想与框架
- 遵循“先思考，后回答”的范式：模型首先在潜在空间中完成若干步推理，每步潜在状态编码一个**“主体‑关系‑客体”三元组**；推理结束后再生成最终答案。
- 训练时引入一个专门的关系基底模块 **ReGFormer**（Relation‑Grounding Transformer），用以将潜在状态对齐到具体的视觉对象和关系；推理时该模块被移除，不增加额外开销。

### ReGFormer 模块细节
- **投影与交叉注意力**：将第 t 步的潜在状态 \(z_t\) 和所有视觉 Token 投影到同一维度的空间，让潜在状态与视觉 Token 做交叉注意力，得到融合视觉信息的推理状态 \(u_t\)。
- **角色感知池化**：
  - 从 \(u_t\) 生成两个查询向量：主体查询 \(q^s_t\) 和客体查询 \(q^o_t\)。
  - 分别与视觉键计算注意力分布，得到主体注意力 \(\alpha^s_t\) 和客体注意力 \(\alpha^o_t\)。
  - 用这两个注意力分布对投影后的视觉 Token 加权求和，得到主体特征 \(c^s_t\) 和客体特征 \(c^o_t\)。
- **关系预测**：拼接 \([c^s_t; c^o_t; u_t]\)，通过一个线性头预测该步对应的**关系标签**（如“in front of”“wearing”等）。

### 训练数据：RG ROUNDING‑351K
- 从多个既有数据集（GQA、OpenImages、CLEVR、Visual Genome、PSG、mGrounding、VSR）收集约 **351K** 样本。
- 每个样本包含：图像、问答对、场景图、对象边界框。训练时从场景图中抽取出**问题相关的**「主体‑关系‑客体」三元组作为监督信号。

### 训练目标
- 使用三种损失联合训练：
  1. **答案生成损失** \(L_{ans}\)：标准的下一个 Token 预测。
  2. **关系预测损失** \(L_{rel}\)：交叉熵，监督 ReGFormer 预测的关系标签。
  3. **注意力对齐损失** \(L_{attn}\)：KL 散度，让预测的主体/客体注意力分布逼近由真实边界框生成的均匀注意力分布。
- 总损失为加权和 \(L = \lambda_{ans} L_{ans} + \lambda_{rel} L_{rel} + \lambda_{attn} L_{attn}\)。

## 7. 优点
- **新颖的方法范式**：首次将“对象关系”作为监督信号，注入到 LVLMs 的潜在推理过程中，填补了组合结构建模的不足。
- **高效的推理方案**：训练时用 ReGFormer 诱导模型学习关系感知的潜在推理，推理时无需外部场景图、对象标注或额外模块，保持了标准的接口和速度。
- **高质量数据贡献**：构建了 351K 级别、包含场景图与边界框的视觉问答训练集，未来可促进更大规模的结构化推理研究。
- **实验扎实全面**：覆盖多类基准和多类对比方法，消融有层次，可视化分析增强了可解释性。

## 8. 不足与局限
- **对监督数据的依赖**：训练需要目标边界框和关系标注，当扩展到更广域时，获取高质量关系监督的成本可能较高。
- **应用场景目前限于静态图像**：方法仅在单张图像和部分多图像任务上验证，尚未扩展到动态视频中的时序关系与交互。
- **潜在风险**：与其他 LVLM 类似，模型仍可能产生错误或过于自信的答案；训练数据继承自公开数据集，可能存在偏见。
- **训练稳定性**：消融实验显示，关系监督的权重过弱或过强都会导致性能下降，实际部署时需要仔细调节超参数。
