## 摘要
“以图像思考”的新兴范式将视觉状态嵌入到中间推理步骤中，为视觉语言模型开辟了新的前沿。现有方法分为两条路线。工具辅助方法应用显式的视觉操作，但存在高延迟和有限的操控类型。潜在推理方法自回归地产生隐式视觉状态，但性能不如工具辅助方法，且其潜在令牌未能捕获有效的视觉信息。在这项工作中，我们提出了DeepLatent，一个用于潜在视觉推理的并行框架。首先，我们引入了LatentFormer。它使用可学习的二维令牌并行生成上下文条件化的潜在状态，将每次视觉更新直接锚定在原始图像特征中。其次，我们设计了一个连续空间强化学习算法。它直接在嵌入空间中优化潜在调制参数，显著提高了潜在表示的质量。该框架通过知识蒸馏和随后的连续空间RL算法进行训练。此外，我们贡献了DeepLatent-180K，一个专为潜在视觉推理设计的大规模数据集。在多个基准上的广泛评估表明，DeepLatent实现了最先进的性能。

## Abstract
The emerging paradigm of "thinking with images" embeds visual states into intermediate reasoning steps, defining a new frontier for Vision-Language Models. Existing approaches diverge along two lines. Tool-assisted methods apply explicit visual operations but suffer from high latency and restricted manipulation types. Latent reasoning methods autoregressively produce implicit visual states, but underperform tool-assisted methods, and their latent tokens fail to capture effective visual information. In this work, we propose DeepLatent, a parallel framework for latent visual reasoning. First, we introduce LatentFormer. It uses learnable 2D tokens to generate context-conditioned latent states in parallel, anchoring every visual update directly in the original image features. Second, we design a continuous-space reinforcement learning algorithm. It optimizes latent modulation parameters directly in the embedding space, significantly improving latent representation quality. The framework is trained via knowledge distillation followed by this continuous-space RL algorithm. Furthermore, we contribute DeepLatent-180K, a large-scale dataset tailored for latent visual reasoning. Extensive evaluations across multiple benchmarks demonstrate that DeepLatent achieves state-of-the-art performance.

## 研究背景与核心问题
该论文聚焦于视觉语言模型中的“用图像思考”范式，即把视觉状态嵌入到中间推理步骤中。现有方法主要分为两类，均存在缺陷：
- **工具辅助方法**：通过外部工具（如执行代码或显式图像操作）实现视觉交互，虽然可解释，但存在推理延迟高、操作类型受限的问题。
- **潜在推理方法**：在模型内部自回归地生成隐式视觉令牌，实现集成化推理，但其性能落后于工具辅助方法，且生成的潜在令牌存在高度同质化、视觉信息含量低的问题。

**核心动机**：解决自回归潜在生成中的两个系统性偏差：
1.  **结构失配**：图像是连续的 2D 场，自回归的一维因果链式生成与图像的空间结构相冲突。
2.  **信息源偏离**：后续潜在令牌过度依赖前序潜在状态，而非原始图像特征，导致视觉-语言对齐能力减弱。

## 方法论
论文提出了 **DeepLatent**，一个并行、上下文条件的潜在推理框架，核心包含两大组件：

- **LatentFormer（并行潜在生成器）**：
    - 当语言模型（LLM）发出 `<latent>` 标记时，触发 LatentFormer，而非让 LLM 自回归生成潜在令牌。
    - 维护一组可学习的二维潜在查询网格 $\mathbf{L}$。
    - 基于当前推理上下文生成的三个调制嵌入（$\mathbf{e}_s$ 控制空间尺度; $\mathbf{e}_l$ 调制查询以驱动视觉搜索; $\mathbf{e}_i$ 调制图像特征以模拟隐式视觉编辑），通过 MLP 预测网格尺寸和仿射变换参数。
    - 对潜在查询和原始图像特征 $\mathbf{I}_0$ 分别施加随机仿射调制（训练时含噪声，推理时跳过），得到 $\tilde{\mathbf{L}}$ 和 $\tilde{\mathbf{I}}$。
    - 通过一个轻量级 Transformer（包含自注意力和与调制后图像特征的交叉注意力），并行细化潜在网格 $\mathbf{Z}$，并将其扁平化后一次性插入 LLM 的输入序列。

- **连续空间强化学习**：
    - 扩展传统的 GRPO（Group Relative Policy Optimization）算法，使其能同时优化离散动作（文本和 `<latent>` 标记生成）和连续动作（调制参数的输出）。
    - 将调制 MLP 输出的高斯分布作为连续动作的策略，计算对数概率和 KL 散度，与文本令牌的离散策略一同更新。

**训练流程**：
1.  **SFT 第一阶段**：在包含交错图文推理轨迹的 **DeepLatent-180K** 数据集上训练基础 VLM（Qwen2.5-VL-7B），并缓存中间助手图像的 LLM 隐藏状态作为“教师视觉状态”。
2.  **SFT 第二阶段**：将轨迹中的助手图像替换为潜在块，通过余弦相似度损失使 LatentFormer 重构缓存的教师状态，同时进行文本生成和潜在尺度监督。
3.  **RL 阶段**：在可验证奖励（准确性+格式奖励）上使用连续空间 GRPO 进行联合优化，冻结视觉编码器和 LatentFormer，仅更新 LLM 和调制 MLP。
