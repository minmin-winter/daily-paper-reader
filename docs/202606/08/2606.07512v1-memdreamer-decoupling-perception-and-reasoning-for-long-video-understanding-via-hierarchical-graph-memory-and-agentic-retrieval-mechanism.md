## 摘要
当前的视觉语言模型在处理数小时长的视频时存在困难，因为处理完整长度的视觉序列会导致难以承受的令牌爆炸和注意力稀释。为了克服这一问题，我们引入了MemDreamer，将感知与推理解耦，将长视频理解转化为一个智能体探索过程。作为一个即插即用的框架，它增量式地流式传输视频以构建一个分层图记忆，这是一种自上而下的三层架构，用于语义抽象，并以一个捕获时空和因果关系的基图为基础。在推理过程中，推理模型采用智能体工具增强的检索，通过观察-推理-行动循环在层次结构中导航、搜索节点以及遍历逻辑边。实验表明，MemDreamer在四个主流基准测试中取得了最先进的结果，将人类专家的差距缩小到仅3.7个百分点。它将推理上下文窗口限制为全上下文消费的仅2%，同时提供了12.5个百分点的绝对准确率提升。此外，统计分析揭示了VLM在逻辑推理和长视频理解基准上的性能之间存在强烈的正线性相关性，将智能体能力扩展确立为多模态理解的新范式。

## Abstract
Current Vision-Language Models struggle with hours-long videos because processing full-length visual sequences induces prohibitive token explosion and attention dilution. To overcome this, we introduce MemDreamer to decouple perception and reasoning, shifting long-video understanding into an agentic exploration process. As a plug-and-play framework, it incrementally streams videos to construct a Hierarchical Graph Memory, a top-down three-tier architecture for semantic abstraction, anchored by a foundational graph capturing spatiotemporal and causal relations. During inference, the reasoning model employs agentic tool-augmented retrieval, navigating hierarchies, searching nodes, and traversing logical edges via an Observation-Reason-Action loop. Experiments show MemDreamer achieves SOTA results across four mainstream benchmarks, narrowing the gap with human experts to only 3.7 points. It constrains the reasoning context window to merely 2% of full-context ingestion while delivering a 12.5 point absolute accuracy gain. Furthermore, statistical analysis uncovers a strong positive linear correlation between an VLM's performance on logic reasoning and long-video understanding benchmarks, establishing agentic capability scaling as a new paradigm for multimodal comprehension.

## 1. 论文的核心问题与整体含义

- **研究动机**：当前视觉语言模型在处理小时级长视频时，全帧采样导致**令牌爆炸**（2小时视频1FPS产生约160万视觉令牌）和**注意力稀释**（“lost in the middle”现象），使得模型无法有效提取关键信息进行推理。现有的端到端范式将感知与推理紧密耦合，加剧了该问题。
- **核心问题**：如何在不增加上下文窗口的前提下，让VLM能够理解数小时视频中的复杂叙事结构、因果关系和细节。
- **整体意义**：提出将长视频理解**重定义为智能体主动探索问题**——通过构建结构化的外部记忆，使推理引擎仅与纯文本记忆交互，从而完全摆脱原始视频令牌的噪音和规模限制。这项工作首次揭示了**VLM的智能体推理能力与长视频性能之间存在强正线性相关**，为多模态理解提供了新范式。

## 2. 方法论

### 2.1 核心思想：解耦感知与推理
- 采用**即插即用框架**，包含两个独立阶段：
  - **记忆构建阶段**：感知模型 \(P\) 流式处理视频，增量构建**纯文本分层图记忆** \(G\)。
  - **推理阶段**：推理模型 \(R\) 通过工具增强的智能体循环仅与 \(G\) 交互，不访问原始视频。
- 推理上下文窗口仅需5–6K令牌，而端到端方法需240–784K。

### 2.2 分层图记忆（Hierarchical Graph Memory）

- **三层粗到细语义拓扑**：
  - **Video Root**：全局根节点，包含标题、描述、主题、关键实体。
  - **Super Events**：中层叙事阶段（10–20个），描述时间范围、关键实体。
  - **Macro Events**：底层事件段，每个包含一个**局部子图**（实体节点 + 微事件节点 + 三种拓扑边）。
- **子图节点与边**（表1）：
  - 节点：**实体**（人物、物体、位置、团体）和**微事件**（带时间戳的动作）。
  - 边分为三类：
    - 空间-属性边（实体↔实体）：位置、相邻、组成等。
    - 主体-客体边（实体↔微事件）：执行、接收、使用工具等。
    - 时间-因果边（微事件→微事件）：因果、阻止、时序等。
- **构建流程**（图3左）：
  1. **流式自适应分割**：使用10分钟滑动窗口，感知模型基于语义边界输出完整的Macro Events，保证语义完整性。
  2. **向下子图提取**：为每个Macro Event解析局部子图 \(g_i\)。
  3. **向上层次聚合**：依据时序和语义相似性，将Macro Events聚类为Super Events，最终得到Video Root。

### 2.3 智能体工具增强检索

- **工具集**（表2）：
  - **层次导航**：GetSummary, GetSuperEvent, GetMacroEvent, GetSubgraph。
  - **精确搜索**：SearchNodes（语义嵌入），SearchByTime（时间区间）。
  - **图遍历**：GetRelationGraph（获取节点邻居及边类型）。
- **观测-推理-行动循环**（ORA Loop）：
  - 每步 \(t\)，模型 \(R\) 根据查询 \(Q\) 和历史轨迹 \(H_{t-1}\) 选择工具并执行，得到观测 \(o_t\)。
  - 模型对观测进行条件性压缩，提取任务相关线索 \(c_t\)，追加到历史 \(H_t\)。
  - 当模型判断信息充足时，输出最终答案。最大轮数 \(T_{max}=12\)。
