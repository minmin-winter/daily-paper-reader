## 摘要
Transformer的复杂度随输入长度呈二次增长，给大型语言模型（LLM）带来了不可持续的计算负载。相比之下，选择性扫描结构化状态空间模型（即Mamba）有效解决了这一计算挑战。本文探索了一种基于查询的跨模态投影器，通过交叉注意力机制根据输入压缩视觉标记，从而增强Mamba在视觉-语言建模中的效率。该创新投影器还消除了在将原始图像特征转换为Mamba LLM输入序列时，手动设计二维扫描顺序的需要。在多个视觉-语言理解基准上的实验结果表明，所提出的跨模态投影器增强了基于Mamba的多模态LLM，提升了性能和吞吐量。

## Abstract
The Transformer's quadratic complexity with input length imposes an unsustainable computational load on large language models (LLMs). In contrast, the Selective Scan Structured State-Space Model, or Mamba, addresses this computational challenge effectively. This paper explores a query-based cross-modal projector designed to bolster Mamba's efficiency for vision-language modeling by compressing visual tokens based on input through the cross-attention mechanism. This innovative projector also removes the need for manually designing the 2D scan order of original image features when converting them into an input sequence for Mamba LLM. Experimental results across various vision-language understanding benchmarks show that the proposed cross-modal projector enhances Mamba-based multimodal LLMs, boosting both performance and throughput.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：Transformer 在多模态大语言模型中存在计算复杂度随输入长度平方增长（O(n²)）的瓶颈，导致处理长序列时计算和内存开销过高。同时，现有基于 Mamba 的多模态 LLM（如 Cobra、VL-Mamba）依赖手动设计的二维图像扫描顺序（如前向/后向/双向），缺乏灵活性，且视觉 token 数量固定，无法动态压缩。
- **整体含义**：本文旨在通过引入一种基于查询（query）的跨模态投影器（Querying Mamba, Q-Mamba），将 Mamba 架构的高效性扩展到视觉-语言理解，实现无需手动扫描顺序、可自适应降采样视觉 token 长度、且与 Mamba LLM 自然对齐的跨模态连接，从而提升性能与吞吐量。

## 2. 论文提出的方法论

### 核心思想
- 采用 **Q-Former** 风格的可学习查询（learnable queries）与视觉特征通过交叉注意力交互，将二维图像特征投影为一维因果 token 序列，供 Mamba LLM 使用。
- 利用 Mamba 的序列建模层和交叉注意力交替堆叠，实现视觉信息的动态压缩与对齐。

### 关键技术细节

## 6. 论文的主要结论与发现

- Q-Mamba 在所有 6 个基准上一致优于 Cobra 和 VL-Mamba，展示了基于查询的投影器在 Mamba 多模态 LLM 中的有效性。
- 增加查询数量（128→256→512→729）通常提升性能，但收益递减；某些任务（VizWiz, POPE）上更长查询可能引入冗余信息导致轻微下降。
- 局部注意力优于全局注意力。
- 使用预训练的双向 Mamba 连接器（来自 VL-Mamba）比随机初始化更好。
- 推理时仅使用前向扫描（而非双向）性能不减甚至提升，表明 Q-Mamba 对扫描顺序不敏感。
- Q-Mamba 通过动态降采样视觉 token 长度显著提高吞吐量（例如 729 查询时每秒推理迭代 0.147 s，优于 Cobra 的 0.129 s 和 VL-Mamba 的 0.152 s）。

## 7. 优点

- **创新性**：首次将基于查询的跨模态投影（类似 Q-Former）引入 Mamba 架构，摆脱手动扫描顺序，实现自适应 token 压缩。
- **效率**：动态降采样视觉 token 长度，降低 LLM 后端计算负担，提升训练和推理吞吐量。
- **可解释性/可控性**：查询数量可调，提供性能与速度的灵活权衡。
- **实验公平**：在相同代码库和实验条件下复现 Cobra 和 VL-Mamba，确保公平比较。

## 8. 不足与局限

- **数据集规模有限**：仅使用 595K+655K+220K+400K 数据训练 1 epoch，对比其他 Transformer 类 MLLM（如 LLaVA-1.5 训练 2 epoch）可能不足，限制泛化能力。
- **Mamba 遗忘问题**：Mamba 的循环特性可能导致长序列时“遗忘”早期信息，论文未充分分析或解决。
- **预训练不足**：Q-Mamba 未经过类似 Q-Former 的图像-文本对比学习预训练，初始化仅依赖随机或小参数 Mamba 权重，可能影响对齐质量。
- **实验覆盖有限**：仅评估图像-文本任务，未涉及视频/语音/3D 等多模态场景；未测试更大规模 Mamba LLM（如 7B 参数）。
- **潜在风险**：模型规模（>1B 参数）可能加剧计算资源不平等，且存在大模型幻觉风险。
