## 摘要
近年来，在单一架构内同时处理多模态理解和生成的统一视觉-语言模型取得了显著进展。尽管自回归VLM能够跨模态推理，但它们无法生成高质量图像。相比之下，扩散模型能生成逼真的视觉效果，但在生成连贯文本方面存在困难，这使得开发一个能无缝处理视觉和文本生成的单一统一模型具有挑战性。最近的研究表明，语言可以有效地嵌入到视觉表示中，使模型能够直接从图像中推理文本语义。为此，我们提出了UniCanvas，这是首次尝试通过文本内图像生成来统一扩散模型以生成交错多模态内容。扩散模型自然地捕捉共享像素画布上的变换，这可以看作视觉变化的世界模型。该模型不是生成离散的文本标记，而是学习将语言表示为图像内部的视觉模式，利用其固有的多模态嵌入空间。这种设计使得模型在图像合成过程中能够在单个像素画布上自然地"绘制"文本，从而实现无缝的多模态生成。实验表明，UniCanvas在性能上优于以前的统一模型，将扩散模型的文本内图像生成定位为一种有前途的统一多模态生成范式。

## Abstract
Recent years have seen remarkable progress in unified vision-language models handling both multimodal understanding and generation within a single architecture. While autoregressive VLMs can reason across modalities, they fail to generate high-quality images. In contrast, diffusion models produce photorealistic visuals yet struggle to generate coherent text, making it challenging to develop a single unified model that can seamlessly handle both visual and text generation. Recent advances suggest that language can be effectively embedded within visual representations, allowing models to reason about textual semantics directly from images. To this end, we propose UniCanvas, a first attempt that unifies diffusion models to generate interleaved multimodal contents through text-in-image generation. Diffusion models naturally capture transformations on a shared pixel canvas, which can be viewed as world models of visual change. Instead of producing discrete text tokens, the model learns to represent language as visual patterns inside images, leveraging its inherent multimodal embedding space. This design allows the model to "draw" text naturally within a single pixel canvas during image synthesis, achieving seamless multimodal generation. Experiments demonstrate that UniCanvas improves performance over previous unified models, positioning text-in-image generation with diffusion models as a promising unified multimodal generation paradigm.

## 2. 方法论

### 核心思想
- 将文本与视觉统一到同一个**像素级画布（pixel canvas）**上，语言不再表示为离散词元，而是作为光学字符直接渲染在图像中。
- 扩散模型本身可以看作视觉变换的“世界模型”，通过流动匹配（flow matching）学习从当前画布到下一个状态画布的变换。
- 采用**两阶段生成**：第一阶段进行视觉推理（在画布上“写”文本），第二阶段进行视觉合成（根据文本更新场景）。

### 关键技术细节
1. **文内图像生成**：给定输入图像 \(x\)，目标画布 \(x^{\text{text}}_0\) 是在图像中光学渲染了文本的版本。使用流动匹配损失：
   \[
   L^{\text{text}}_{\text{FM}} = \mathbb{E}_{t, x, x^{\text{text}}_0} \left[ \| v_\theta(x_t, t, c_{\text{reason}}) - (x^{\text{text}}_0 - x) \|^2 \right]
   \]
   其中 \(c_{\text{reason}}\) 是推理提示。

2. **两阶段生成流程**：
   - **Stage 1（视觉推理）**：从当前图像 \(x\) 开始，通过上述流动匹配生成文本增强的画布 \(\hat{x}^{\text{text}}_0\)。
   - **Stage 2（视觉合成）**：从 \(\hat{x}^{\text{text}}_0\) 开始，使用执行提示 \(c_{\text{exec}}\) 进行第二次流动匹配，生成下一状态画布 \(\hat{x}^{\text{state}}_0\)。
   - 多步任务中重复上述两步，得到可解释的轨迹。

3. **CLIP对比正则化**：引入额外的 \(L_{\text{CLIP}}\)，鼓励渲染的文本在语义上与提示对齐，不更新CLIP本身。

4. **预训练**：在LLaVA-Instruct-150K（VQA数据）和通用图像编辑数据上预训练，使模型学会在图像中写文本，同时保留视觉编辑能力；使用LPIPS感知损失稳定文字区域。

5. **总损失**：
   \[
   L_{\text{total}} = L^{\text{text}}_{\text{FM}} + L^{\text{state}}_{\text{FM}} + \lambda_{\text{CLIP}} L_{\text{CLIP}}
   \]

## 7. 优点

- **方法创新性**：首次提出纯扩散模型实现文本和图像在共享画布上的统一生成，避免了离散词元与像素之间的转换，保持表示一致性。
- **两阶段流水线**：巧妙地将推理和渲染解耦，共享同一骨干网络，降低优化难度。
- **轻量级对齐损失**：利用冻结的CLIP提供语义监督，不增加额外参数，显著改善文字质量。
- **预训练设计**：在VQA数据上预训练“写文字”能力，既保持编辑能力又学习渲染文本，为下游微调提供强初始化。

## 8. 不足与局限

- **长文本生成可靠性低**：模型不擅长生成多句解释性文本，易出现字符混淆或语义偏离。
- **视觉合成误差累积**：在长序列（如6×6网格）中，视觉预测偏差会导致后续步骤脱离正确轨迹，最终失败。
