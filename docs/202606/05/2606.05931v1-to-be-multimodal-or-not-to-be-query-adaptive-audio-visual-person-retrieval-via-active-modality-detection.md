## 摘要
当通过语音和人脸从视频档案中检索人物时，系统应该采用多模态吗？在现实世界的广播档案中，与精心策划的基准不同，目标可能只闻其声不见其人、只见其人未闻其声，或者两者兼而有之。融合缺失模态的分数会引入噪声，导致精度低于最佳的单模态系统。我们提出了一种查询自适应框架，通过跨模态分数一致性来检测活跃模态：当两种模态都活跃时，通过一种模态检索到的文件在另一种模态上也获得高分；当一种模态缺失时，这种一致性被破坏。由这些跨模态特征驱动的分类器实现了89%的检测准确率。在BBC Rewind语料库（包含超过12,000个广播视频）上，自适应系统达到了94.2%的P@1，优于仅说话人（82.9%）、仅人脸（93.4%）和固定融合（90.0%），并恢复了与具有真实模态标签的oracle（96.6%）之间差距的64%。

## Abstract
When retrieving a person from a video archive by voice and face, should the system be multimodal or not? In real-world broadcast archives, unlike curated benchmarks, a target may be heard but unseen, seen but unheard, or both. Fusing scores from an absent modality injects noise, degrading precision below the best unimodal system. We propose a query-adaptive framework that detects active modalities via cross-modal score consistency: when both modalities are active, files retrieved by one also score highly on the other; this agreement breaks down when a modality is absent. Classifiers driven by these cross-modal features achieve 89% detection accuracy. On the BBC Rewind corpus (with over 12,000 broadcast videos) the adaptive system attains 94.2% P@1, outperforming speaker-only (82.9%), face-only (93.4%), and fixed fusion (90.0%), recovering 64% of the gap to an oracle with ground-truth modality labels (96.6%).

- **核心问题**：在真实世界的广播视频档案中检索特定人物时，是否应该使用多模态（音频+视觉）融合？当目标人物的某一模态缺失（只闻其声不见其人，或只见其人未闻其声）时，固定的多模态融合反而引入噪声，导致检索精度低于最佳单模态系统。
- **研究背景**：现有基准测试（如VoxCeleb）精心策划，确保每个片段目标同时出现声音和人脸。但真实广播档案（如BBC Rewind语料库）中，人物可能仅语音出现（AoP）、仅视觉出现（VoP）或两者兼有（AVP）。早期多模态检索工作（如MVSE框架）假设模态总是同时可用，忽略了模态缺失问题。
- **整体含义**：提出查询自适应框架，通过检测当前查询的活跃模态，动态决定是否进行多模态融合，从而避免噪声注入，显著提升检索精度。

## 2. 论文提出的方法论

- **核心思想**：利用**跨模态分数一致性**作为模态是否活跃的诊断信号。当两种模态都活跃时，一种模态检索到的文件在另一种模态上也会获得高分；当某一模态缺失时，这种一致性被破坏。
- **关键技术细节**：
  - **特征设计**：对于每个查询，分别用说话人嵌入和人脸嵌入检索档案，取top-n个文件。提取四类分数向量：
    - 模态内分数（ss, sf）：本模态检索到的文件的余弦相似度。
    - 跨模态分数（cs→f, cf→s）：用本模态的检索集去查另一模态的分数。
    - 每个向量的均值和标准差（μ, σ）。
    - 最终特征向量维度为 4n+8（n=10时为48维）。
  - **分类器**：采用逻辑回归（LogReg）、线性SVM（SVM-L）、RBF核SVM（SVM-R）、决策树（DT）对查询分类为{AoP, VoP, AVP}。
  - **融合策略**：根据分类结果设置融合权重λ：λ=1（AoP，仅用说话人）、λ=0（VoP，仅用人脸）、λ=0.5（AVP，等权融合）。
- **算法流程**（文字说明）：
  1. 对查询视频提取说话人嵌入 e_spk 和人脸嵌入 e_face。
  2. 分别计算与档案中所有文件的余弦相似度，得到每个文件的说话人分数 s_spk 和人脸分数 s_face。
  3. 取每个模态的top-n文件，构建上述特征向量。
  4. 用训练好的分类器判断活跃模态类型。
  5. 根据类型选择λ，进行分数级融合，得到最终排名。
