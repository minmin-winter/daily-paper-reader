## 摘要
近期，通过二维视觉语言模型（VLM）实现零样本3D场景理解因其具有前景的空间推理能力而受到越来越多的研究关注。通常，从3D点云中采样多个二维视图，并输入预训练的VLM以回答给定问题。这一范式凸显了输入上下文质量的关键作用，并提出了在有限输入预算下尽可能保留与任务相关的3D细节的挑战。我们提出\texttt{KeyVT}，一种在视图和令牌两个层次上进行输入上下文收集的层次化方法。具体来说，我们将像素特征与相机参数相结合，并基于语义内容和几何位置评估视图重要性，从而得到空间一致且与任务相关的视图。此外，我们通过最优传输（OT）框架识别代表性令牌来解决所选视图中补片间的冗余问题，其中视图令牌和关键令牌被表述为嵌入空间中的两个离散分布。这些关键令牌期望通过最小化OT距离来覆盖所有视图特征。我们在三个广泛使用的基准上评估我们的框架，显示出相对于现有无调优方法的显著改进，并且性能与基于训练的方法相当。

## Abstract
Recently, zero-shot 3D scene understanding via 2D Vision-Language Models (VLMs) has gained increasing research interest due to their promising spatial reasoning capabilities. Typically, multiple 2D views are sampled from a 3D point cloud and fed into pre-trained VLMs to answer a given question. This paradigm highlights the critical role of input context quality and raises the challenge of retaining as many task-relevant 3D details as possible under a limited input budget. We propose \texttt{KeyVT}, a hierarchical approach for input context collection at both the view and token levels. Specifically, we combine pixel features with camera parameters and assess view importance based on both semantic content and geometric position, resulting in spatially consistent and task-relevant views. Furthermore, we address redundancy among patches across selected views by identifying representative tokens under the optimal transport (OT) framework, where view tokens and key tokens are formulated as two discrete distributions in the embedding space. These key tokens are expected to cover all view features by minimizing the OT distance. We evaluate our framework on three widely used benchmarks, demonstrating significant improvements over existing tuning-free methods and performance comparable to training-based approaches.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究问题**：零样本3D问答（Zero-Shot 3D Question Answering）任务，即在不经过3D数据微调的情况下，利用预训练的2D视觉语言模型（VLM）理解3D场景并回答关于场景的问题。
- **挑战**：通常方法是从3D点云中采样多个2D视图输入VLM，但受制于输入预算（如令牌数量限制），难以同时保留足够多的与任务相关的3D细节，且视图间存在严重语义冗余。
- **动机**：现有方法多关注视图与问题的语义相似性，忽略了空间几何一致性；且仅进行视图级选择，未在令牌级压缩冗余。作者提出层次化输入上下文收集方法，同时利用语义和几何信息选择关键视图，并进一步通过最优传输（OT）压缩令牌，以在有限预算下保留最丰富的任务相关信息。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：分两步优化输入上下文：
    1. **KeyV（几何感知的关键视图选择）**：结合视觉语义和相机几何参数，将场景分割为空间一致的子场景，并根据子场景与问题的相关性分配视图数量，选择空间连续且任务相关的关键视图。
    2. **KeyT（最优传输引导的关键令牌选择）**：在已选关键视图的所有令牌中，构造虚拟令牌集合，通过最小化与真实视图令牌分布之间的最优传输距离，学习代表所有视图特征的紧凑令牌集；再根据传输计划选择与虚拟令牌最相关的真实令牌作为最终输入。
- **关键技术细节**：
    - **视图距离定义**：基于相机位置和平移计算视图间距离，包括位置差异和方向角差异，用于窗口分割子场景。
    - **子场景重要性评分**：使用预训练BLIP2计算每个子场景对问题的语义相关性（取最大值和平均值），结合子场景大小加权分配要采样的视图数。
    - **最优传输（OT）**：将视图令牌和虚拟令牌视为两个离散分布，使用Sinkhorn距离进行差分优化，更新虚拟令牌；传输计划矩阵的列概率用于选择与每个虚拟令牌最邻近的真实令牌。
    - **整体流程**：输入所有2D视图 → KeyV选择K个关键视图 → KeyT压缩为M个虚拟令牌（M < 所有令牌数） → 根据传输计划选取真实令牌 → 作为VLM的输入，连同问题生成答案。

## 6. 主要结论与发现

- **KeyVT在三个基准上均取得最优零样本性能**，在绝大多数指标上超越现有无调优方法（如AKS, DivPrune, FLoC），并可与需要微调的方法（如cdViews, Video-3D）相媲美。
- **层次化策略有效**：几何感知的视图选择（KeyV）优于纯语义/时序方法（如AKS）；OT引导的令牌压缩（KeyT）在多个压缩率下优于基于聚类或多样性的方法（DivPrune, FLoC）。
- **鲁棒性良好**：对相机参数噪声容忍度高（5%噪声仍超越基线），且使用VGGT估计参数也取得相近性能。
- **可视化分析**：关键视图和关键令牌重建的子场景能保留任务相关区域的整体几何与语义结构，t-SNE显示关键令牌覆盖原始令牌分布。

## 7. 优点

- **无需训练或微调**：KeyV和KeyT均为无训练方法，仅需少量迭代优化虚拟令牌，极大降低计算和数据门槛。
- **即插即用**：可作为预处理模块直接应用于现有VLM，不改变模型结构，易于迁移至不同VLM骨干。
- **高效利用输入预算**：同时考虑视图级和令牌级冗余，在同等预算下允许输入更多任务相关细节，提升推理质量。
- **几何与语义融合**：引入相机几何信息进行空间一致性子场景划分，优于仅依赖语义相似度的传统方法。
- **OT理论提供可解释性**：传输计划矩阵可直观指示每个虚拟令牌与真实令牌的对应关系，方便定位重要区域。

## 8. 不足与局限

- **实验覆盖的局限性**：仅在室内场景基准（ScanNet系列）上评估，未涉及室外场景或大规模3D数据集（如Matterport3D）；VSI-Bench包含部分第一人称视频，但本质上仍是扫描得到的场景。
- **密集场景或模糊空间关系时失效**：失败案例（图6）显示，在物体密集或空间关系表述模糊时，关键令牌可能误选，导致答案错误。
- **依赖相机参数**：虽能使用VGGT估计，但参数不准确仍会轻微影响性能（10%噪声下降约2个CIDEr点），且VGGT本身也需资源。
- **计算效率**：KeyT的OT优化迭代需要约1.4s/样本，虽快于FLoC但慢于DivPrune，在端到端实时系统中仍有优化空间。
- **仅限问答任务**：当前工作在3D-QA上验证，其是否适用于更广泛的3D理解任务（如描述、检测、定位）有待进一步探索。
