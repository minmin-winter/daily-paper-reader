## 摘要
视觉-语言模型（VLM）为文本和视觉信息提供了统一的表示空间，然而它们作为图结构数据通用骨干的潜力在很大程度上尚未被探索。在实践中，属性图表现出显著的模态异质性：一些图仅包含文本节点属性，另一些仅包含视觉属性，还有一些同时提供两种属性。现有的图学习方法通常针对固定的模态模式设计，需要为不同的设置使用单独的模型，限制了可扩展性和跨图泛化能力。为弥补这一差距，我们提出了OMG-VLM（One Model, Many Graphs with Vision-Language Models），一个用于跨异构模态模式学习属性图的统一框架。OMG-VLM利用预训练的VLM作为共享骨干，并引入结构感知的图适配器，这些适配器整合邻域信息，同时保持与VLM原生嵌入空间的兼容性。这种设计使得单个模型能够有效地在文本属性图、图像属性图和多属性图上进行学习。跨多个领域的广泛实验表明，OMG-VLM在节点分类和链接预测等属性图学习任务上始终优于基于GNN和基于LLM的最先进基线，同时展现出对未见图及不同模态模式的强泛化能力。源代码可在https://github.com/Jo-eyang/OMG-VLM获取。

## Abstract
Vision-language models (VLMs) provide a unified representation space for textual and visual information, yet their potential as general-purpose backbones for graph-structured data remains largely unexplored. In practice, attributed graphs exhibit substantial modality heterogeneity: some graphs contain only textual node attributes, others only visual attributes, while still others provide both. Existing graph learning approaches are typically designed for fixed modality schemas, requiring separate models for different settings and limiting scalability and cross-graph generalization. To bridge this gap, we present OMG-VLM (One Model, Many Graphs with Vision-Language Models), a unified framework for learning over attributed graphs across heterogeneous modality schemas. OMG-VLM leverages a pretrained VLM as a shared backbone and introduces structure-aware graph adapters that integrate neighborhood information while remaining compatible with the VLM's native embedding space. This design enables effective learning over text-attributed, image-attributed, and multi-attributed graphs within a single model. Extensive experiments across diverse domains show that OMG-VLM consistently outperforms state-of-the-art GNN- and LLM-based baselines on attributed graph learning tasks such as node classification and link prediction, while exhibiting strong generalization to unseen graphs and varying modality schemas. The source code is available at https://github.com/Jo-eyang/OMG-VLM.

## 2. 方法论

- **核心思想**：利用预训练VLM（Qwen-VL-7B）的共享嵌入空间（其分词器和视觉编码器原生对齐文本和图像），在其基础上注入图结构信息，设计**结构感知的图适配器**，使VLM能够理解图上下文而不破坏其原有表示空间。
- **关键技术细节**：
    1. **目标感知文本聚合（Target-Aware Textual Aggregation）**：
        - 使用VLM自身的token embedding对目标文本和邻居文本进行嵌入，形成邻居文本token库。
        - 引入可学习查询token（M_T个），与目标文本嵌入拼接后通过RoPE自注意力生成目标条件查询。
        - 通过多头交叉注意力从邻居token库中检索与目标最相关的文本信息，输出紧凑的聚合文本token序列。
    2. **图感知视觉表示学习（Graph-Aware Visual Representation Learning）**：
        - **逐邻居压缩**：每个视觉邻居图像先经VLM自带ViT提取patch序列，再用可学习视觉查询（M_I个）通过交叉注意力压缩到少量token（M_I远小于原始LI），形成压缩后的视觉邻居token库。
        - **中心条件视觉融合**：目标图像token通过L层交叉注意力逐步聚合压缩后的邻居token，更新目标视觉表示，保持与原始token长度一致，避免增加下游序列长度。
    3. **统一输入构建**：将处理后的文本适配器输出、视觉适配器输出与任务指令嵌入拼接，直接送入VLM backbone进行自回归生成。
- **训练策略**：
    - 冻结VLM的视觉编码器和分词器，仅通过**LoRA**微调VLM Transformer骨干，同时从头训练两个图适配器。
    - 采用**端到端联合优化（co-optimization）**，所有可训练参数在同一生成目标下更新：  
      \[
      \mathcal{L}(\Theta)=\mathbb{E}_{z\sim D}\left[\sum_{t=1}^{|Y|}\log P_{\text{VLM}}(y_t\mid y_{<t}, X_v; \Theta)\right]
      \]
    - 训练数据混合多种模态的图（TAG、IAG、MAG），使模型学会适应不同模态模式。

## 6. 主要结论与发现

- OMG-VLM在**所有域内基准**及**大多数跨域转移基准**上取得最高或次高准确率，说明统一VLM框架能够有效处理异构模态属性图，且具备强泛化能力。
- 图适配器的设计至关重要：简单池化（均值和中心查询注意力）替换适配器会导致显著性能下降（如RedditS LP下降>22%）。
- 逐邻居图像压缩可在几乎不损失精度的情况下减少约75% FLOPs，实现可扩展的视觉邻居聚合。
- 端到端联合优化优于两阶段训练，且更省时，说明图结构理解和生成推理能相互适应。
- 超参数（文本/视觉token数、邻居数）在合理范围内变化时性能稳定，表明方法鲁棒。
