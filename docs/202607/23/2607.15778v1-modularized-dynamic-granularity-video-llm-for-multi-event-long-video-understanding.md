## 摘要
视频大语言模型在各种视频理解任务中取得了显著进展。然而，长视频场景仍然具有挑战性，因为有限的视觉令牌预算与捕获多个关键事件的需求之间存在矛盾。现有方法通常分两个阶段处理长视频，即：i) 选择关键帧，ii) 执行详细感知，这些方法存在局限性：缺乏自适应容量分配和自我纠正的模块化机制，导致建模不可靠。为了解决这些挑战，我们提出了MoD-VLLM，一种新颖的模块化动态粒度视频大模型框架，用于多事件长视频理解，该框架以迭代和自我反思的方式统一了时间定位和语义理解。具体来说，我们提出了一个正负视频片段定位模块和一个模块化动态粒度反思模块，它们形成一个闭环，逐步定位与问题相关的视频片段。定位模块指导视频大模型根据视频问题区分相关和不相关的视频片段。反思模块采用模块化调度器，动态选择细粒度编码用于相关的正片段以捕获详细感知，以及粗粒度编码用于负片段以维持全局上下文。我们还提出了一种动态粒度强化学习策略，使MoD-VLLM能够联合学习最优定位策略和动态粒度视觉表示。此外，我们提出了MEventBench，一个具有挑战性的多事件长视频基准，用于复杂的长期视频推理。在多个长视频理解基准和我们的MEventBench上进行的大量实验表明，MoD-VLLM显著优于最先进的基线方法。

## Abstract
Video Large Language Models (Video LLMs) have made significant advancements in various video understanding tasks. However, long-video scenarios remain challenging due to the tension between limited visual token budgets and the need to capture multiple key events. Existing approaches typically process long videos in two stages, i.e., i) select keyframes and ii) perform detailed perception, which exhibit limitations: they lack a modular mechanism for adaptive capacity allocation and self-correction, resulting in unreliable modeling. To tackle these challenges, we propose MoD-VLLM, a novel Modularized Dynamic-Granularity Video LLM framework for multi-event long video understanding, which unifies temporal grounding and semantic understanding iteratively and self-reflectively. Specifically, we propose a Positive-Negative Video Segments Grounding module and a Modularized Dynamic-Granularity Reflection module, which form a closed loop to progressively localize the question-related video segments. The grounding module instructs a Video LLM to distinguish relevant from irrelevant video segments based on the video question. The reflection module employs a modularized scheduler that dynamically selects fine-grained encoding for relevant positive segments to capture detailed perception and coarse-grained encoding for negative segments to maintain global context. We further propose a dynamic-granularity reinforcement learning strategy, allowing MoD-VLLM to learn optimal grounding policies and dynamic granularity visual representation jointly. Moreover, we propose MEventBench, a challenging Multi-Event Long Video Benchmark for complex long video reasoning. Extensive experiments on several long video understanding benchmarks and our MEventBench demonstrate that MoD-VLLM significantly outperforms state-of-the-art baselines.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：长视频理解面临根本性矛盾——有限的视觉 token 预算与需要捕获多个分散关键事件之间的矛盾。现有处理长视频的方法存在两大缺陷：
  - **Token 压缩/帧采样方法**（如 LongVU、MovieChat）忽略不同视频片段的语义重要性差异，导致关键细节丢失。
  - **两阶段粗到细方法**（如 VideoTree、AKS）先定位关键帧再详细理解，但缺乏自我反思和错误纠正机制，初始定位错误会不可逆传播。
- **整体含义**：需要一种能自适应分配建模容量（即对不同重要性的片段给予不同粒度）且具备自我校正能力的方法，以实现多事件长视频的可靠理解。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：提出 MoD-VLLM（Modularized Dynamic-Granularity Video LLM），通过“正-负视频片段定位”与“模块化动态粒度反思”形成闭环迭代，逐步精确地定位与问题相关的视频片段，并动态分配编码粒度（正片段细粒度、负片段粗粒度），最后联合优化定位策略和粒度表示。

- **关键技术细节**：

  - **正经化-负视频片段定位模块**：
    - 输入：长视频均匀采样 N 帧，视觉编码器提取每帧特征，同时计算每帧全局特征与问题嵌入的余弦相似度。
    - 结构化输入模板：连接指令文本、视觉 token 序列、帧-问题相似度序列、任务提示，送入 Video LLM。
    - 输出：以 JSON 格式的定位策略，即问题相关片段的起止时间列表，这些片段被标记为“正片段”，其余为“负片段”。

  - **模块化动态粒度反思模块**：
    - 预定义多个编码模块（粗/中/细粒度），通过微调投影层实现不同 token 产生率（36、64、169 tokens/帧）和不同采样率。
    - 模块化调度器：根据正片段比例 ρ 和 token 预算 Lmax，通过公式（6）计算正、负片段的目标粒度级别，并选择对应模块。若 token 超出上限，优先降级负片段粒度，必要时降级正片段；若远低于上限，优先升级正片段粒度。优化目标为最大化正片段 token 权重与负片段 token 权重的差值，受 token 预算约束。
    - 生成动态粒度 token 序列 Z'，替代原始均匀粒度 token，重新输入定位模块进行下一轮迭代。

  - **动态粒度迭代与强化学习**：
    - 每次迭代：用上一轮的动态粒度 token 进行新一轮定位，得到更精确的定位策略。
    - 第一轮额外生成反事实 token 序列 Z''（正负分类反转），用于合并定位结果以减少错误传播。
    - **动态粒度强化学习**：对每个视频，让 Video LLM 生成多个候选定位策略（通过提示、反事实增强、随机种子保证多样性）。每个策略对应的动态 token 序列输入 Video LLM 计算交叉熵损失，将损失最小的策略视为正样本，损失较大的视为负样本，使用直接偏好优化（DPO）更新 Video LLM。DPO 与动态表示学习的 SFT 交替进行。

- **MoD-VLLM 在所有长视频 benchmark 上均优于同等规模的最先进方法**，在 VideoMME 长视频子集上达到 66.9%，在 MEventBench 上达到 64.8%，分别比最强基线 Qwen2.5-VL 高 4.3% 和 4.0%。
