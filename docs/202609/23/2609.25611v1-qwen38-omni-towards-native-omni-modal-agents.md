## 摘要
我们推出 Qwen3.8-Omni-Flash，一个面向真实世界多模态生产力的原生多模态智能体模型。与以往主要强调感知与交互的全能模型相比，Qwen3.8-Omni-Flash 显著提升了多模态理解与推理能力，以及在长时程智能体任务上的表现。这些能力得益于一种原生多模态协同训练策略：该策略在保持强文本领域能力的同时，促进智能体能力从文本任务向音频和视频任务迁移。该模型继承了 Qwen3.8-Next 的稀疏混合专家（MoE）架构，并将上下文窗口扩展至 100 万 token，支持长上下文多模态推理和长时程规划。这些进展使其能够作为主智能体或专用子智能体集成到生产工作流中，支持视频编辑、长音频与视频翻译、以音乐为条件的音乐视频或电影生成，以及基于视频的笔记或全技能创建。为解决现有智能体运行框架缺乏原生音频和视频支持的问题，我们发布了 Qwen-MM-Plugins，一个面向多模态生产力的轻量级开源插件框架。我们进一步将实时多模态交互视为一项系统级挑战，需要编排上下文与记忆管理、工具使用以及子智能体委派。因此，我们发布了 Qwen-Live-Harness，一个基于 Qwen3.8-Omni-Flash 构建响应式实时多模态智能体的开源框架。大量评估表明，Qwen3.8-Omni-Flash 在多模态理解、推理、长时程智能体执行以及视频生产力任务上均取得了强劲表现。这些结果及配套开源工具为 Qwen3.8-Omni-Flash 作为在研究与生产环境中部署原生多模态智能体的实用基础提供了支撑。

## Abstract
We introduce Qwen3.8-Omni-Flash, a natively multimodal agentic model for real-world multimodal productivity. Compared with previous omni models, which primarily emphasized perception and interaction, Qwen3.8-Omni-Flash substantially improves multimodal understanding and reasoning, as well as performance on long-horizon agentic tasks. These capabilities are supported by a native multimodal co-training strategy that preserves strong text-domain capabilities while facilitating the transfer of agentic capabilities from text to audio and video tasks. The model inherits the sparse mixture-of-experts (MoE) architecture of Qwen3.8-Next and extends the context window to one million tokens, supporting long-context multimodal reasoning and long-horizon planning. These advances enable integration into production workflows as a primary agent or a specialized sub-agent, supporting video editing, long-form audio and video translation, music-conditioned music video or movie generation, and video-based note or omni-skill creation. To address the lack of native audio and video support in existing agent harnesses, we release Qwen-MM-Plugins, a lightweight open-source plugin framework for multimodal productivity. We further frame real-time multimodal interaction as a system-level challenge requiring orchestration of context and memory management, tool use, and sub-agent delegation. Accordingly, we release Qwen-Live-Harness, an open-source framework for building responsive, real-time multimodal agents based on Qwen3.8-Omni-Flash. Extensive evaluations demonstrate that Qwen3.8-Omni-Flash achieves strong performance across multimodal understanding, reasoning, long-horizon agentic execution, and video productivity tasks. These results and the accompanying open-source tools support Qwen3.8-Omni-Flash as a practical foundation for deploying natively multimodal agents in research and production.

- **核心问题**：面向视频中心的多模态生产力工作流（如智能体视频编辑、音乐视频创作、电影制作）缺乏支持，这类任务不仅需要多模态感知，还需要全局规划、时序推理，以及对生成内容连贯性与质量的评估。
- **三大挑战**：
  - 视频输入存储与传输成本高、token 预算大，长视频在智能体工作流中处理昂贵。
  - 多数现有智能体运行框架（harness）不支持在主模型上下文中流式处理音频与视频。
  - 面向生产力的全模态模型应用仍未被充分探索。
- **整体含义**：论文提出 Qwen3.8-Omni-Flash，试图将全模态模型从“感知与交互”推进到“真实多模态生产力”，使模型可作为主智能体或专用子智能体嵌入生产工作流，并配套开源 Qwen-MM-Plugins 与 Qwen-Live-Harness，形成模型能力与系统基础设施协同推进的实践基础。

## 2. 方法论

### 2.1 核心思想

- 采用**原生多模态协同训练**：在保持强文本能力的同时，将文本域中的推理与智能体能力迁移到音频、视频任务。
- 继承 Qwen3.8-Next 的**稀疏混合专家（MoE）**语言骨干，上下文扩展至 **100 万 token**，支持长上下文多模态推理与长时程规划。
- 采用 Qwen-Omni 家族的 **Thinker-Talker 统一架构**：Thinker 负责多模态理解、推理、对话与工具使用；Talker 负责流式语音生成。

### 2.2 架构与关键技术细节

- **Thinker 骨干**：
  - 混合稀疏 MoE 语言模型，稀疏专家激活提升容量并控制每 token 前馈计算量。
  - Token 混合结合 **Gated DeltaNet（GDN）**（以固定大小循环状态总结前文）与交错注意力层（直接访问上下文 token）。
  - 注意力层经 warmup 与稀疏训练阶段过渡到 **Qwen Sparse Attention（QSA）**：轻量 indexer 对压缩微块表示打分，选择相关上下文块，核心注意力仅在选中块内的原始 token 上计算。
  - 预训练原生上下文窗口 **256K token**，后训练后扩展至 **1M token**。
- **多模态编码器**：
  - **视觉编码器**：来自 Qwen3.8-Next，处理图像与采样视频帧。
  - **通用 AuT 编码器**：4 个 Conv2D 块下采样 16 倍，后接时间自注意力；输出 token 频率 **6.25 Hz**（约每 160 ms 一个 token）；在超过 20 种语言的音频语料上预训练，中/英/其他比例约 3.5:3.5:3。
  - **Spatial AuT 编码器**：处理多通道空间音频，先转为**一阶 Ambisonics（FOA）**格式，再对 FOA 通道的复数 STFT 处理，保留实部与虚部以保留通道间幅度与相位关系，从而编码声源方向、距离与运动等空间线索。
  - 三类编码器输出经模态适配器投影到语言骨干共享表示空间，并在预训练 S1 阶段与骨干对齐。
- **时间与位置建模**：
  - 音频、空间音频、视频表示均包含显式时间信息，文本时间戳直接暴露给语言骨干。
  - 空间音频嵌入的位置 ID 类似视频帧内不同空间位置的视觉 patch：同一时间切片共享时间索引，但保留不同空间位置索引。
