## 摘要
潜在视觉推理旨在通过隐状态计算而非显式的文本思维链来执行多模态推理。然而，视觉信息存在于潜在状态中，并不意味着模型在生成答案时实际依赖该状态，尤其当其他以图像为条件的路径仍然可用时。我们提出因果视觉循环推理（Causal Visual Recurrent Reasoning, CVRR），它在保留预训练视觉能力的同时，使循环计算成为预测所必需的、以图像为条件的路径。CVRR 在预训练视觉-语言模型已整合图像后，从问题隐状态初始化循环，并在反复读取同一固定视觉证据的同时反复更新该状态。在解码之前，视觉状态和原始多模态 KV 缓存被移除，从而只有最终循环状态将图像条件信息携带到答案中。在 V*、MMVP、BLINK 和 MME-RealWorld-Lite 基准上，CVRR 在这种严格接口下仍保持强劲性能，而兼容的潜在推理器即使在相同约束下重新训练，也无法恢复可比的视觉能力。因果干预进一步表明，当问题固定时，预测仍对循环内容敏感，并且持续存在的视觉证据会因果性地修正循环轨迹。这些结果区分了潜在信息性与实际用于预测的潜在计算。

## Abstract
Latent visual reasoning aims to perform multimodal reasoning through hidden-state computation rather than explicit textual chains of thought. However, visual information being present in a latent state does not imply that the model actually relies on that state when producing its answer, especially when alternative image-conditioned paths remain available. We introduce \textbf{C}ausal \textbf{V}isual \textbf{R}ecurrent \textbf{R}easoning (CVRR), which preserves pretrained visual competence while making recurrent computation the required image-conditioned path to prediction. CVRR initializes recurrence from the question hidden state after the pretrained vision-language model has incorporated the image, then repeatedly updates this state while re-reading the same fixed visual evidence. Before decoding, visual states and the original multimodal KV cache are removed so that only the final recurrent state carries image-conditioned information to the answer. Across the $V^*$, MMVP, BLINK, and MME-RealWorld-Lite benchmarks, CVRR retains strong performance under this strict interface, while compatible latent reasoners fail to recover comparable visual competence even when retrained under the same constraint. Causal interventions further show that predictions remain sensitive to recurrent content when the question is held fixed, and that persistent visual evidence causally revises the recurrent trajectory. These results distinguish latent informativeness from latent computation that is actually used for prediction.

## 2. 方法论：CVRR 的核心思想与关键技术
- **核心思想**：
  - 从预训练 VLM 已经吸收图像后的**原生多模态问题隐状态**初始化循环。
  - 在循环中反复更新问题状态，同时反复读取同一份固定视觉证据。
  - 解码前移除视觉状态和原始多模态 KV cache，使最终循环状态成为唯一图像条件路径。
- **因果视觉读取边界定位**：
  - 使用层间激活替换（activation patching）寻找视觉信息仍对下游有影响、且问题状态已具备较强视觉能力的层。
  - Qwen2.5-VL-7B 上得到边界 \(\ell^*=20\)，后续层 \(f_0=L_{21}\) 用于初始化循环。
- **初始化与持久视觉证据**：
  - 冻结低层得到多模态状态 \(H^*_{mm}\) 和纯文本状态 \(Q^*_{txt}\)。
  - 先以预训练形式执行 \(f_0\)：\(H_1=f_0(H^*_{mm})\)，取问题行 \(h_1=P_QH_1\)，视觉行 \(v=P_VH_1\)。
  - \(h_1\) 携带预训练视觉能力，\(v\) 作为循环中持续可读的固定视觉证据。
- **共享循环更新**：
  - 对 \(t=2,\dots,T\)，重建多模态脚手架：只替换问题行为上一轮 \(h_{t-1}\)，视觉行保持 \(v\)。
  - 用共享解码层加 LoRA 计算更新：\(\tilde h_t=P_Q f_\phi(H_t)\)，并做混合 \(h_t=(1-\beta)h_{t-1}+\beta \tilde h_t\)。
  - 默认 \(T=4\)，\(\beta=0.50\)；视觉重读通过原生因果自注意力完成，不引入额外跨注意力模块。
- **严格因果解码接口**：
  - 解码前丢弃视觉行、原始多模态 KV cache 和循环缓存。
  - 下层自回归只使用纯文本前缀 cache \(K_{txt}\)；上层冻结解码器只接收最终 \(h_T\)。
  - 因此 \(h_T\) 是答案解码器唯一可用的图像条件信息。
- **训练目标**：
  - 只优化共享 LoRA 参数 \(\phi\)，冻结主干与上层解码器。
  - 最小化答案 token 交叉熵：  
    \[
    \mathcal L_{ans}=-\frac1{|\mathcal B|}\sum_i\frac1{|A_i|}\sum_j\log p_\phi(y_{i,j}\mid y_{i,<j},h_{T,i},K_{txt,i})
    \]
  - 不使用潜在目标、教师轨迹或重构损失；路径必要性由解码接口直接强制。

## 3. 实验设计
- **训练数据**：Visual CoT，约 438K QA 对，含与答案相关的边界框。
- **评估基准**：
  - \(V^*\)：191 个高分辨率样例，报告 Overall、Direct Attributes、Relative Position。
  - MMVP：150 个视觉相似图像对，300 个问题，报告 item 与 pair accuracy。
  - BLINK：报告 Counting、IQ-Test、Jigsaw、Relative Reflectance、Spatial Relation 子集及 Overall。
  - MME-RealWorld-Lite：报告 Overall accuracy。
- **对比方法**：
  - 通用 VLM/CoT：GPT-5、Qwen3-VL-8B-Thinking、Qwen2.5-VL-7B-Instruct。
  - 视觉推理：VL-Rethinker、DeepEyes、PixelReasoner。
  - 潜在视觉推理：LVR、Monet、SkiLa、Laser、UniVLR、HyLaR、PEARL。
  - 全多模态 SFT 控制：同数据、保留标准多模态答案路径。
  - 无旁路潜在推理基线：LVR、Monet、SkiLa、Laser、UniVLR、HyLaR 在相同严格接口下重训；PEARL 因需改变其预测路径而被排除。
- **主要结果**：
  - CVRR 在严格无旁路接口下达到 \(V^*\) 81.2%、MMVP pair 52.7%、BLINK Overall 55.2%、MME-RealWorld-Lite 46.7%。
  - 无旁路重训的潜在推理基线最多约 \(V^*\) 39.8%、MMVP pair 2.7%、BLINK 38.8%、MME 33.1%，显著退化。
  - 全多模态 SFT 控制为 \(V^*\) 80.6%、MMVP pair 52.0%、BLINK 53.0%、MME 44.7%；CVRR 在 \(V^*\)、MMVP、BLINK 上匹配或超过该控制。
