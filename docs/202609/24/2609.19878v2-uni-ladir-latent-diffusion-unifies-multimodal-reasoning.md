## 摘要
多模态推理要求模型在整个推理过程中利用来自多种模态的信息。然而，现有方法通常将特定模态的思维标记拼接在单一序列中，让模型在跨模态推理时自行弥合表示差异。我们提出 Uni-LaDiR（统一潜在扩散推理器），一个将这些思维引入共享潜在空间以进行推理的框架。一个统一编码器将来自不同模态的教师推理步骤映射为共享思维标记，并通过训练保留后续推理步骤以及最终答案或动作所需的信息。由于同一上下文可以支持多个有效的下一步，我们使用扩散根据输入及此前块预测下一块思维标记。以共享模型权重联合训练编码器与扩散推理器，促使思维标记既对任务有用，又能从可用上下文中预测。在推理时，模型无需教师观测即可生成这些标记。在十一个视觉-语言模型（VLM）基准和两个视觉-语言-动作（VLA）套件上，Uni-LaDiR 相较评估的最强基线，在视觉推理任务上取得 7.3% 的相对提升，在机器人操作任务上取得 6.1% 的相对提升。

## Abstract
Multimodal reasoning requires models to draw on information from multiple modalities throughout the reasoning process. Yet existing methods often concatenate modality-specific thought tokens in a single sequence, leaving the model to bridge representational differences as it reasons across modalities. We introduce Uni-LaDiR (Unified Latent Diffusion Reasoner), a framework that brings these thoughts into a shared latent space for reasoning. A unified encoder maps teacher reasoning steps from different modalities into shared thought tokens, trained to preserve the information needed for later reasoning steps and the final answer or action. Because the same context can support multiple valid next steps, we use diffusion to predict the next block of thought tokens from the input and preceding blocks. Jointly training the encoder and diffusion reasoner with shared model weights encourages thought tokens to be both useful for the task and predictable from the available context. At inference, the model generates these tokens without teacher observations. Across eleven vision-language model (VLM) benchmarks and two vision-language-action (VLA) suites, Uni-LaDiR achieves relative gains over the strongest evaluated baselines of 7.3% on visual reasoning tasks and 6.1% on robot manipulation tasks.

# Uni-LaDiR：潜在扩散统一多模态推理 — 论文总结

## 1. 核心问题与研究动机

- **背景**：多模态推理要求模型在推理全过程中整合图像、语言、3D 点云、机器人状态等互补模态信息。现有方法（VLM 与 VLA）普遍采用"编码后拼接"范式：各模态被编码为各自的 token/特征，再拼接或交错进 LLM 序列。
- **核心问题**：当相邻推理步骤使用不同模态时，模型不仅需要转换推理状态，还要跨越不同的表示空间（Z_mi ≠ Z_mi+1），形成**模态切换鸿沟（modality-switching gap）**。表示空间切换本身并非推理的一部分，却给推理增加了不必要的复杂度。
- **核心洞见**：不同模态以不同形式表示观测，但推理真正需要的只是这些观测中隐含的任务相关信息。只要将其编码进**共享潜在空间**，推理状态便可独立于观测模态演化。
- **整体含义**：提出 Uni-LaDiR，把来自不同模态的教师推理步骤统一到同一潜在空间，用扩散模型预测思维 token，从而让多模态推理在单一表示空间中完成。

## 2. 方法论

### 核心思想
- 用**统一编码器** $E_\theta$ 将各模态教师特征 $s_i$ 映射为共享潜在空间 $Z$ 中的思维 token $z_i^\star = E_\theta(s_i)$，使推理状态变化时表示空间保持不变（无 switch）。
- 思维 token 需同时满足两个性质：**推理充分性**（保留后续推理与最终输出所需信息）与**上下文可预测性**（在推理时可从可用上下文生成）。
- 通过**共享 LLM 权重联合训练**统一编码器与扩散推理器，使表示空间与推理模型相互适应。

### 关键技术细节
- **统一潜在编码**：模态特定编码后，向每个教师特征 $s_i$ 追加固定长度的可学习嵌入块 $q$；统一编码器将 $q$ 位置的最后隐藏状态映射为干净思维 token $z_i^\star$。所有模态共用同一 $q$、输出投影和每块 token 数（4 个 512 维 token）。潜在编码 mask 隔离各步骤，每个 $q$ 副本只关注自身及其关联教师特征，防止跨步骤信息交换。训练时把多个教师步骤及其 $q$ 副本打包进一次前向。
- **继续预测（Continuation Prediction）**：给定输入 $x$ 与前缀 $z_{<i}^\star$，backbone 预测下一教师目标 $s_i^{GT}$；给定完整序列 $z_{1:K}^\star$，预测最终输出 $y$。
  $$L_{cont}=\sum_{i=2}^{K}\ell(\hat{s}_i,s_i^{GT})+\lambda_y L_{out}$$
  其中文本目标用交叉熵，连续目标（图像/3D 特征、机器人状态）用 L2；VLM 的 $L_{out}$ 为答案 CE，VLA 的 $L_{out}$ 为 flow-matching 动作损失。
- **扩散训练**：对每个块独立采样噪声 $\epsilon_i\sim\mathcal{N}(0,I)$ 与时间 $t\sim U[0,1]$，构造噪声块 $z_i^t=(1-t)\epsilon_i+t\,\mathrm{sg}(z_i^\star)$，目标速度为 $v_i^\star=z_i^\star-\epsilon_i$。条件于 $z_i^t$、$x$、detached 前缀 $\mathrm{sg}(z_{<i}^\star)$ 与 $t$，backbone 预测速度 $\hat{v}_i$，优化流匹配目标：
  $$L_{diff}=\mathbb{E}_{t,\epsilon}\left[\sum_{i=1}^{K}\|\hat{v}_i-\mathrm{sg}(v_i^\star)\|_2^2\right]$$
  其中 $t$ 索引块内去噪，$i$ 索引推理步骤。
- **联合训练**：共享 LLM 权重，总损失 $L=L_{cont}+\lambda L_{diff}$（$\lambda_y=2$，$\lambda=5$）。虽然扩散梯度通过 stop-gradient 不回流到干净目标与前缀，但两个损失仍共同更新共享 LLM 权重，使扩散训练也更新统一编码器。
- **推理**：不需要教师步骤与统一编码路径。从 $x$ 开始逐块去噪生成 $z_1,\dots,z_K$，每块条件于此前已生成块；$K$ 不固定，当模型不再预测 `<BOT>` 时停止。完整潜在序列再条件生成最终答案或动作。

## 6. 主要结论与发现

- **推理效率**：无 action chunking 下 16.5 Hz，比 LaST 0 高 7.1%，是显式 CoT-VLA 的 15 倍。
- **消融结论**：
  - 继续预测比重建源特征提升 13.5%（六基准平均）。
