## 摘要
由于稀疏的 LiDAR 几何、模态不平衡融合以及受限边缘到服务器链路上的冗余特征传输，现有的多模态方法对无人机（UAV）进行精确三维定位仍面临挑战。为解决这些局限，我们提出 PRI-Net，一种用于无人机定位的高效轻量级多模态融合框架，集成了点云泼溅、残差注意力融合和信息瓶颈。具体而言，引入三维点云泼溅（3DPCS）策略，将稀疏的 LiDAR 观测转换为几何一致的稠密深度图。随后设计残差注意力融合（RAF）模块，通过使用图像分支进行粗估计和门控融合分支进行细化，以缓解模态偏差。此外，多模态信息瓶颈（MIB）模块通过滤除任务无关冗余来压缩特征。实验表明，PRI-Net 以轻量级架构实现了高定位精度，同时降低了特征维度，并提升了边缘到服务器无人机感知的效率与鲁棒性。

## Abstract
Accurate 3D localization of unmanned aerial vehicles (UAVs) remains challenging for existing multimodal approaches due to sparse LiDAR geometry, modality-imbalanced fusion, and redundant feature transmission over constrained edge-to-server links. To address these limitations, we propose PRI-Net, an efficient and lightweight multimodal fusion framework for UAV localization that integrates point cloud splatting, residual attention fusion, and an information bottleneck. Specifically, a 3D point cloud splatting (3DPCS) strategy is introduced to transform sparse LiDAR observations into geometrically consistent dense depth maps. A residual attention fusion (RAF) module is then designed to alleviate modal bias by using an image branch for coarse estimation and a gated fusion branch for refinement. In addition, a multimodal information bottleneck (MIB) module compacts features by filtering task-irrelevant redundancy. Experiments show that PRI-Net achieves high localization accuracy with lightweight architectures, while reducing feature dimensionality and improving edge-to-server UAV sensing efficiency and robustness.

## 1. 核心问题与整体含义

- **研究背景**：低空无人机感知系统快速发展，准确的三维无人机定位对监控、协同感知与态势理解至关重要。
- **现有方法局限**：
  - 纯视觉方法成本低、流程成熟，但缺乏显式深度、依赖外观线索，在复杂光照与遮挡下鲁棒性不足。
  - 纯 LiDAR 方法虽具几何优势，却面临点云稀疏、语义贫乏、计算复杂度高的问题，难以部署在资源受限的边缘设备上。
  - 多模态融合（如 MV3D、PointPainting、BEVFusion）虽能互补，但仍存在三大挑战：点云投影到图像平面后深度图空洞严重；模态间分布差异大导致融合失衡；特征提取与融合管线沉重，边缘到服务器传输开销大。
- **论文整体含义**：提出 PRI-Net——一个轻量级多模态融合框架，同时应对“稀疏几何”“模态不平衡”“传输冗余”三个问题，目标是在边缘-服务器架构下兼顾三维定位精度与通信效率。

## 2. 方法论

- **核心思想**：以三个模块对应三个挑战——3D 点云泼溅（3DPCS）解决深度图空洞，残差注意力融合（RAF）解决模态偏置，多模态信息瓶颈（MIB）解决传输冗余。
- **系统架构**：边缘设备负责高带宽相机与 LiDAR 数据的特征提取与压缩；边缘服务器仅接收压缩后的任务相关表示并完成最终坐标回归。
- **3D 点云泼溅（3DPCS）**：
  - 定义虚拟针孔相机内参 $K_v$ 与外参 $[R_v|t_v]$，将每个 LiDAR 点 $p_l$ 投影到虚拟图像平面。
  - 对每个投影点，在半径 $R$ 内的像素上执行泼溅赋值，深度图取该邻域内深度的最小值（基于 $L_\infty$ 距离），从而填补稀疏点云造成的空洞。
  - 构建几何张量 $M^{geo}_i \in \mathbb{R}^{3\times H\times W}$：将归一化深度图与归一化二维坐标网格拼接，再送入带专用输入 stem 和预训练 ResNet 骨干的 CNN 编码器提取几何特征。
- **图像模态处理**：
  - 原始图像经逆内参与畸变模型校正；使用冻结的 YOLOv7 检测无人机并裁剪 ROI。
  - 图像特征由 ROI 的 ResNet 特征与边界框几何的 MLP 编码拼接而成，兼顾局部外观与空间先验。
- **残差注意力融合（RAF）**：
  - 将图像特征 $x_c$ 与深度特征 $x_l$ 拼接为 $x_f$，经轻量 MLP 与 Sigmoid 生成模态门控权重 $w_m$。
  - 采用残差门控更新：$\tilde{x}_m = x_m + x_m \odot w_m$，保留原始模态信息，融合表示为 $x_n = [\tilde{x}_c; \tilde{x}_l]$。
  - **残差多模态回归**：图像分支先给出基础预测 $\hat{y}_c$，融合分支学习残差修正 $\Delta y$，最终 $\hat{y} = \hat{y}_c + \Delta y$，避免图像模态主导训练、抑制深度模态。
  - **辅助监督**：对融合、图像、深度三个分支联合优化，总损失为 $\mathcal{L} = \lambda_1\mathcal{L}_{fusion} + \lambda_2\mathcal{L}_{img} + \lambda_3\mathcal{L}_{depth}$。
- **多模态信息瓶颈（MIB / EMIB）**：
  - 采用变分信息瓶颈（VIB），目标为 $\mathcal{L}_{IB} = I(Z;X) - \beta I(Z;Y)$，在压缩与任务相关性之间权衡。
  - 后验 $p(z_n|x_n)$ 参数化为对角高斯 $\mathcal{N}(\mu,\sigma^2)$，最终训练目标在定位损失外加入 KL 正则项：$\mathcal{L}_{ALL} = \mathcal{L}_{fusion} + \frac{\beta}{2}\sum_j(\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1)$。
  - 压缩后的隐表示 $z_n$ 仅保留任务相关信息，显著降低边缘到服务器的传输量。

## 6. 主要结论与发现

- **输入策略**：ROI 裁剪加边界框信息性能最佳；去掉边界框略有退化；masked full image 误差最大，说明目标区域裁剪能有效抑制背景干扰，边界框提供有用空间先验。
- **融合策略**：RAF 在三轴上均取得最低 RMSE；相比 Image Only，Z 轴误差降低约 26.3%，说明深度信息有效改善距离估计。Simple Concat 甚至差于 Image Only，表明直接拼接无法充分利用跨模态互补性，模态不平衡反而干扰主导模态。
- **3DPCS**：深度图管线在不同隐维度下误差更低且更稳定，而点云基线误差明显更高且对维度变化敏感；3DPCS 作为离线几何预处理，不增加可训练参数或推理层。
- **IB 隐表示**：$k \leq 32$ 时 IB 平均 RMSE 低于 MLP，$k=64$ 时 MLP 因高维拟合能力更强而更优；在噪声与部分遮挡下，IB 在受限隐空间中更鲁棒，MLP 对干扰更敏感。
- **压缩效率**：原始数据 22.5 GB（图像）与 209 MB（点云），经 EMIB 后 $z_n$（$k=32$）仅 25.55 KB/模态，相比原始数据约 $4.4\times10^5$ 倍压缩，相比中间特征 $x_n$（204.5 KB）再降低 87.5%。
- **总体结论**：点云泼溅、残差注意力融合与信息瓶颈协同，可在受限链路下提升三维无人机定位精度、压缩效率与噪声鲁棒性，具备资源受限边缘部署潜力。
