## 摘要
多模态推理要求模型在整个推理过程中利用来自多种模态的信息。然而，现有方法通常将模态特定的思维标记拼接在单一序列中，使模型在跨模态推理时自行弥合表示差异。我们提出 Uni-LaDiR（Unified Latent Diffusion Reasoner，统一潜在扩散推理器），一个将这些思维引入共享潜在空间进行推理的框架。统一的编码器将来自不同模态的教师推理步骤映射为共享思维标记，并通过训练使其保留后续推理步骤以及最终答案或动作所需的信息。由于同一上下文可以支持多个有效的下一步，我们使用扩散模型根据输入及前序思维块来预测下一思维块。以共享模型权重联合训练编码器与扩散推理器，可促使思维标记既对任务有用，又能从可用上下文中被预测。在推理时，模型无需教师观测即可生成这些标记。在十一个视觉-语言模型（VLM）基准和两个视觉-语言-动作（VLA）套件上，Uni-LaDiR 相较于所评估的最强基线，在视觉推理任务上取得 7.3% 的相对提升，在机器人操作任务上取得 6.1% 的相对提升。

## Abstract
Multimodal reasoning requires models to draw on information from multiple modalities throughout the reasoning process. Yet existing methods often concatenate modality-specific thought tokens in a single sequence, leaving the model to bridge representational differences as it reasons across modalities. We introduce Uni-LaDiR (Unified Latent Diffusion Reasoner), a framework that brings these thoughts into a shared latent space for reasoning. A unified encoder maps teacher reasoning steps from different modalities into shared thought tokens, trained to preserve the information needed for later reasoning steps and the final answer or action. Because the same context can support multiple valid next steps, we use diffusion to predict the next block of thought tokens from the input and preceding blocks. Jointly training the encoder and diffusion reasoner with shared model weights encourages thought tokens to be both useful for the task and predictable from the available context. At inference, the model generates these tokens without teacher observations. Across eleven vision-language model (VLM) benchmarks and two vision-language-action (VLA) suites, Uni-LaDiR achieves relative gains over the strongest evaluated baselines of 7.3% on visual reasoning tasks and 6.1% on robot manipulation tasks.

## 1. 核心问题与整体含义（研究动机与背景）

- **多模态推理的核心挑战**：许多多模态问题必须结合图像、语言、3D 点云、机器人状态等互补证据才能解决，因此一个强大的多模态推理器需要在整个推理过程中调用不同模态的信息。
- **现有方法的共同模式**：无论 VLM 还是 VLA，多数方法先将每个模态编码为各自的 token 或特征，再在 LLM 序列中**拼接或交织**（concatenate / interleave）。结果是推理仍然发生在**模态特定的表示**之上。
- **由此产生的"模态切换鸿沟"**：当中间推理反复在模态间传递信息时，**跨模态表示转换与推理动态被纠缠**——模型不仅要决定推理状态如何变化，还要决定该状态如何用下一个模态的表示来表达。
- **论文的核心主张**：感知可以保持模态相关（各模态专门提取不同证据），但**推理动态应运行在一个统一的推理空间**上。一旦任务相关信息被编码进共享空间，后续推理即可独立于观测模态演化。
- **整体含义**：论文提出 Uni-LaDiR（Unified Latent Diffusion Reasoner），把中间思维统一到共享潜空间，并以扩散模型生成这些思维，试图从架构层面消除模态切换开销。

## 2. 方法论

### 2.1 核心思想

- 用**统一编码器**把来自不同模态的教师推理步骤映射为同一潜空间中的**共享思维 token（thought tokens）**。
- 每个思维块不负责重建源模态，而是被训练为**保留后续推理与最终输出所需的信息**（推理充分性），同时**可从推理时可用上下文预测**（上下文可预测性）。
- 用**扩散模型**建模下一思维块的条件分布，因为同一上下文可能支持多个有效的下一步。
- 统一编码器与扩散推理器**共享骨干权重、联合训练**，使表示空间与预测模型相互适配。

### 2.2 关键技术细节

- **问题形式化**：给定多模态输入 x，推理器生成 K 个中间思维块 z₁:ₖ，再预测任务输出 y（VLM 为文本答案，VLA 为机器人动作）。
- **共享思维 token 构造**：
  - 先做模态特定编码得到教师特征 sᵢ；
  - 在每个 sᵢ 后附加**固定长度、所有模态共享**的可学习嵌入块 q；
  - 统一编码器把 q 位置上的最后隐藏状态映射为干净思维 token z*ᵢ；
  - 使用**构造掩码**隔离各推理步骤：每份 q 只关注自身及其教师特征，防止跨步骤信息交换。
- **下游接地（Grounding）**：
  - 给定 x 与前缀 z*<ᵢ，骨干预测下一教师目标 s_i^GT；给定完整序列 z*₁:ₖ，预测最终输出 y。
  - 损失：`L_ground = Σ_{i=2}^{K} ℓ(ŝᵢ, s_i^GT) + λ_y ℓ(ŷ, y)`，其中 ℓ 对文本用交叉熵、对连续目标（图像/3D/状态特征）用 L2；VLA 的最终动作由 flow-matching 动作头产生，其损失为 flow-matching 损失。
  - 梯度经 z*ᵢ 回传至统一编码器与共享骨干，使思维 token 按"对后续推理的效用"保留信息。
  - 用**接地掩码**在单次前向中并行计算所有预测，且每个预测只能看到被允许的思维前缀。
- **扩散生成（Diffusion）**：
  - 对每个干净块加高斯噪声得到 zᵢᵗ，条件于 x、前序干净块 z*<ᵢ 与噪声水平 t，骨干预测去噪速度 v̂ᵢ。
  - 采用 **flow matching 目标**：`L_diff = E_{t,ϵ}[ Σᵢ ‖v̂ᵢ − v*ᵢ‖² ]`，其中 t 索引块内去噪，i 索引推理步骤。
  - 使用**扩散掩码**：噪声块只能读取 x、前序干净块和自身，不能读取未来块或自己的干净目标。
- **联合训练**：
  - 总目标 `L = L_ground + λL_diff`（实验设 λ_y=1，λ=5）。
  - 在扩散分支上对干净 token z*ᵢ（含条件前缀与加噪目标）**停止梯度**：L_ground 更新编码器与骨干，L_diff 更新骨干但把当前干净 token 当作固定目标。
- **推理**：不需要教师步骤和统一编码路径；从 x 开始逐块去噪生成 z₁…z_K，每块条件于已生成块，完整潜序列再条件预测最终答案或动作。使用每块 4 个 512 维思维 token，推理预算为 4 个块（16 个 token）。

## 6. 主要结论与发现

- **VLM 视觉推理**：
  - 7 个视觉中心基准平均比 Qwen2.5-VL-7B 提升 **18.1%**；4 个数学/逻辑基准相对提升 **34.7%**。
  - 超过最强模态特定潜推理基线：平均比 Mirage 高 **1.7%**，比 ILVR 高 **7.3%**；VisualPuzzles 比 Mirage 高 30.3%，MathVision 比 ILVR 高 10.8%，VisuLogic 高 12.6%。
- **VLA 操作**：
  - RLBench 平均成功率比最强先验潜策略 LaST 0 相对提升 **6.1%**，10 个任务中 9 个提升、1 个持平，最大增益在 Plants（16.7%）。
  - LIBERO 平均成功率 **99.15%**，比 PearlVLA + PRL 高 0.45 个百分点。
  - 无 action chunking 时推理速度 **16.5 Hz**，比 LaST 0 快 7.1%，是显式 CoT-VLA 的 **15.0 倍**。
- **模态统一程度**：越多模态共享同一潜空间，增益越大——视觉推理中文本+图像共享比分离提升 9.0% 相对；RLBench 中共享任意两个模态提升 1.8–3.0%，三个全共享提升 6.1%（相对分离）。
- **接地目标**：下游效用预测比源重建在六基准平均上提升 5.4% 相对（V* 提升 26.0%，RLBench 提升 7.4%），但 MathVista 下降 4.20 个百分点。
- **联合训练**：比分阶段训练在六基准平均提升 11.3% 相对，比冻结目标提升 21.9% 相对。
- **扩散目标**：flow matching 比直接 L2 预测平均提升 14.9%，比余弦相似度损失提升 19.5%。
- **跨骨干泛化**：在 BAGEL-7B、Qwen3-VL-8B、Janus-Pro-1.5B/7B 上视觉中心平均分别提升 29.5%、12.4%、35.9%、51.5%。

## 7. 优点

- **问题切入清晰**：明确区分"模态相关感知"与"共享推理动态"，把模态切换鸿沟作为可优化的设计目标。
- **统一潜接口**：所有模态共享同一组 q、输出投影与 token 数，避免为每个模态设计私有潜格式。
- **训练目标设计合理**：推理充分性（grounding）与上下文可预测性（diffusion）分别由两个损失实现，并通过共享权重联合训练相互适配。
- **扩散建模选择恰当**：承认"同一上下文可有多个有效下一步"，用条件分布而非确定性回归建模，flow matching 相对 L2/余弦的显著增益提供了实证支持。
- **推理阶段无需教师观测**：部署时不依赖未来图像、3D 或状态教师信号，实用性强。
- **效率优势**：3.3B 参数模型在 RLBench 上达到 16.5 Hz，明显快于显式 CoT 方法，且无需 action chunking。
- **实验对照严谨**：消融严格控制变量；跨 4 个骨干验证；推理速度在统一硬件与计时边界下比较。

- **个别任务负增益**：下游接地相比源重建使 MathVista 下降 4.20 个百分点，说明该设计并非对所有
