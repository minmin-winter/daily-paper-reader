## 摘要
多模态大语言模型（MLLMs）近期在视觉-语言推理方面取得了显著进展，然而随着生成内容变长，其性能往往下降。一个关键因素是，在单一不断增长的上下文下，它们经常丢失对早期视觉证据和中间约束的追踪。受人类在解决复杂任务时分别回忆所见与所推断之物的启发，我们提出 DLMR，一种参数高效机制，为 MLLMs 配备双潜在记忆：一个压缩图像证据的视觉记忆，以及一个追踪中间结论与约束的推理记忆。随后，一个路由器在推理过程中动态决定复用哪个记忆以及复用多少，从而在保持视觉锚定的同时维持连贯的长时程推理。DLMR 分三阶段训练，从潜在记忆构建到选择性路由器学习，同时保持基础 MLLM 冻结，仅用少量额外可训练参数即可在通用与推理基准上取得显著增益。分析进一步表明，其路由具有可解释性、依赖状态，并具有专门化的记忆角色，且在长生成中减少了解码 token 数。代码见 https://github.com/Hunter-Wrynn/DLMR。

## Abstract
Multimodal large language models (MLLMs) have recently made strong progress in vision-language reasoning, yet their performance often degrades as generations grow longer. A key factor is that they frequently lose track of earlier visual evidence and intermediate constraints under a monolithic growing context. Inspired by how humans separately recall what they see and what they infer when solving complex tasks, we propose DLMR, a parameter-efficient mechanism that equips MLLMs with Dual Latent Memories: a visual memory that compresses image evidence and a reasoning memory that tracks intermediate conclusions and constraints. A Router then dynamically decides which memory and how much to reuse during inference, preserving visual grounding while maintaining coherent long-horizon reasoning. DLMR is trained in three stages, from latent memory construction to selective router learning, while keeping the base MLLM frozen, yielding substantial gains on both general and reasoning benchmarks with only a small number of additional trainable parameters. Analyses further show interpretable, state-dependent routing with specialized memory roles and reduced decoding tokens over long generations. Code is available at https://github.com/Hunter-Wrynn/DLMR.

# 论文总结：Dual-Latent Memory Routing for Vision-Language Reasoning（DLMR）

## 1. 核心问题与研究动机

- **背景**：多模态大语言模型（MLLM）在视觉-语言推理上进步显著，但在**长时程生成**场景下性能会持续退化。
- **核心症结**：主流 MLLM 采用**单一不断增长的上下文**——图像只作为前缀编码一次，之后所有中间状态仅靠生成文本承载。作者从注意力质量守恒角度给出解释：随着上下文长度 $n_t$ 增长，对固定图像 token 集合的平均注意力上界约为 $O(L_v/n_t)$，随 $t\to\infty$ 趋于 0，导致**早期视觉证据与中间约束被逐渐"遗忘"**（论文 Fig. 1 显示 vanilla 模型对图像 token 的注意力随解码步骤单调衰减）。
- **现有方法局限**：CoT 提示、训练对齐、RAG 增强等仍未跳出"单流增长上下文"范式，只能缓解而非根本解决长时程遗忘。
- **认知科学启发**：人类进行复杂多步推理时，会分别维护"所见"（观察缓冲）与"所推"（约束缓冲）并在需要时按需回访。论文据此提出需要一个**解耦表示 + 状态依赖控制器**的架构接口。
- **整体含义**：DLMR 试图在**冻结基座**的前提下，用少量可训练参数为 MLLM 加装结构化记忆接口，从而在保持视觉锚定的同时维持长程推理一致性，并减少冗余解码。

## 2. 方法论

### 2.1 核心思想
在冻结的 MLLM 之上增加三个轻量组件：(i) 双潜在记忆（视觉 / 推理）；(ii) 记忆注入器（将选中的潜向量上下文化为记忆 token）；(iii) 离散路由器（决定何时/注入哪类/注入多少）。

### 2.2 关键技术细节

- **双潜在记忆**：维护两个输入无关、跨样本共享的可学习潜空间记忆
  $Z^{(s)} \in \mathbb{R}^{M_s \times d},\ s\in\{v,r\}$，分别对应视觉证据与推理约束。给定预算 $k$，取前 $k$ 个潜向量 $Z^{(s)}_{1:k}$。
- **记忆注入器 $g_\phi$**：以 LoRA 增强的骨干副本实现。将当前多模态嵌入 $E_t$ 投影到注入器空间，与潜向量拼接成 $\tilde E^{(w)}_t=[E^{(w)}_t; Z^{(s)}_{1:k}]$，过 Transformer 后取最后 $k$ 个隐状态再投影回原空间，得到记忆 token $M_t\in\mathbb{R}^{k\times d}$，在推理时**追加到解码上下文**。
- **记忆路由（离散动作）**：
  - **可注入步骤**：仅当解码前缀以分隔符集合 $\mathcal{D}=\{,, .\ , \backslash n\}$ 结尾时（delimiter-eligible），且每样本注入次数不超过 $N_{max}$（默认 5）。
  - **动作空间**：$a_t=(s_t,k_t)$，$s_t\in\{v,r\}$，$k_t\in\mathcal{K}^+=\{4,8,16\}$，共 $2m$ 个动作（另含 null 动作）。
  - **策略网络 $\pi_\psi$**：在骨干最后一个前缀 token 的末层隐状态上加轻量分类头（可加 LoRA），输出动作分布；训练时采样、推理时贪心。
  - 注入后需**重置 KV cache** 并从增强前缀继续解码。
- **三阶段训练（骨干全程冻结）**：
  1. **阶段 1：潜在记忆预热**。教师为学生提供两类池化表示 $(t_v,t_r)$（无注入前向的图像 token 池化 / 文本池化）；学生以随机类型与预算注入，得到 $(z_v,z_r)$，用**双教师对齐损失**优化：$\mathcal{L}_{stage1}=\sum_s (1-\cos(z_s,t_s)) + \lambda_{neg}\sum_{s\neq s'}[\cos(z_s,t_{s'})-m]_+ + \lambda_{sep}\cos(z_v,z_r)$。
  2. **阶段 2：注入器训练**。联合训练 $\phi$ 与 $Z$，路由器禁用；以**混合注入**（交替/随机类型与预算）暴露模型以增强鲁棒性；目标为 SFT 似然或 GRPO，并加弱化特化正则 $\epsilon\mathcal{L}_{preserve}$。
  3. **阶段 3：路由器学习**。冻结注入器与记忆，用 GRPO 训练 $\pi_\psi$，目标为代价感知形式 $\max_\psi \mathbb{E}_{\tau\sim\pi_\psi}[R_{task}(\tau)+\lambda_{eff}R_{eff}(\tau)]-\beta KL(\pi_\psi\|\pi_{ref})$，其中效率奖励 $R_{eff}=\mathbb{I}\{R_{task}=1\}\cdot(1-\bar k/k_{max})$ **仅在答对时计入**。

## 6. 主要结论与发现

- **性能提升显著**：在 Qwen2.5-VL-7B 上，DLMR(RL) 使推理均值从 46.61→56.45、通用均值 64.67→71.07；InternVL3-8B 上推理均值 48.27→63.08。MathVision 增益最大（Qwen 上 22.37→39.34）。
- **SFT 与 RL 分工**：DLMR(SFT) 更擅长通用视觉锚定，DLMR(RL) 更擅长多步推理与约束维持。
- **解耦是核心**：合并为单一记忆后六 benchmark 均值从 59.73 降至 52.05（−7.68），MathVision 单项 35.32→22.37，说明分离视觉证据与推理约束直接命中目标失败模式。
