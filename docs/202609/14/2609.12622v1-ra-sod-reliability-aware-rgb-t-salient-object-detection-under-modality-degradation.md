## 摘要
RGB-热红外（RGB-T）显著目标检测利用可见光和热红外模态的互补线索，以提高在复杂环境中的鲁棒性。然而，在真实场景中，各模态的可靠性本质上并不稳定：RGB图像在低照度、运动模糊和噪声下会退化，而热红外图像则常受对比度压缩和传感器伪影的影响。这种退化会引入不可靠的感知证据，可能误导跨模态融合，并显著降低检测性能。为应对这一挑战，我们提出RA-SOD，一种可靠性感知的RGB-T显著目标检测框架，它显式建模模态可靠性，并将其融入特征学习和跨模态融合。首先，我们引入可靠性条件化表示，自适应地补偿退化的模态特征，同时保留结构线索。其次，一种不确定性引导的双流细化策略逐步校正跨模态表示，同时抑制不可靠证据。最后，我们提出像素级模态竞争机制，根据空间可靠性动态选择模态线索，以实现细粒度融合。在四个基准（VT821、VT1000、VT5000和VT-IMAG）上的大量实验表明，RA-SOD达到了当前最优性能，并在严重模态退化下表现出强鲁棒性。代码和模型可在 https://github.com/zaoxienian/RA-SOD 获取。

## Abstract
RGB-Thermal (RGB-T) salient object detection leverages complementary cues from visible and thermal modalities to improve robustness in challenging environments. However, in real-world scenarios, the reliability of each modality is inherently unstable: RGB images degrade under low illumination, motion blur, and noise, while thermal imagery often suffers from contrast compression and sensor artifacts. Such degradation introduces unreliable perceptual evidence that can mislead cross-modal fusion and significantly deteriorate detection performance. To address this challenge, we propose RA-SOD, a reliability-aware RGB-T salient object detection framework that explicitly models modality reliability and integrates it into feature learning and cross-modal fusion. First, we introduce a reliability-conditioned representation that adaptively compensates degraded modality features while preserving structural cues. Second, an uncertainty-guided dual-stream refinement strategy progressively corrects cross-modal representations while suppressing unreliable evidence. Finally, we propose a pixel-wise modality competition mechanism that dynamically selects modality cues according to spatial reliability for fine-grained fusion. Extensive experiments on four benchmarks (VT821, VT1000, VT5000, and VT-IMAG) demonstrate that RA-SOD achieves state-of-the-art performance and exhibits strong robustness under severe modality degradation. Code and models are available at https://github.com/zaoxienian/RA-SOD.

## 2. 方法论

### 2.1 核心思想

- 构建统一的**分层可靠性建模框架**：编码阶段补偿退化特征，解码阶段抑制不可靠传播，融合阶段按空间可靠性动态选择模态。
- 网络包含三个关键组件：
  - **Reliability-Conditioned Backbone Representation, RCBR**：可靠性条件化骨干表示。
  - **Uncertainty-Guided Dual-Stream Decoding, UGDD**：不确定性引导双流解码。
  - **Pixel-wise Fusion Stream Decoding**：像素级融合流解码与模态竞争。
- 最终输出由 RGB 流、热红外流、融合流三路预测线性聚合得到。

### 2.2 关键技术细节

- **RCBR：可靠性条件化骨干表示**
  - 使用共享冻结骨干提取基础特征：  
    \(F^{l,base}_m = B_l(F^{l-1}_m)\)，其中 \(m \in \{r,t\}\)。
  - 并行残差调制分支根据基础特征预测专家路由权重：  
    \(\alpha^l_m = \text{Softmax}(g^l_m(F^{l,base}_m))\)，且 \(\sum_k \alpha^l_{m,k}=1\)。
  - 残差调制由共享专家库和模态特定低秩适配器组成：  
    \(\Delta F^l_m = \sum_k \alpha^l_{m,k} E_{l,k}(F^{l-1}_m) + A^l_m(F^{l-1}_m)\)。
  - 最终表示为：  
    \(F^l_m = F^{l,base}_m + \Delta F^l_m\)。
  - 目的：保留冻结骨干的结构先验，同时让网络自适应补偿退化模态特征。

- **UGDD：不确定性引导双流解码**
  - RGB 与热红外通过两个并行自顶向下流解码，得到初步解码特征 \(\hat{D}^l_m\)。
  - 预测不确定性图：  
    \(U^l_m = \sigma(\phi^l(\hat{D}^l_m))\)，其中 \(\phi^l\) 为模态共享轻量不确定性预测器。
  - 双向跨模态修正：  
    \(D^l_r = \hat{D}^l_r + U^l_r \odot T^l(\hat{D}^l_t)\)，  
    \(D^l_t = \hat{D}^l_t + U^l_t \odot T^l(\hat{D}^l_r)\)。
  - 不确定性图作为结构化可靠性信号，防止不可靠特征在层级传播中被强化。

- **像素级融合流解码与模态竞争**
  - 融合流输入来自 MFM 模块生成的模态集成编码特征 \(\{E^l_{fus}\}\)。
  - 在每层预测像素级模态竞争权重：  
    \([W^l_r, W^l_t] = \text{Softmax}(\psi^l([\text{Up}(D^{l+1}_{fus}); D^l_r; D^l_t]))\)。
  - 融合引导特征：  
    \(H^l = W^l_r \odot D^l_r + W^l_t \odot D^l_t + \text{Up}(D^{l+1}_{fus})\)。
  - 目的：按空间位置动态选择更可靠的 RGB 或热红外线索，抑制局部退化响应。

- **多流预测与训练目标**
  - 三路独立预测头分别生成 \(S_r, S_t, S_{fus}\)。
  - 最终显著图：  
    \(S = S_r + S_t + S_{fus}\)。
  - 训练目标对三路进行深监督：  
    \(\mathcal{L} = \sum_{m \in \{r,t,fus\}} (\lambda_1 \mathcal{L}_{BCE}(S_m,G) + \lambda_2 \mathcal{L}_{IoU}(S_m,G))\)。

### 2.3 算法流程概括

1. 输入对齐 RGB 与热红外图像。
2. 共享冻结骨干提取基础特征。
3. RCBR 通过路由、共享专家和低秩适配器生成可靠性条件化表示。
4. UGDD 双流递归解码，并用不确定性图引导跨模态校正。
5. 融合流执行像素级模态竞争，逐层融合 RGB、热红外与融合流特征。
6. 三路预测头输出显著图，线性聚合得到最终结果。
7. 使用 BCE 与 IoU 损失对三路输出进行联合深监督。
