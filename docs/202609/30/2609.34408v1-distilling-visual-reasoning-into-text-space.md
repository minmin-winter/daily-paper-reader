## 摘要
大型视觉语言模型（LVLMs）在多模态推理方面展现出巨大潜力，但在需要输入图像中无法直接观察到的概念的任务上往往表现不佳。现有方法生成中间图像或潜在视觉标记来引导推理，但这些表示可能引入错误，并且随着推理推进，会越来越干扰文本推理。我们提出视觉到文本思维链蒸馏（Visual-to-Text Chain-of-Thought Distillation, V2T），一个使 LVLMs 能够在推理时无需生成中间视觉表示即可内化视觉推理的框架。V2T 首先使用交错的视觉与文本思维链训练教师 LVLM，然后利用知识蒸馏，通过教师的 logits 和来自真实文本推理的交叉熵监督来训练学生 LVLM。当推理图像能够映射到原始图像时，V2T 还可以蒸馏教师对相应区域的注意力，而真实边界框可进一步指导后续的强化学习阶段。在多个多模态推理基准上的实验表明，V2T 持续优于教师模型和现有基线，在留出集上将平均准确率提升 14.3%，在更广泛的视觉评估套件上提升 2.7%。此外，轻量级 SFT 和大幅减少的 RL 使 V2T 的训练速度比最先进的基线快达 42 倍。

## Abstract
Large Vision-Language Models (LVLMs) have shown strong promise for multimodal reasoning, yet often struggle with tasks requiring concepts beyond what is directly observable in the input image. Existing methods generate intermediate images or latent visual tokens to guide reasoning, but these representations can introduce errors and increasingly interfere with textual reasoning as reasoning progresses. We propose Visual-to-Text Chain-of-Thought Distillation (V2T), a framework that enables LVLMs to internalize visual reasoning without generating intermediate visual representations at inference time. V2T first trains a teacher LVLM using interleaved visual and textual chains of thought, and then uses knowledge distillation to train a student LVLM using the teacher's logits and cross-entropy supervision from ground-truth textual reasoning. When reasoning images can be mapped to the original image, V2T can additionally distill the teacher's attention to corresponding regions, while ground-truth bounding boxes can further guide a subsequent reinforcement learning stage. Experiments across multiple multimodal reasoning benchmarks show that V2T consistently outperforms the teacher and existing baselines, improving average accuracy by 14.3% on a held-out set and 2.7% on the broader visual evaluation suite. Moreover, lightweight SFT and substantially reduced RL make V2T up to 42x faster to train than state-of-the-art baselines.

# 论文总结：Distilling Visual Reasoning into Text Space（V2T）

## 1. 核心问题与整体含义

- **研究动机**：大型视觉语言模型（LVLMs）在多模态推理任务中表现突出，但面对需要**输入图像中无法直接观察到的概念**（如几何题中的辅助线、隐藏的空间关系）时往往力不从心。人类会自然地在脑中想象中间视觉状态，而主要在文本空间中训练的 LVLM 难以胜任这类推理。
- **现有方法的困境**：
  - 一类方法引入**外部视觉工具**（裁剪、画辅助线、高亮区域等），但依赖工具能力，中间图像的不准确会沿自回归过程传播误差，且需要强模型或大量 RL 才能学会工具使用策略。
  - 另一类方法采用**潜在视觉推理**（生成中间图像或潜在视觉 token），但这些表示可能不准确、不完整，误导后续推理。
- **关键实证发现（论文图 2 的受控分析）**：
  - 交错视觉输入与纯文本推理之间的**损失差距随推理步骤推进而扩大**（图像数从 3→9，损失差距从 +0.38 增至 +5.99）。
  - 即使加入**无关视觉内容**（如 50% 灰色背景），损失差距也会进一步增大（如 Object Counting 从 3.91 增至 9.90）。
  - 在生成层面，随着推理前缀变长，**去掉中间图像反而匹配或优于保留图像**的条件。
- **核心问题**：能否将视觉推理**内化到文本思维链中**，使模型在推理时无需真正生成中间视觉信息，却"仿佛"拥有这些信息？

## 2. 方法论

### 核心思想
V2T 分两阶段：先训练一个能利用中间推理图像的**教师模型**，再通过知识蒸馏将教师的视觉推理能力迁移到一个**完全在文本空间推理的学生模型**。推理时学生不接收任何中间图像，从而避免模态切换、图像生成错误与误差传播。

### 关键技术细节

- **Stage 1：训练教师模型**
  - 数据为交错多模态推理样本：问题图像 $v_{prob}$、文本提示 $x$、K 步 CoT（每步含真值文本 $y_t$，部分步骤配对中间推理图像 $v_{reason,t}$）。
  - 教师以交叉熵在文本 token 上训练，条件为前序文本-图像对及当前推理图像：
    $$L_{CE}(\theta) = -\sum_{t=1}^{K} \log p_\theta(y_t \mid x, v_{prob}, (y_j, v_{reason,j})_{j<t}, v_{reason,t})$$
  - **教师局限**：推理时无中间图像，存在训练-测试不匹配。

- **Stage 2：蒸馏到文本空间**
  - 冻结教师，训练学生仅从提示 $x$ 与问题图像 $v_{prob}$ 生成文本推理（训练和推理均无中间图像）。
  - 教师与学生使用相同的真值文本前缀（teacher forcing），教师额外条件于当前及历史推理图像。
  - **Logit 蒸馏损失**：
    $$L_{KD}(\phi) = \sum_t KL(q_\theta(y_t) \parallel p_\phi(y_t))$$
  - **真值文本监督**：$L_{text}(\phi) = -\sum_t \log p_\phi(y_t \mid y_{<t}, x, v_{prob})$
  - **总目标**：$L_{total}(\phi) = L_{text}(\phi) + \lambda L_{KD}(\phi)$，实验中 $\lambda=0.1$。
  - **重要说明**：蒸馏时教师条件于**真值交错推理轨迹**而非生成的图像，防止生成视觉状态的误差传播。

- **辅助模块 1：注意力蒸馏**
  - 当推理图像可空间映射到原图某区域（如裁剪、变换）时，提取教师与学生在推理步骤后第一个真值文本 token 处的注意力分布（中间层、跨 head 取最大）。
  - 对齐损失：$L_{attn}(\phi) = \frac{1}{|S|}\sum_{t\in S} KL(a_{\theta,t} \parallel a_{\phi,t})$
  - 总目标变为：$L_{total}^{attn}(\phi) = L_{text} + \lambda L_{KD} + \beta L_{attn}$，$\beta=0.5$。

- **辅助模块 2：强化学习增强视觉定位**
  - 蒸馏后可选短程 GRPO 微调（学生已有强初始化）。
  - 当有真值边界框时加入**视觉定位奖励**：
    $$r_{ground} = \frac{1}{2}\left(\frac{|\hat{M} \cap M|}{|\hat{M}|} + \frac{|\hat{M} \cap M|}{|M|}\right)$$
  - 总奖励：$r = r_{task} + \eta r_{ground}$，$\eta=0.5$；$r_{task}$ 为答案正确性二值奖励 + 格式奖励（权重 0.1）。

## 3. 实验设计

### 数据集与场景
- **训练数据**：Zebra-CoT（图像-文本交错 CoT 数据集，涵盖科学图表、2D 视觉谜题、视觉逻辑与策略游戏），经两阶段过滤（用 Qwen2.5-VL-7B 去掉无图也能答对的简单样本，用 Qwen2.5-VL-72B 去掉交错图下仍答错的噪声样本），得到约 **23K** 训练样本。
- **评估套件**：
  - **留出集（held-out Zebra-CoT）**：每类随机 200 样本，共 800 个，覆盖 Graph Algorithm、RPM、Tetris、Visual Search。
  - **更广泛视觉评估**：HR-Bench 4K/8K（高分辨率细粒度感知）、V*Bench（视觉搜索与空间定位）、BLINK（Functional/Visual Correspondence、Object Localization、Forensic Detection、Jigsaw、Multi-view Reasoning）、POPE（物体幻觉）。

## 6. 主要结论与发现

- **性能显著提升**：
  - Zebra-CoT 留出集：V2T 平均准确率 **75.5%**，超过教师（Interleaved SFT）**14.3%**，超过最强基线 VLAA-Thinker-7B **14.6%**，在四类任务上均最佳。
  - 广泛视觉评估：V2T 平均 **61.8%**，超过最强基线 Vision-R1-7B / DeepEyes **2.7%**，超过 Qwen2.5-VL-7B **4.0%**；加 GRPO 后达 **63.4%**。
  - 学生**一致优于教师**，说明蒸馏不仅消除了训练-测试不匹配，还带来了额外收益。
- **注意力定位更强**：V2T 的问题图像注意力 IoU 达 **0.269**，高于 Text-Only SFT（0.215）、Interleaved（Inf, 0.223）和 base（0.191）；交错模型在有图时注意力转向推理图像，问题图像 IoU 反降至 0.168（"捷径"现象）。
- **错误类型改善**：V2T 总错误数比 Interleaved SFT 减少 7.4%，其中 **Spatial & Global Context 错误减少 16.1%**，Task & Answer Consistency 减少 14.4%，而 Perception & Grounding 和 Reasoning & Knowledge 改善较小。
- **效率优势**：训练最高快 42×，推理成本与纯文本模型相同（1×）。
- **消融结论**：注意力蒸馏带来平均 +4.7%（57.1→61.8），在 HR-Bench 4K/8K 和 V*Bench 上提升尤为显著（+10.3%、+14.9%、+16.7%）；GRPO 视觉定位奖励再提升至 63.4%（BLINK Functional Correspondence +16.1%）。

## 7. 优点

- **范式创新**：首次系统性地论证"交错视觉输入随推理推进会干扰文本推理"，并据此提出将视觉推理**内化到文本空间**的蒸馏范式，推理时零中间视觉表示，规避模态切换与误差传播。
- **教师条件于真值轨迹**：蒸馏时教师使用真值交错轨迹而非生成图像，避免生成误差污染蒸馏信号，设计严谨。
- **多层级监督互补**：logit 蒸馏 + 真值文本 CE + 注意力蒸馏 + 视觉定位 RL 奖励，形成从输出分布到内部注意力的多层次知识迁移。
- **效率极高**：训练最高快 42×，推理成本与纯文本模型持平，实用性强。
- **实验分析扎实**：不仅有主结果，还通过注意力 IoU、错误分类、受控损失差距分析、评判一致性校验等多角度验证"真正内化了视觉定位"而非语言模式匹配。
- **公平性处理得当**：对训练集重叠的 Bagel-Zebra 做排除处理，对基线做数学基准合理性检查，并明确标注估计成本。

## 8. 不足与局限

- **数据依赖强**：需要**交错多模态推理数据**（文本 CoT 配对中间图像），收集成本高、规模有限（仅约 23K），限制了方法的可扩展性。
- **继承教师偏差**：学生会继承教师在视觉定位推理中的任何偏差或错误。
- **改进范围有限**：错误分析显示 V2T 主要改善**空间推理**，对感知层面和领域知识错误改善有限，无法替代更强的底层视觉感知能力。
- **实验覆盖局限**：受算力限制，所有实验仅**单次训练运行**，缺少多种子评估；模型规模仅 7B，更大规模验证留待未来。
