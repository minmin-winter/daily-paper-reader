## 摘要
多模态情感分析常常因原始视频噪声和时间建模不足而保持文本主导。本研究基于CH-SIMS v2.0S，提出三项改进：NAPS流程——一个七阶段系统，整合人脸跟踪、身份嵌入和归一化唇动分析以减少视觉噪声；DS-TANet，结合EfficientNetB2静态流、RAFT光流运动流、运动引导注意力及Bi-GRU时间建模；以及DS-TAFNet，通过拼接融合整合视觉和MacBERT-Base文本表示。采用NAPS后，静态视觉基线达到80.98%的Macro F1，与文本基线的80.55%相当；DS-TANet将视觉Macro F1提升至82.58%；DS-TAFNet则实现87.49%的准确率和87.48%的Macro F1。这些结果表明，在有限数据条件下，提升视觉输入质量与时间表示比增加融合复杂度更为有效。

## Abstract
Multimodal sentiment analysis often remains text-dominant due to raw-video noise and insufficient temporal modeling. Using CH-SIMS v2.0S, this study proposes three improvements: the NAPS pipeline---a seven-stage system integrating face tracking,identity embedding, and normalized lip-motion analysis to reduce visual noise;DS-TANet, combining an EfficientNetB2 static stream, RAFT optical-flow motion stream, motion-guided attention, and Bi-GRU temporal modeling; and DS-TAFNet, fusing visual and MacBERT-Base textual representations via concatenation fusion. With NAPS, the static visual baseline achieves 80.98\% Macro F1, comparable to the text baseline of 80.55\%; DS-TANet improves visual Macro F1 to 82.58\%;and DS-TAFNet achieves 87.49\% accuracy and 87.48\% Macro F1. These results demonstrate that improving visual input quality and temporal representation is more effective than increasing fusion complexity under limited-data conditions.

## 1. 核心问题与研究动机

- **背景问题**：多模态情感分析（MSA）在实际社交媒体视频场景中往往呈现"文本主导"现象，视觉模态贡献有限，原因在于两个层面：
  - **数据层面**：研究者通常直接将原始视频送入模型，视觉特征被多人同框、非目标说话人干扰、侧脸、遮挡、光照不稳等因素污染；
  - **建模层面**：视觉建模仍以静态帧级特征为主，忽视了面部时序动态（如眉毛、眼睛、嘴唇的连续变化）所携带的重要情感线索。

- **研究定位**：不同于大多数学者把重心放在融合模块的复杂化上，本文认为在有限标注数据条件下，提升单模态表征质量（尤其是视觉）比增加融合复杂度更有效。作者在中文数据集 CH-SIMS v2.0S 上系统验证了这一主张。

- **核心路线**：先在数据源头做细粒度视觉预处理（NAPS），再进行视觉双流时序建模（DS-TANet），最后以轻量拼接融合接入文本模态（DS-TAFNet）——以三级递进方式增强视觉模态的实际贡献。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体架构（DS-TAFNet）

由三个模块组成：

- **视觉编码器（DS-TANet）**：处理 NAPS 预处理后的 14 帧均匀采样人脸序列（224×224）；
- **文本编码器**：使用带情感引导 prompt 的 MacBERT-Base；
- **多模态融合分类器**：视觉与文本表征经维度对齐（各 256 维）后拼接融合，输出情感极性预测。

### 2.2 NAPS 七阶段视觉预处理管线

NAPS（Normalized Adaptive Pose-robust Speaker Localization）包含以下阶段：

| 阶段 | 功能 | 关键技术 |
|------|------|----------|
| Stage 1 | 多目标人脸跟踪 | MediaPipe 人脸检测（置信度≥0.55）、YCrCb 肤色过滤、InceptionResNetV1/VGGFace2 提取 512 维人脸嵌入、匈牙利算法全局最优匹配（代价函数结合 IoU 与余弦相似度，式1） |
| Stage 2 | 轨迹合并与候选选择 | 轨迹级身份特征取平均嵌入，贪心策略按余弦相似度（阈值 0.68）合并碎片化子轨迹，取前 5 个候选 |
| Stage 3 | 侧脸候选过滤 | FaceMesh 提取嘴角色标，以双嘴角水平距离 mouth_width ≥ 0.11 判定正脸帧；正脸比例低于 35% 的候选丢弃（带 fallback） |
| Stage 4 | 场景类型判定 | 双候选时计算帧序列重叠率（式3），>30% 判为多人共现（转 Stage 5），≤30% 判为单人镜头切换（跳过说话人识别） |
| Stage 5 | 归一化唇动分析 | 核心改进：①**唇动归一化**——以嘴宽归一化嘴唇垂直距离开口比 dᵢ（式4），消除个体嘴型差异与头部姿态影响；②**姿态感知软加权**——正脸帧权重 1.0、轻度侧脸 0.5、重度侧脸 0 且剔除，计算加权变异系数 CV 与动态转换率 DR（式5-6） |
| Stage 6 | 三层说话人终选 | 打分 Score = CV × DR（惩罚"偶发大张口但低频率"与"持续微动但低幅度"两类假阳性），Tier 1: CV≥0.30 且 DR≥0.04；否则 Tier 2: Ntrans≥3；否则 Tier 3 取最高分候选 |
| Stage 7 | 稳定裁剪与视频输出 | EMA（α=0.1）同时平滑裁剪中心与边长（式7），镜头切换检测（MAE>28.0 时重置平滑状态），裁剪边长 = max(框宽,框高)×1.4，黑帧补缺以维持帧率连续与时序对齐；另有低光恢复模式（检测阈值降至 0.20） |

- **效果验证**：在 100 个手工标注的多人共现样本（81 个有效）上，Norm-Soft 的说话人识别准确率为 90.1%，比 Abs-Hard 的 86.4% 提升 3.7 个百分点。主要管线自动定位准确率约 95%。

### 2.3 DS-TANet 双流时序视觉编码器

- **静态流**：EfficientNetB2（AffectNet 预训练）逐帧编码，每帧产生 fₜˢ ∈ ℝ¹⁴⁰⁸，构成 Fˢ ∈ ℝᵀ×¹⁴⁰⁸；
- **动态流**：冻结的 RAFT 估计相邻帧稠密光流 (u,v)，经三层卷积编码器压缩为每帧 fₜᵈ ∈ ℝ²⁵⁶（首帧插入零向量保持对齐）；
- **运动引导特征增强**：
  > mₜ = σ(W₂·ReLU(W₁·fₜᵈ))， fₜ = fₜˢ ⊙ (1 + mₜ)

  （式9）用光流特征生成的通道级调制掩码 mₜ ∈ [0,1]¹⁴⁰⁸ 以残差乘法方式增强静态特征——运动信号弱时保留基线表征，降低噪声动态特征干扰；
- **Bi-GRU 时序建模**：单层双向 GRU（每方向 128 隐单元），输出 256 维视频级表征；通过有效帧掩码将黑帧对应特征置零，**取最后有效帧而非固定末帧的隐藏状态**表达视频整体语义。

### 2.4 文本编码器

- MacBERT-Base + 固定情感引导 prompt："Overall, the sentiment tendency of this text is [MASK]."；
- 取 [MASK] 位置的 768 维 final-layer 隐藏状态，经线性层+LayerNorm+GELU+Dropout 投影至 256 维；
- 两阶段训练：先冻结 MacBERT 训练投影/融合/分类层，再解冻顶部两层以小学习率微调。

### 2.5 多模态融合策略对比

- **Concat Fusion（最终采用）**：视觉与文本表征直接拼接 → 融合头（256 维）→ 两层线性分类器。训练参数约 0.4M。引入 **模态 Dropout（p=0.15）** 与 **辅助分类头（Auxiliary Loss，权重 0.3）** 提升对单模态缺失的鲁棒性；
- **Cross-Modal Attention（对照）**：双向跨模态多头注意力（4 头），v 查询 t、t 查询原始 v，各含残差+LayerNorm+FFN（隐藏维度 512）。训练参数约 1.4M，不设模态 Dropout 与辅助头。

## 6. 主要结论与发现

1. **NAPS 预处理的独立价值**：仅用 EfficientNetB2 + NAPS 处理后的静态视觉特征即达 80.98% Macro F1，与文本基线（80.55%）相当——说明在输入源头去除原始视频噪声，就能使视觉模态达到与文本可比的判别力；
2. **运动与时序建模的有效性**：在静态基础上加入 RAFT 光流动态流并配合 Bi-GRU 时序建模，视觉 Macro F1 从 80.98% 提至 82.58%（+1.60 个百分点），并反超文本基线；
3. **注意力融合与时序建模存在互补性**：运动引导注意力单独使用时弱于简单拼接（注意力路径 -0.87 点 F1），配合 Bi-GRU 后反超拼接（+0.46 点）——Bi-GRU 沿注意力路径的增益（+1.58）远大于沿拼接路径（+0.25），通道调制需要时序上下文才能发挥作用；
4. **融合复杂度需与数据规模匹配**：Cross-Modal Attention（约 1.4M 参数）在测试集 Macro F1 上比 Concat Fusion（约 0.4M 参数）高 0.66 个百分点，但在约 2.4k 训练样本下训练稳定性更差、参数量约 3.5 倍，因此 Concat Fusion 为推荐策略；
5. **最终性能**：DS-TAFNet 在不使用音频模态、不依赖任何额外数据的情况下，Acc2 达 87.49%、Macro F1 达 87.48%，**优于论文中所有三模态全监督基线与半监督方法（含使用 10,161 个额外无标注视频的 MC-Teacher）**；
6. **核心论断**：单模态表示质量优先于融合交互复杂度——这是有限标注条件下设计多模态系统的实践原则。

- 视觉编码器消融设计有清晰的递进逻辑（光流增益→融合方式×时序建模交互），能得出具有可迁移性的结论（注意力需配合时序上下文）；
- 提供混淆矩阵（表4），从 Precision/Recall 细节验证了模型的均衡分类能力，避免只报单一指标；
- 对比中同时涵盖全监督和半监督方法，且在"无额外数据"条件下超越使用了 10k+ 额外数据的半监督方法，增强了结论说服力。

## 8. 不足与局限

### 实验覆盖层面
- **单一数据集与单一语言**：所有主实验仅在 CH-SIMS v2.0S（中文影视/综艺对话场景）上进行，缺乏在 CMU-MOSEI、CH-SIMS 原版或英文数据集上的验证；作者在结论中也承认需验证 NAPS/DS-TANet 在其他语言上的可迁移性；
- **仅二分类**：剔除了中性类（占 12.1%），回避了类别不均衡与类边界模糊问题，与原始数据集的三分类设定不完全可比；
- **缺少音频模态**：尽管引用了数据集中默认声学特征较弱的证据作辩解，但一个声称做"多模态情感分析"的系统放弃音频模态仍是范围上的缩减；作者宣布未来将补入声学模态；
- **对比公平性**：与 CH-SIMS v2.0 原论文基线的比较中，本文剔除了中性样本而基线未剔除，虽然指标计算方式保持一致，但严格意义上并非完全同分布的数据口径；部分近期方法的复现结果取自第三方（Zhong et al.），存在复现差异风险；
- **仅报单次结果**：未提供多次运行的均值±std，无法评估模型随机性带来的波动区间，融合策略比较的 0.66% 差异可能不具统计显著性。

### 偏差风险层面
- **预处理引入了人工环节**：主管线约 95% 的自动定位准确率意味着约 5%（约 220 个）样本经过人工审查，"手动纠正后才进入最终预处理结果"这一做法虽提升了数据质量，但生产环境中的部署成本被低估，且人工判断标准可能引入额外偏差；有少量复杂样本仍需人工参与，作者将此列为待改进项；
- **文本训练配置差异较大**：视觉与文本使用不同的 Focal Loss 参数、数据增强策略和早停 patience，可能给"视觉达到/超过文本基线"这一跨模态比较引入混淆因素；
- **黑帧补缺与均匀采样**：面部缺失帧以黑帧代替，视觉骨干可能学习到与黑帧本身相关的伪特征；14 帧均匀采样对长视频的情绪演化覆盖是否充分，论文未做帧数敏感性分析。

### 应用限制层面
- **数据集来源是影视/综艺对话片段**，与真正的用户生成社交媒体短视频（UGC）在拍摄质量、话题自由度、情感表达方式上仍有差距，"社交媒体场景"的定位存在延展性争议；
- **场景约束**：NAPS 假设情感主要由说话人脸表情/口型承载，对无面部、遮挡严重、非正脸拍摄的短视频场景应用有限。
