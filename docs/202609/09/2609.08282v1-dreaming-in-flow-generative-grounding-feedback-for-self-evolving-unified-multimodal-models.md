## 摘要
统一多模态模型在单一网络中整合了视觉理解与生成，但这两种能力通常被优化为独立任务。我们提出了生成性接地反馈（GGF），一个自进化的后训练框架，仅使用文本提示和模型自身的视觉经验。给定提示，模型首先生成一个视觉“梦境”。流级别反馈在同一噪声潜状态下比较文本、图像和修复条件下的预测，将图像接地生成方向传递到提示条件。梦境回放接地通过字幕生成和再想象来回放该梦境，训练声称级证据在回放过程中保持一致，同时分离无关的视觉经验。联合优化这两个方向，使得生成为理解提供视觉接地，理解在没有配对图像-文本监督的情况下完善后续生成。在具有不同理解-生成集成设计的统一模型上的实验表明，文本到图像生成的一致性改进，以及视觉理解的适度提升。

## Abstract
Unified multimodal models integrate visual understanding and generation within a single network, yet the two capabilities are commonly optimized as separate tasks. We introduce Generative Grounding Feedback(GGF), a self-evolving post-training framework that uses only text prompts and the model's own visual experience. Given a prompt, the model first generates a visual ``dream.'' Flow-level feedback compares text-, image-, and repair-conditioned predictions at the same noisy latent state, transferring image-grounded generation directions to the prompt condition. Dream replay grounding replays this dream through captioning and re-imagination, training claim-level evidence to remain consistent across the replay while separating unrelated visual experiences. Jointly optimized, these two directions let generation provide visual grounding for understanding and understanding refine subsequent generation without paired image--text supervision. Experiments across unified models with different understanding--generation integration designs show consistent improvements in text-to-image generation together with modest gains in visual understanding.

## 2. 方法论：GGF 框架

### 2.1 总览

GGF 建立于一个具备自回归理解分支与基于流（flow）匹配的生成分支的统一多模态模型之上。其核心思想是：给定文本提示 `p`，模型先用自身生成分支采样一幅图像 `x1`，将其作为“视觉梦境”，随后围绕这一梦境构建两条互补的反馈路径：

- **面向生成的反馈（理解→生成）**：通过流级对比，将理解模块编码出的视觉语义证据与生成方向对齐，并利用内部修复方向（repair direction）改善生成质量。
- **面向理解的反馈（生成→理解）**：通过“梦回放”过程（生成标题→依据标题重建图像→再生成标题），约束理解分支对同一视觉内容的语义判断保持一致，从而提升视觉理解的鲁棒性与一致性。

两条目标在同一训练步骤中联合优化，形成“读梦—对齐—回放—接地”的闭环自进化。

### 2.2 自生成视觉经验

- 从当前模型采样图像 `x1 ~ Gθ(p)`，不计算梯度。
- 用 VAE 编码 `x1` 得到潜变量 `z1`，采样流时间步 `t` 和高斯噪声 `ϵ`，构造带噪状态 `zt = (1−t)z1 + tϵ`，目标速度 `v* = ϵ − z1`。
- 同一图像经过理解编码器获得语义 token，构造四种条件：
  - `I`：仅图像
  - `P`：仅提示文本
  - `I+P`：图像+文本
  - `I+P+Q`：图像+文本+修复指令
  
这些条件在同一 `(zt, t)` 上各自生成速度预测 `vC`，另外计算无条件预测 `v0`，从而定义条件引导残差 `gC = vC − v0`。该设计使不同条件在相同噪声状态下严格可比。

### 2.3 流级反馈（Flow-Level Feedback，面向生成）

主要使用以下损失项：

- `Lrec`：以图像条件预测对齐真实流轨迹，`vI → v*`。
- `Lcross`：将提示条件生成方向与图像条件预测对齐，`vP` 对齐 `sg(vI)`，利用图像中的具体视觉信息接地提示。
- `Lrepair`：构造内部修复方向 `gedit = vIPQ − vIP`，令提示条件对齐“图像引导 + 修复增强”综合教师：`gteacher = gI + αgedit`。
- `Lanchor`：为防遗忘，将提示条件预测与冻结初始模型 `θ0` 的对应预测对齐。

完整流级反馈目标：
```
Lflow = Lrec + λcross·Lcross + λrepair·Lrepair + λanchor·Lanchor
```

### 2.4 梦回放接地（Dream Replay Grounding，面向理解）

具体操作流程为：

1. 对初始梦境 `x1` 执行标题生成 `c1 ~ Uθ(·|x1)`；
2. 基于 `c1` 重建图像 `x2 ~ Gθ(c1)`；
3. 再次对 `x2` 生成标题 `c2 ~ Uθ(·|x2)`；
4. 再重建 `x3 ~ Gθ(c2)`。

同时，从训练语料中采样一个与源语义无关的提示 `pb`，生成“无关梦境” `xb ~ Gθ(pb)`。语义语句集为 `A = {p, c1, c2, pb}`。

对任意图像 `x` 与语句 `a`，理解分支输出真/假 logits，定义图像条件证据 `eθ(a|x)`，再用文本条件证据做去偏，得到残余得分 `sθ(x,a) = eθ(a|x) − sg(eθ(a))`。对每张图像在 `A` 上做 softmax，得到语义证据分布 `qi`。

约束包含：

- `Lalign`：回放轨迹中 `x1, x2, x3` 的语义分布与它们的共识分布 `q̄` 对齐；
- `Lcyc`：最终重建的 `x3` 在分布和分数几何上与初始梦境 `x1` 一致（循环一致性）；
- `Lsep`：将无关梦境 `xb` 与共识分布分离（采用 softplus 平滑间隔惩罚）；
- `Lsharp`：最小化共识分布的熵，促使证据集中于少数声明；
- `Lsrc`：源提示重建损失（从 `x1` 恢复 `p`）；
- `U-anchor`：将理解分支的 token 分布对齐冻结初始模型。

完整接地目标为这些损失项的加权和。

### 2.5 双向联合优化

总目标记作：
```
LGGF = Lflow + Lground
```
两个方向的反馈在同一自生成图像的基础上共同更新，形成双向互利的自进化循环。

- 训练 1000 步，使用 rank-16 LoRA 适配器，原模型参数冻结。
- 流时间 `t` 在全区间 `(0,1)` 随机采样；
- 修复损失仅在 `t ≤ 0.7` 时启用，避免高噪声不稳定状态下的不恰当指导。

## 6. 主要结论与发现

1. **生成能力一致提升**：GGF 在三个骨干上均显著提升 GenEval 综合得分（例如 BAGEL 基准从 84.30 → 86.97）和 DPG-Bench，尤其改善计数、空间位置和颜色属性等组合性维度的跟随能力。
2. **理解获得稳健增益**：MME 在 BAGEL 与 Show-o2 上提升 20+ 分，Hallusion-Bench 结构性指标提升显著，说明语义一致性得到加强；POPE 变更较小，SEED-Bench 基本持平，表明增益集中在 grounding 场景而不损害一般理解。
3. **双向反馈的确具有协同效应**：消融发现任一方向的损失移除都会同时损伤生成和理解，验证两者在同一视觉经验上的耦合训练比单向迁移更有效。
4. **无配对数据自进化可行**：仅用文本 prompt 与模型自身采样图像，不依赖外部视觉数据或人工奖励，即可实现持续改善。
5. **防止遗忘的先验锚定至关重要**：`Lanchor` 是加在 flow 方向中对 GenEval 影响最大的组件，说明在学习自生成内容时保留原始流畅构建路径的重要性。

## 7. 优点

- **问题切入点有新意**：提出“梦境需先落地”而非直接盲目训练自生成图像，符合自我改进中的分布偏移问题场景。
- **方法层面充分对接统一架构特征**：利用 flow-based interface，在同一噪声状态下进行条件对比，技术上巧妙且避免需要外部打分手。
- **创造性建立双向闭环**：生成→理解（caption/re-imagine 回放）与理解→生成（semantic-encoded flow transfer）在同一图像上联合，兼具互信息反馈作用。
- **不依赖外部配对真实图片集**：全部依靠模型自身生成，理论上可无限扩展，具有数据效率优势。
- **跨架构验证意识较好**：通过“decoder-only MoT”“shared transformer”“bridge 型”三种架构证明了不应只在单一 backbone 上有效。
- **实验口径统一**：生成与理解用同一权重出来评估，避免常见的“一份权重用于生成，另一份用于理解”的取巧。
- **消融全面**：十个关键组件逐一移除，让每个目标的贡献都有直接证据。

## 8. 不足与局限

### 8.1 实验覆盖不足

- OpenUni 只给出生成结果，没有理解结果，无法验证该架构下双向反馈是否同样成立。
- 对比方法过少，只有 SRUM，缺少 RecA、UNO、SuDer 等近期同线方法，难以客观评价竞品优势。
- 没有进行“同训练 prompt 数量但真实数据 vs 梦境数据”的对照，无法完全排除纯数据增强所带来的增益。
- 没有在更长训练步数或更多训练提示（如 10k/100k）下验证扩展性与稳定性。

### 8.2 评价metric risk

- 训练集 prompt 总量只有 1k，评测集 GenEval / DPG-Bench 的数据规模也有限，部分维度可能出现过拟合评测的嫌疑。
- 不会报告 test-to-test variance、随机种子对结果的影响，单次结果推断可能不稳定。

### 8.3 评估对象限制

- 理解分支的改善集中在 MME + HallusionBench，SEED-Bench 无提升，说明理解适用范围有限，若声称“对理解有益”应进一步说明增益边界。
- 缺乏更细粒度的视觉推理 benchmark（如 VQA-v2、TextVQA、MathVista）检验提升是否泛化。

### 8.4 技术局限

- 公式中多个权重系数（λcross、λrepair、λsrc、τm 等）没有给出取值大小，也没有报告灵敏度分析，复现者只能从 supplementary 里找，但正文亦未显示。
- 修复指令 `Q` 的定义不明确——质量修复文本具体如何书写？这会影响 teacher 信号质量。
- 使用 LoRA 而非全参数更新，无法判断 self-evolution 能在多大程度上发挥完整潜力——LoRA 对表达能力的限制或反而起到正则作用，均未被分析。
- 整个训练流程依赖质量较高的输入 prompt，例如生成的手/脸等常见错误较多的极端 case 可能无法有效修复。

### 8.5 资源可复现性挑战

- 未提供训练代码、超参数表、损失权重、optimizer / lr 等完整 set，外部验证不易。
- 算力成本细节不完整，缺乏对比自进化框架实际所需的显存与时间关系，导致用户难以判断部署性价比。

### 8.6 潜在偏差与安全影响

- 自生成“梦境”会引入模型既有 bias，若生成图像本身带有某种人口/性别/文化偏见，replay 可能进一步强化这些偏见，作者未讨论该风险。
- 应用表现提升依赖源模型的生成质量，如果生成器在某一 prompt 类型上系统性失效，该机制可能存在错误正反馈（虽然 Lsep 与 Lanchor 部分抵消该风险，但并未证明）。
- 由于没有外部 supervisor，模型可能逐渐偏离人类偏好而仅保持自洽，研究没有做人类评测或 A/B test 来验证用户感知的真实改善。

---

## 总结一句话

GGF 展示了一条用模型自身视觉经验自然耦合“理解→生成”与“生成→理解”的可行路径，在免去外部配对数据和奖励模型的条件下带来生成与理解双向收益。然而，评估范围、对比强度与实现透明度仍显不足，其优势若要获得充分验证，还需要进一步扩展骨干模型、更多基线方法和更严格的实验可复现框架。
