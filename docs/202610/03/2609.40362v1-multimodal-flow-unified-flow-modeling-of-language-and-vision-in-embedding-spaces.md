## 摘要
我们提出了 Multimodal Flow，一种语言与视觉的全连续生成模型。大多数统一多模态模型要么将语言和量化图像都建模为离散 token，要么将离散语言预测与连续图像生成相结合。前者引入了视觉量化瓶颈。后者需要依赖模态的目标函数和采样过程。全连续建模避免了这些权衡，并支持共享的生成过程，但在多模态预训练中仍未得到充分探索。Multimodal Flow 引入了一种统一的连续架构，将多模态连续表示与共享的块因果流主干网络相结合。它将文本块和图像组织为有序的连续超块，保留文本 token 顺序和视觉空间结构。该主干网络通过 Flow Matching 在这些超块上学习单一向量场。联合注意力实现跨模态交互，而模态特定的前馈网络处理每种模态。模型在训练期间并行预测多个目标块，并在推理时顺序生成超块。我们实例化了 MF-1，并在多模态数据上对其进行预训练。在 0.6B、1.2B 和 1.6B 规模上，继续预训练持续改善多模态建模。仅使用 150B 预训练 token，MF-1 在 GenEval 和 DPG-Bench 上取得 82.8 的平均得分，在 VQAv2、MMBench 和 POPE 上取得 75.3，与使用显著更多数据训练的统一模型相比仍具竞争力。在数据、优化和参数预算匹配的情况下，Multimodal Flow 进一步优于代表性的混合模型和离散模型。这些结果确立了基于连续块的嵌入流建模作为一种新的全连续范式，用于统一多模态建模。相关代码和模型已在 https://github.com/hustvl/Multimodal-Flow 公开。

## Abstract
We present Multimodal Flow, a fully continuous generative model of language and vision. Most unified multimodal models either model both language and quantized images as discrete tokens or combine discrete language prediction with continuous image generation. The former introduces a visual quantization bottleneck. The latter requires modality-dependent objectives and sampling procedures. Fully continuous modeling avoids these trade-offs and enables a shared generative process, but remains underexplored for multimodal pretraining. Multimodal Flow introduces a unified continuous architecture that integrates multimodal continuous representations with a shared chunk-causal flow backbone. It organizes text blocks and images as ordered continuous hyperchunks, preserving textual token order and visual spatial structure. The backbone learns a single vector field over these hyperchunks through Flow Matching. Joint attention enables cross-modal interaction, while modality-specific feed-forward networks process each modality. The model predicts multiple target chunks in parallel during training and generates hyperchunks sequentially at inference. We instantiate MF-1 and pretrain it on multimodal data. Across 0.6B, 1.2B, and 1.6B scales, continued pretraining consistently improves multimodal modeling. With only 150B pretraining tokens, MF-1 achieves an average score of 82.8 across GenEval and DPG-Bench and 75.3 across VQAv2, MMBench, and POPE, remaining competitive with unified models trained on substantially more data. Under matched data, optimization, and parameter budgets, Multimodal Flow further outperforms representative hybrid and discrete models. These results establish continuous chunk-based embedding flow modeling as a new fully continuous paradigm for unified multimodal modeling. The related code and model are publicly released at https://github.com/hustvl/Multimodal-Flow.

## 1. 核心问题与整体含义

- **研究背景**：统一多模态模型通常希望在同一模型中同时处理语言理解与图像生成，但语言是离散、有序的 token 序列，图像则具有连续、密集的空间结构，二者在表示和生成机制上存在天然差异。
- **现有范式及问题**：
  - **全离散模型**：将图像量化为视觉 token，与文本一起做离散序列建模。优点是目标统一，但存在视觉量化瓶颈，tokenizer 丢失的细节无法由后续模型恢复。
  - **离散—连续混合模型**：文本用离散自回归或扩散建模，图像用扩散/流模型生成。避免量化，但需要模态相关的目标函数、扰动策略和采样流程，难以真正共享生成过程。
- **核心问题**：能否让语言与视觉共享一个生成过程，同时保留各自所需的表示保真度和结构？具体而言，能否在连续嵌入空间中，用统一的 Flow Matching 目标同时建模文本和图像？
- **整体含义**：论文提出 **Multimodal Flow**，将文本块和图像组织为有序连续超块（hyperchunks），用共享的 chunk-causal flow 主干学习统一向量场。它试图确立“连续块嵌入流建模”作为统一多模态建模的新全连续范式，避免视觉量化，也避免模态分离的目标与采样流程。

## 2. 方法论

### 2.1 核心思想

- **全连续建模**：语言和视觉都映射到连续嵌入空间，由同一个 Flow Matching 目标建模。
- **有序超块表示**：文本按块组织，图像作为一个空间结构块，形成任务定义的多模态序列。
- **共享主干 + 模态特定计算**：跨模态交互通过联合注意力实现，模态差异通过模态特定 FFN 和前馈投影处理。
- **训练并行、推理顺序**：训练时多个目标块可并行预测；推理时按块顺序生成，并利用 KV 缓存。

### 2.2 连续表示与超块构造

- 文本：将 token 序列切分为长度为 \(B=8\) 的连续文本块，每块独立编码。主模型使用冻结的 T5-small 编码器，文本嵌入维度为 512。
- 图像：每张图像作为一个视觉块，保留空间网格结构。主模型使用冻结的 SigLIP2-so400m，输入 224×224，产生 256 个 patch embedding，维度 1152，形成 16×16 视觉网格。
- 文本块和图像块分别归一化后，经模态特定输入投影映射到共同隐藏空间。
- 生成后，预测表示经反归一化，由冻结的文本解码器或图像解码器还原为文本或图像。

### 2.3 Chunk-causal Flow 建模

- 将多模态序列表示为有序块序列 \(C=(c_1,\dots,c_K)\)，按块顺序做因果分解：
  - 预测当前块时，只能看到所有前序块；
  - 当前块内部的位置被联合建模，而不是逐 token 自回归。
- 对目标块构造线性概率路径：
  - \(z_t = t x + (1-t)\epsilon\)，其中 \(t=0\) 为噪声，\(t=1\) 为干净表示，\(\epsilon\) 为高斯噪声。
- 主干网络预测干净端点：
  - \(\hat{x}_\theta = f_\theta(z_t, t \mid c_{<k})\)。
- 再转换为速度：
  - \(\hat{v}_\theta = (\hat{x}_\theta - z_t)/\max(1-t, 0.05)\)，用于数值稳定性。
- 训练损失为目标块速度预测的 MSE，对所有并行预测目标块的有效位置求平均。
- 位置编码使用 MRoPE，同时编码块顺序和块内结构。
- 注意力使用 chunk-causal mask：前序块可见，当前噪声目标块可见，未来块和当前块干净版本不可见。

### 2.4 训练与推理流程

- **并行训练**：
  - 多个目标块可在一次前向中并行预测；
  - 每个目标块独立采样 Flow 时间步；
  - 使用序列打包，将多个逻辑序列打包到最多 32768 个模型位置，并用序列 ID 隔离不同样本。
- **顺序推理**：
  - 按任务指定顺序逐块生成；
  - 当前目标块从高斯噪声初始化，从 \(t=0\) 积分到 \(t=1\)；
  - 生成后的干净块加入上下文；
  - 由于 chunk-causal 注意力不依赖未来块，可缓存已完成块的 KV，每步只需重算当前目标块。
- **无分类器引导 CFG**：
  - \(\hat{x}_{\theta,\gamma} = \hat{x}_{\theta,\varnothing} + \gamma(\hat{x}_{\theta,c} - \hat{x}_{\theta,\varnothing})\)；
  - 同一 CFG 机制可用于文本生成和图像生成，但最佳引导尺度不同。
- **混合多模态预训练**：
  - 任务混合比例为：70% 纯文本建模、20% 图像理解、9% 文本到图像生成、1% 纯图像建模；
  - 文本到图像使用文本块前缀 + 视觉目标；图像到文本使用视觉块前缀 + 文本目标；
  - 所有任务共享同一 Flow Matching 目标，仅块内容、顺序和目标模态不同。
- **下游微调**：
  - VQA：视觉块 + 问题块作为干净前缀，答案块作为文本目标；
  - 文本到图像：提示块作为前缀，图像作为视觉目标；
  - 接口、因果分解和连续目标保持不变。
