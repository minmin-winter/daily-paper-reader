## 摘要
直接图像到语音（Img2Sp）在将视觉内容映射为有序语音序列时面临对齐挑战，因为图像允许多种口头描述，且与语音序列之间缺乏单调对应关系。我们提出单调性引导的语义对齐（MGSA），据我们所知，这是首个用于零样本多说话人 Img2Sp 合成的框架。我们使用语义语音单元为不同说话人提供共享的内容目标，并以参考语音进行说话人条件建模。查询对齐器通过软单调先验将从视觉内容中学到的语义记忆映射到语音单元位置，从而产生位置特定的条件状态。我们采用分块掩蔽扩散生成器，在这些状态条件下生成语音单元。在 Flickr8k-Audio 上的实验表明，其字幕生成性能与单说话人基线相比具有竞争力，而使用 LibriTTS-R 参考的评估支持对未见说话人的零样本合成。消融实验验证了对齐器和分块扩散的有效性。音频样本见 https://alizeded.github.io/mgsa-demo。

## Abstract
Direct image-to-speech (Img2Sp) poses an alignment challenge in mapping visual content to ordered speech sequences, as images permit multiple spoken descriptions and lack monotonic correspondence with speech sequences. We propose Monotonicity-Guided Semantic Alignment (MGSA), to the best of our knowledge, the first framework for zero-shot multispeaker Img2Sp synthesis. We use semantic speech units to provide shared content targets across speakers with reference speech for speaker conditioning. A query aligner maps semantic memory learned from visual content to speech unit positions via a soft monotonic prior, which yields position-specific conditioning states. A blockwise masked diffusion generator is employed for the speech unit generation conditioning on these states. Experiments on Flickr8k-Audio show competitive captioning performance against single-speaker baselines, while evaluation with LibriTTS-R references supports zero-shot synthesis for unseen speakers. Ablations validate the effectiveness of aligner and block diffusion. Audio samples are available at https://alizeded.github.io/mgsa-demo.
