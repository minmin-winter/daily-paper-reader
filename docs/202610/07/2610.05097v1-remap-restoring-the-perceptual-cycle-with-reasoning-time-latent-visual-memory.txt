Abstract: As multimodal large language models (MLLMs) reason for longer, attention to the initial visual input diminishes, weakening visual grounding. Visual memory reintroduces vi-sual evidence during reasoning. We conduct a controlled analysis of visual memory along three axes: curation, organization, and access. We find that local evidence benefits from global con-text, compact latent representations balance accuracy and visual-context cost, and the utility of memory access depends on the reasoning state. Guided by these findings, we propose ReMAP 

(Reasoning-Time Memory-Augmented Perception ), which couples two complementary la-tent memories: a static, question-conditioned Global memory that preserves scene and cross-image context, and a dynamic Local memory that uses this context as an anchor while selecting and re-encoding region-level evidence according to the current reasoning state and the question. Both memories return compact latent tokens that are inserted into the reasoning sequence, and a reinforcement-learning access policy trained with branched rollouts decides when to continue reasoning or invoke Global or Local memory. On ten benchmark families, ReMAP outperforms prior visual-memory methods on all four multi-image benchmarks, exceeding the strongest prior results on MuirBench and MIMIC by 8.38 and 14.84 percentage points, respectively. Across four backbone families, enabling memory access improves over the same trained model with memory disabled, and on shared V*Bench, CV-Bench-2D, and MuirBench questions ReMAP reduces the visual tokens entering the reasoning sequence by 51.0–76.8% relative to the native-resolution backbone. Further analyses show that Global and Local memory form distinct yet complementary latent representations and play coordinated roles in interleaved vision-language reasoning. Together, these components restore the perceptual cycle by letting the reasoning state trigger targeted visual retrieval, with the retrieved evidence guiding subsequent reasoning. Code coming soon. 

1 INTRODUCTION 

Vision–language models are increasingly applied to visual tasks covering larger visual contexts and longer reasoning trajectories. These tasks require models to draw on visual evidence at different reasoning stages such as inspecting fine-grained details, comparing observations across images, or verifying intermediate conclusions. As visual inputs and generated text accumulate, maintaining ac-cess to relevant visual evidence is increasingly challenging. Recent studies report visual forgetting, where attention to visual inputs diminishes during extended generation (Sun et al., 2025; Liu et al., 2025), highlighting the difficulty of sustaining visual grounding throughout reasoning. Visual memory methods have emerged as a natural solution to retain visual evidence during reason-ing. These approaches differ in evidence selection, representation, and delivery timing. We therefore ask: what design choices of a visual memory system truly improve visual reasoning? 

We characterize visual memory along three design axes: curation (what evidence enters memory), 

organization (how evidence is represented), and access (when to access memory and which memory to use). Under this framework, we conduct preliminary experiments combining qualitative analysis with controlled empirical evaluations, as illustrated in Figure 1. These analyses yield three key findings: ❶ Memory curated from local visual evidence alone can be insufficient for contextual reasoning, as illustrated in Figure 1(a). ❷ Memory organization affects both reasoning accuracy and computational overhead, as illustrated by the trade-off between image-crop replay and compact latent representations in Figure 1(b). ❸ Reintroducing visual evidence is not always beneficial, and its utility depends on when it is access ed during reasoning (Figure 1(c)). Guided by these findings, we propose ReMAP (Reasoning-Time Memory-Augmented Perception ). For memory curation , ReMAP combines Global memory, which preserves scene and cross-image context from the input images and question, with Local memory, which selects and re-encodes image regions according to the current reasoning state. For memory organization , Global and Local memory return compact latent tokens that are inserted into the reasoning sequence to balance reasoning accuracy and computational overhead. For memory access , we treat memory invocation as an agentic tool call so that the model can obtain relevant visual evidence when needed. We leverage branched rollouts before each invocation to learn whether, when, and which memory to invoke. These rollouts compare the outcomes of requesting memory versus continuing from the same reasoning state and teach when memory helps. Inference follows a single trajectory. We evaluate ReMAP against existing visual memory methods on ten benchmark families span-ning single-image perception, multi-image reasoning, and broader visual understanding. ReMAP achieves state-of-the-art overall performance across the benchmark suite. Notably, ReMAP sig-2Preprint. Under review. nificantly improves multi-image reasoning, outperforming existing visual-memory methods on all four benchmarks and exceeding the strongest prior results on MuirBench and MIMIC by 8.38 and 14.84 percentage points, respectively. Beyond these aggregate gains, our analyses characterize reasoning-time visual memory: ReMAP’s memory access improves performance across four back-bone families, Global and Local evidence provide complementary benefits, and compact latent re-turns reduce visual-context cost while maintaining leading accuracy. Further analyses make Global and Local memory interpretable through their distinct yet complementary latent representations and coordinated roles in interleaved vision-language reasoning. Our contributions are threefold: 

❶ We identify three principles for reasoning-time visual memory: contextualize local evidence with global context, compress representations, and adapt access to the evolving reasoning state. 

❷ We introduce ReMAP, a framework for reasoning-time visual memory. ReMAP com-bines query-conditioned Global context with state-guided Local evidence in compact latent returns and learns when and which memory to invoke through branched rollouts. 

❸ We demonstrate strong multi-image reasoning with interpretable memory roles. 

ReMAP outperforms prior visual-memory methods on all four multi-image benchmarks, while representation and trajectory analyses reveal the complementary functions of Global and Local memory. 

2 RELATED WORK 

Memory curation spans pixel reacquisition, feature replay, and learned memory formation, with dis-tinct trade-offs between evidence coverage and processing overhead (Zheng et al., 2026; Su et al., 2025; Zhang et al., 2026b). Memory organization represents evidence through images, text, en-coded features, or latent tokens, with different trade-offs in interpretability and context cost (Hu et al., 2024; Zhang et al., 2026d; Huang et al., 2026; Yu et al., 2026). Memory access uses heuristic triggers, uncertainty criteria, or learned policies (Sun et al., 2025; Liu et al., 2026b; Peng et al., 2026), and related policy optimization methods improve tool use and visual reasoning through train-ing feedback (Dong et al., 2026a; Li et al., 2026c). ReMAP bridges these dimensions by combining pixel reacquisition with compact latent memory and preserving scene and cross-image context to interpret newly acquired local evidence. Its access training branches before memory invocation to compare requesting memory with continuing from the same reasoning state, providing feedback on the utility of memory access. A detailed review and comparison are provided in Appendix A.1. 

3 REASONING -T IME MEMORY -A UGMENTED PERCEPTION 

In this section, we introduce ReMAP, which interleaves autoregressive reasoning with access to la-tent visual memory to restore the perceptual cycle. Figure 2 provides an overview of the framework. Given images I = {Ii}Ni=1 and a question Q, the model begins reasoning from a coarse visual prefix 

V c = Ec(I). During reasoning, the model can continue generating text or invoke Global or Local latent memory. After each memory return, the model resumes reasoning with the retrieved evidence. Specifically, Section 3.1 describes how Global and Local memories are formed and integrated into the reasoning sequence. Section 3.2 describes memory access and its training policy. 3.1 MEMORY CURATION AND ORGANIZATION 

Global memory. Global memory provides a compact representation of image content and, for multi-image inputs, relationships across images. We construct it in two stages: the Image Weaver summarizes each image, and the Relation Weaver integrates these summaries into relational context. Both stages are conditioned on the input question. Let Vi denote the encoded visual features of image Ii. We use two sets of learnable query tokens, 

QG and QR, to aggregate per-image content and relational context, respectively. The corresponding modules, Wimg and Wrel , apply cross-attention followed by feed-forward layers. The Image Weaver attends to each image’s features separately, while the Relation Weaver attends to the concatenated image summaries. Latent memory keeps retrieved visual evidence within a fixed token budget. Replaying whole im-ages at every request would repeatedly expand the context and compete with the ongoing reasoning sequence. Moreover, memory does not help at every step, since its value depends on when it is ac-cessed, consistent with our third finding. The content of a return can be supervised directly, whereas the value of its timing appears only in later reasoning. We therefore separate memory formation from memory access. Stage I: Supervised learning and warm-up. Stage I isolates memory formation from access-policy learning, so that each return localizes the right region and carries evidence that supports sub-sequent reasoning. The vision encoder, pretrained LLM, and decoder LoRA remain frozen through-out this stage. Existing datasets lack ROI annotations that change along the reasoning chain, so we annotate reasoning steps with target regions, together with reference CoTs from a teacher VLM, per-image facts, cross-image relations, and answers. We first optimize memory quality by training the Image and Relation Weavers and then the Local Weaver. Their returns are inserted into teacher CoTs, and the continuation cross-entropy Lsuffix through the frozen LLM, together with fact, rela-tion, and answer supervision, trains them to encode evidence for the teacher’s subsequent reasoning. We then train Twig to localize the annotated regions with LROI . Because student states differ from teacher states, we next train continuation on student rollouts, where the teacher reviews the student’s prefixes and crops to provide continuation and ROI targets for the same two losses. Finally, with the formation modules fixed, a warm-up lets the model emit the memory special tokens, updating only the input embeddings of the four markers and the output-layer rows that score <mem g> and 

<mem l> . Figure 3(b) illustrates these signals, and Appendix A.3.3 gives the objectives.

4 EXPERIMENTS 

We evaluate ReMAP on single-image perception, multi-image reasoning, and broader visual under-standing. We then examine the contributions of memory curation, organization, and access through ablations, latent visualizations, reasoning trajectories, and visual-context cost. 4.1 EXPERIMENTAL SETUP 

Benchmarks. We use ten benchmark families in three categories. Single-image perception 

includes V*Bench (Wu & Xie, 2024), CV-Bench-2D/3D (Tong et al., 2024), and HR-Bench-4K/8K (Wang et al., 2025b). Multi-image reasoning includes BLINK (Fu et al., 2024), Muir-Bench (Wang et al., 2025a), MMSI-Bench (Yang et al., 2026a), and MIMIC (Das et al., 2026). 

Broader visual understanding (Yu et al., 2024; Lu et al., 2024; xAI, 2024) uses MM-Vet, Math-Vista, and RealWorldQA for generalization tests.

5 LIMITATIONS 

We note three limitations of ReMAP that we hope to address in future work. First, ReMAP operates within a fixed memory and access budget: each trajectory permits at most five memory requests, each Local request re-encodes at most three selected images, and each Global block has a fixed 

4N + 4 layout. These limits keep computation low but may omit evidence when an input contains many images or when a task requires extended visual search. Second, Twig is trained only in Stage I on teacher-reviewed ROI targets and receives no further training dedicated to localization. When its box misses the relevant region, the subsequent zoom-in contributes less useful detail, so we expect a stronger localizer, for example one trained with dedicated grounding data, to further improve Local memory. Third, the memory modules are attached at fixed positions of the backbone: the Source Selector reads layer 12, and Twig reads layer 18. Internal layer sweeps selected these taps from the quality of the tapped representations, but we have not yet studied how placing the components at other layers affects end-to-end performance, and we leave this analysis to future work. 

6 CONCLUSION 

ReMAP shows that visual memory becomes effective when the scope and timing of visual evidence follow the reasoning state. Global memory preserves question-conditioned scene and cross-image context, while Local memory reacquires fine-grained pixels as the trajectory demands. A learned policy coordinates these two forms of evidence within compact latent returns, improving over prior methods on all four multi-image benchmarks and over the Native backbone on all five single-image 10 Preprint. Under review. metrics while reducing the profiled visual context. Together, these components restore the perceptual cycle by letting each reasoning step use its current evidence to guide the next visual inspection. A.1 RELATED WORK AND POSITIONING 

Memory curation: acquiring and selecting visual evidence. Memory curation determines which evidence reasoning acquires. DeepEyes learns crop requests (Zheng et al., 2026), while Pixel Reasoner combines image cropping and video-frame selection (Su et al., 2025). VLM-R 3 interleaves region selection, cropping, and zooming with textual reasoning (Jiang et al., 2025). VPT supports token-guided cropping and state-conditioned full-image re-encoding (Yu et al., 2025). CMMCoT generates image indices and boxes to re-encode entity regions during multi-image reasoning (Zhang et al., 2026a). Qwen Look Again, ICoT, and MINT-CoT instead select or reuse encoded visual to-kens (Chu et al., 2025; Gao et al., 2025; Chen et al., 2025). VTPerception-R1 grounds reasoning in explicit perceptual descriptions (Ding et al., 2025), while perception-time scaling decomposes per-ceptual estimates into symbolic intermediate steps (Li et al., 2026b). VisMem uses state-conditioned formers to produce perceptual and semantic memory (Yu et al., 2026). V-Reflection trains latent rea-soning states with spatial supervision (Zhou et al., 2026). 

Memory organization: representing visual evidence. Visual Sketchpad represents intermediate evidence as generated sketches (Hu et al., 2024), VTool-R1 as annotated images (Wu et al., 2026), and CSMR as text (Zhang et al., 2026d). Take-along Visual Conditioning pools visual tokens (Sun et al., 2025), while Persistent Visual Memory projects image embeddings into a lower-dimensional space (Huang et al., 2026). CMMCoT retrieves cross-image cues from cached per-layer visual key– value features (Zhang et al., 2026a). FlexMem compresses and retrieves visual KV memories for long-video understanding (Chen et al., 2026c). MemGen and VisMem represent memory as latent token sequences (Zhang et al., 2026b; Yu et al., 2026). Laser and Mirage represent intermediate reasoning through continuous hidden states or self-generated visual tokens (Wang et al., 2026b; Yang et al., 2026b). Positioning ReMAP. ReMAP bridges these dimensions by connecting active visual evidence ac-quisition with latent memory and learned access. Within memory curation, it emphasizes the com-plementarity between newly acquired local details and the scene and cross-image context needed to interpret them. Within memory organization, it brings pixel-level reacquisition into compact latent memory, connecting renewed perception with an efficient representation of visual evidence. Within memory access, it focuses on the utility of requesting evidence at a given reasoning state, using comparisons between invocation and continuation to guide selective access. Together, these choices support sustained visual grounding throughout reasoning. A.2 RUNTIME AND MEMORY INTERFACE 

Memory transactions. ReMAP begins autoregressive reasoning from a coarse visual prefix of the input images. Ordinary autoregressive generation continues by default. A memory transaction is performed only when the decoder emits a Global or Local request token. The corresponding transactions are 

⟨mem g ⟩; ZG; ⟨mem g end ⟩, ⟨mem l ⟩; ZL; ⟨mem l end ⟩. (4) 17 Preprint. Under review. After the decoder emits a request token, the runtime inserts the corresponding latent block and end marker into the current decoder sequence. Generation resumes from the position following the end marker. End markers are not sampled as vocabulary outputs, and returned latents enter the decoder as continuous inputs. Each reasoning trajectory permits at most five memory requests. After the request budget is exhausted or the model commits an answer, Global and Local request tokens are masked. Inserted latents and end markers occupy successive positions in the decoder sequence and KV cache. Request tokens and these inserted positions do not count toward the ordinary-text budget, but they still consume decoder context capacity. 

Global memory. Global curation forms a question-conditioned latent block from the ordered in-put images. For an input containing N images, four tokens are allocated to each image and four additional tokens encode cross-image relations: 

KG(N ) = 4 N + 4 . (5) The resulting block is formed before decoding, cached throughout the reasoning trajectory, and inserted at a new sequence position whenever the decoder emits a Global request. Repeated Global requests neither re-encode the input images nor regenerate the cached block from a later reasoning state. 

Local memory. The Local request uses the current reasoning state to select image sources and regions. The selector retains at most three sources, stopping when cumulative selection probability reaches 0.85. A frozen vision encoder maps the selected crops to region features, and the Local Weaver combines these features with the reasoning state and cached Global memory: 

ZL = [ WL(ht, R t,i ; ZG)] i∈S t . (6) Each Local request returns 32 latent tokens. Global memory supplies context for Local compression but is not concatenated into the 32-token Local output. The 4N + 4 Global layout, the 32-token Local return, the three-source cap, and the 0.85 threshold define the memory interface used in all main experiments. The Source Selector reads the layer-12 state exposed at a request boundary, and Twig uses layer-18 prefix states selected by a layer sweep. Stage II rollout branching follows the partial-rollout strategy of ARPO (Dong et al., 2026a) and is specified with the access objective below. A.3 MEMORY FORMATION AND ACCESS OBJECTIVES

Route-based selection therefore exposes more alternative memory deci-sions at the branch, and these alternatives come with larger reward differences than those found by random or entropy-change selection.
