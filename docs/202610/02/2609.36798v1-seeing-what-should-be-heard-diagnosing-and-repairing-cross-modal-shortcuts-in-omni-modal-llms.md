## 摘要
全模态大语言模型（LLMs）被期望使用问题明确指涉的模态来回答该问题。然而，现有训练范式很少验证模型是否真正遵循该模态，因为同一样本的多模态输入往往为同一答案提供冗余证据。在本工作中，我们揭示了全模态LLMs中普遍存在的跨模态捷径：当被问及音频相关问题时，模型对图像的依赖与对音频的依赖相当，有时甚至更多。为系统诊断这一行为，我们提出了因子化模态诊断（Factorized Modality Diagnostic），它独立地在样本之间交换音频和图像，以分离每种模态的因果贡献。在不同设置下的两个模型系列中，我们发现这种捷径在监督微调和强化学习后训练过程中持续存在，而基于评判器的强化学习可能进一步放大这种对无关视觉信息的依赖。基于这一发现，我们提出DMC-Repair，它在同类跨模态交换样本上训练模型，同时根据问题指定的模态分配监督信号。这防止模型利用同一片段内模态之间的虚假对应关系。实验表明，DMC-Repair将图像诱发的答案效应占比降低了59.9%，在不损害音频问题回答性能的情况下有效抑制了跨模态捷径。对捷径依赖的降低可泛化到两个模型系列，并能零样本泛化到未见数据集和未见基准，且在后续后训练中持续存在。代码见 https://anonymous.4open.science/r/DMC-Repair。

## Abstract
Omni-modal large language models (LLMs) are expected to answer a question using the modality it explicitly refers to. However, existing training paradigms rarely verify whether models actually follow this modality, because multimodal inputs from the same sample often provide redundant evidence for the same answer. In this work, we uncover a pervasive cross-modal shortcut in omni-modal LLMs: when asked an audio-related question, models rely on the image as much as on the audio, and sometimes even more. To systematically diagnose this behavior, we introduce the Factorized Modality Diagnostic, which independently swaps audio and images between samples to isolate each modality's causal contribution. Across two model families in different settings, we find that this shortcut persists throughout supervised fine-tuning and reinforcement learning post-training, while judge-based RL may further amplify such reliance on irrelevant visual information. Based on this finding, we propose DMC-Repair, which trains models on the same kind of cross-modal swapped samples while assigning supervision according to the modality specified by the question. This prevents models from exploiting the spurious correspondence between modalities within the same clip. Experiments demonstrate that DMC-Repair reduces the image-induced share of the answer effect by 59.9%, effectively suppressing the cross-modal shortcut without compromising audio-question answering performance. The reduction in shortcut reliance generalizes across two model families and zero-shot to an unseen dataset and an unseen benchmark, and persists through subsequent post-training. Code is available at https://anonymous.4open.science/r/DMC-Repair.

# 论文总结：Seeing What Should Be Heard — 全模态大模型跨模态捷径的诊断与修复

## 1. 核心问题与研究动机

- **背景**：全模态（omni-modal）大语言模型（如 Qwen2.5-Omni、HumanOmniV2、MiniCPM-o-2.6）同时接收图像、音频、视频等流，并被期望"用问题所指定（designated）的模态"作答。例如问"是否有大提琴声"，答案应来自听觉而非画面。
- **核心问题**：现有 SFT / RL 后训练范式只奖励"答案正确 + 格式规范"（部分方法再加评判器给推理文本打分），**没有任何奖励检验模型实际依赖了哪个模态**。由于同一样本的图像与音频天然互为冗余证据（画面里是大提琴、音频里也在拉大提琴），模型完全可以"看图答题"并拿到满分奖励。
- **作者命名**：这种"用非指定模态替代指定模态"的行为称为**跨模态捷径（cross-modal shortcut）**，其典型外化表现是**跨模态幻觉**——仅因声源可见就报告听到了该声音。
- **形式化判据**：设问题 Q 的指定模态子集为 d(Q)，理想模型应满足
  `p(A | Q, M_d(Q), M_¬d(Q)) = p(A | Q, M_d(Q), M'_¬d(Q))`（即非指定模态完全无影响）。
  自然语料中两模态高度相关，因此仅靠准确率**无法**验证该条件。
- **整体含义**：这是对"多模态模型是否真的在听/在看"这一可信性问题的基础性诊断工作，同时给出了一个不依赖额外奖励模型或偏好对的修复方案。

## 2. 方法论

### 2.1 因子化模态诊断（Factorized Modality Diagnostic）

- **2×2 析因设计**：对同一问题 q，选取两个**答案不同**的真实样本——own 项 (i_o, a_o) 答案 g，partner 项 (i_x, a_x) 答案 g'。交叉图像来源与音频来源两个因子（各两水平），得到 4 个**格子（cell）**：
  - 匹配格（matched）：(i_o,a_o)、(i_x,a_x)，即原始样本；
  - 不匹配格（mismatched）：(i_o,a_x)、(i_x,a_o)，图像与音频来自不同片段。
- **答案边际（answer margin）**：`m_uv = log p(g | q, i_u, a_v) − log p(g' | q, i_u, a_v)`，符号表示模型偏好哪个答案。
- **主效应与交互项**：
  - 音频效应 `EA = ½[(m_oo − m_ox) + (m_xo − m_xx)]`
  - 图像效应 `EV = ½[(m_oo − m_xo) + (m_ox − m_xx)]`
  - 交互项 `ψ = ½(m_oo − m_ox − m_xo + m_xx)`
- **捷径指数（Shortcut Index）**：`SI = |EV| / (|EA| + |EV|)`。音频问题上理想值为 0（图像应无影响），视觉问题上理想值为 1；SI≈0.5 意味着图像对音频问题答案的影响与音频相当。
- 采用完整析因而非"单模态 swap/遮蔽"，是为了把主效应与交互效应分离；每个问题族（family）取两对样本并统一朝向（own 项答案固定为 yes），家族内取均值再跨家族平均。

### 2.2 DMC-Repair（Designated-Modality Counterfactual Repair）

三个组件，核心思想是**改变"哪个输入能预测训练标签"**，而非改变奖励或解码：

- **(a) 反事实网格构造**：将同问题、不同答案的样本两两配对，把每对展开为与诊断相同的 4 格网格（含双向 swap），全部使用真实媒体，每段图像/音频都同时出现在一个匹配格和一个不匹配格中。
- **(b) 指定模态重标注**：对格子 c = (q, i_u, a_v)，
  - 音频问题 → 标签取音频来源样本的答案 y_v；
  - 视觉问题 → 标签取图像来源样本的答案 y_u；
  - 音视频问题 → 仅保留两个原始匹配格（反事实格无已知标签）。
  由此对均匀抽样的格子满足 `Pr[y*(c)=g | 非指定输入] = Pr[y*(c)=g | match(c)] = 1/2`：**非指定模态与"是否匹配"均不含标签信息**，只有指定模态能决定标签；联合训练音频与视觉网格还迫使模型从问题文本推断该用哪一模态，而非固化单一偏好。
- **(c) 仅监督答案 token**：对候选答案 y，teacher-forcing 后用长度归一化对数似然打分
  `s_θ(y|c) = (1/|y|) Σ_t log p_θ(y_t | c, <answer>, y_<t)`；
  损失为带阈值 τ（=1.0）的 hinge：
  `L(θ) = (1/|C|) Σ_c max(0, τ − [s_θ(y*(c)|c) − s_θ(ȳ(c)|c)])`。
  该目标直接优化诊断所测的答案边际；**不需要 rollout、评判器、奖励模型或偏好对**，也不对生成的描述/推理文本设目标。
- **(d) 向 N 模态的一般化**：对每个模态流 k 从源样本 s_k 取媒体组成格子，仅当所有指定流的源样本一致时定义标签 `y*(c_s) = y_{s_k}`（k ∈ d(Q)）。
