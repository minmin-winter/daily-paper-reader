## 摘要
我们提出 Multimodal Flow，一种面向语言与视觉的全连续生成模型。大多数统一多模态模型要么将语言和量化图像都建模为离散 token，要么将离散语言预测与连续图像生成相结合。前者引入了视觉量化瓶颈。后者需要依赖模态的目标函数和采样过程。全连续建模避免了这些权衡，并支持共享的生成过程，但在多模态预训练中仍未得到充分探索。Multimodal Flow 引入了一种统一的连续架构，将多模态连续表示与共享的 chunk-causal flow 主干网络相结合。它将文本块和图像组织为有序的连续超块（hyperchunks），从而保留文本 token 顺序和视觉空间结构。该主干网络通过 Flow Matching 在这些超块上学习单一向量场。联合注意力实现跨模态交互，而模态特定的前馈网络分别处理每种模态。该模型在训练期间并行预测多个目标块，并在推理时顺序生成超块。我们实例化了 MF-1，并在多模态数据上进行预训练。在 0.6B、1.2B 和 1.6B 规模下，继续预训练持续提升了多模态建模能力。仅使用 150B 预训练 token，MF-1 在 GenEval 和 DPG-Bench 上取得 82.8 的平均分，在 VQAv2、MMBench 和 POPE 上取得 75.3 的平均分，与使用远更多数据训练的统一模型相比仍具竞争力。在数据、优化和参数预算匹配的情况下，Multimodal Flow 进一步优于代表性的混合模型和离散模型。这些结果确立了基于连续块的嵌入流建模作为一种用于统一多模态建模的新全连续范式。相关代码和模型已在 https://github.com/hustvl/Multimodal-Flow 公开发布。

## Abstract
We present Multimodal Flow, a fully continuous generative model of language and vision. Most unified multimodal models either model both language and quantized images as discrete tokens or combine discrete language prediction with continuous image generation. The former introduces a visual quantization bottleneck. The latter requires modality-dependent objectives and sampling procedures. Fully continuous modeling avoids these trade-offs and enables a shared generative process, but remains underexplored for multimodal pretraining. Multimodal Flow introduces a unified continuous architecture that integrates multimodal continuous representations with a shared chunk-causal flow backbone. It organizes text blocks and images as ordered continuous hyperchunks, preserving textual token order and visual spatial structure. The backbone learns a single vector field over these hyperchunks through Flow Matching. Joint attention enables cross-modal interaction, while modality-specific feed-forward networks process each modality. The model predicts multiple target chunks in parallel during training and generates hyperchunks sequentially at inference. We instantiate MF-1 and pretrain it on multimodal data. Across 0.6B, 1.2B, and 1.6B scales, continued pretraining consistently improves multimodal modeling. With only 150B pretraining tokens, MF-1 achieves an average score of 82.8 across GenEval and DPG-Bench and 75.3 across VQAv2, MMBench, and POPE, remaining competitive with unified models trained on substantially more data. Under matched data, optimization, and parameter budgets, Multimodal Flow further outperforms representative hybrid and discrete models. These results establish continuous chunk-based embedding flow modeling as a new fully continuous paradigm for unified multimodal modeling. The related code and model are publicly released at https://github.com/hustvl/Multimodal-Flow.

## 2. 方法论

### 2.1 核心思想

- 将文本块和图像分别编码为连续表示，并组织成有序的**超块（hyperchunks）**序列。
- 使用一个共享的 **chunk-causal Flow Matching 主干**，在超块序列上学习单一向量场。
- 训练时并行预测多个目标块，推理时按块顺序生成。
- 通过**联合注意力**实现跨模态交互，通过**模态特定 FFN**适配语言与视觉的不同表示统计。

### 2.2 连续多模态表示与超块构建

- 使用冻结的模态编码器：
  - 文本编码器：T5-small，文本 embedding 维度 512；
  - 视觉编码器：SigLIP2-so400m，224×224 图像产生 256 个 patch embedding，维度 1152。
- 文本按长度 \(B=8\) 切分为连续块，每块独立编码；图像整体作为一个视觉块。
- 归一化后，文本块和图像块分别形成：
  - 文本超块：保留 token 顺序；
  - 视觉超块：保留 16×16 空间网格结构。
- 生成后，预测表示经反归一化，分别送入冻结的图像解码器和单独训练并冻结的文本解码器，恢复图像或文本。

### 2.3 Chunk-Causal Flow 建模

- 将多模态序列表示为有序块序列 \(C=(c_1,\dots,c_K)\)，并按块因果方式分解：
  - \(p_\theta(C)=\prod_{k=1}^{K}p_\theta(c_k \mid c_{<k})\)。
- 预测第 \(k\) 个块时：
  - 所有前序块可见；
  - 当前块内部位置联合建模；
  - 未来块被 mask。
- 对目标块干净表示 \(x^{(k)}\) 构造线性概率路径：
  - \(z_t^{(k)}=t x^{(k)}+(1-t)\epsilon^{(k)}\)，\(\epsilon\sim N(0,I)\)；
  - \(t=0\) 为噪声，\(t=1\) 为干净表示。
- 主干预测干净端点：
  - \(\hat{x}_\theta^{(k)}=f_\theta^{m_k}(z_t^{(k)},t \mid c_{<k})\)。
- 再转换为速度：
  - \(\hat{v}_\theta^{(k)}=(\hat{x}_\theta^{(k)}-z_t^{(k)})/(1-t)\)；
  - 训练目标为速度 MSE。
- 位置编码使用 **MRoPE**，同时编码块顺序和块内结构。
- 注意力为 chunk-causal mask 下的联合自注意力；FFN 为模态特定。
- 训练时使用 sequence packing，将多个逻辑序列打包到最长 32768 个模型位置中，并用序列标识隔离不同样本。

### 2.4 并行训练与顺序推理

- **训练**：
  - 多个目标块可在一次前向中并行预测；
  - 每个目标块独立采样 Flow 时间步；
  - 目标块只能关注前序干净块和自身扰动状态，不能关注自身干净版本或未来块。
- **推理**：
  - 按任务指定顺序逐块生成；
  - 当前块从高斯噪声开始，沿学习到的向量场从 \(t=0\) 积分到 \(t=1\)；
  - 生成后的干净块加入上下文缓存；
  - 由于块因果注意力，已完成块的隐藏状态不依赖未来块，可进行 **KV caching**。
- **条件生成**：使用统一 CFG：
  - \(\hat{x}_{\theta,\gamma}=\hat{x}_{\theta,\varnothing}+\gamma(\hat{x}_{\theta,c}-\hat{x}_{\theta,\varnothing})\)；
  - 文本到图像和图像条件文本生成均可使用同一 CFG 机制。

### 2.5 混合多模态预训练与下游微调

- 混合预训练任务：
  - 纯文本建模；
  - 纯图像建模；
  - 文本到图像；
  - 图像到文本。
- 训练配比：70% 纯文本、20% 图像理解、9% 文本到图像、1% 纯图像。
- 下游微调：
  - VQA：视觉块 + 问题块作为干净前缀，答案块作为文本目标；
  - 文本到图像：提示词块作为前缀，图像为视觉目标；
  - 任务接口、因果分解和连续目标保持不变。

- MF-1 在 0.6B、1.2B、1.6B 规模下，继续预训练持续改善 Flow Matching 目标、语言 PPL、GenEval 和 CLIPScore。

- 在匹配数据、优化和可训练参数预算下，Multimodal Flow 优于：

  - DINOv2 在图像生成上最强，SigLIP2 在生成与描述之间更平衡；
