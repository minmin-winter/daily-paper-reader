## 摘要
对比式视觉-语言模型通过对齐匹配的图像-文本对来学习共享嵌入空间，但其表示仍因模态差距而彼此分离。已有研究报告了修改该差距所带来的不同效果：缩小差距可提升零样本分类和跨模态对齐，而移除与差距相关的结构则可能损害图像-文本检索。本文为这些依赖任务的效果提供统一的几何解释。在 CLIP 和 SigLIP 编码器中，我们发现单一主导方向捕获了图像-文本均值分离平方范数的 94.4–99.9%，表明均值分离分量近似为秩一。对相似度分数进行分解后，可识别出三种任务特定的作用。在零样本分类中，查询侧固定差距偏移的减去恰好等价于加性类别偏置。在标准跨模态检索中，投影掉差距方向并对残差重新归一化会丢弃候选特定的范数信息，从而引入乘性排序失真；一个由几何导出的指数与网格搜索最优值相吻合（Spearman rho = 0.93），并在某些设置下恢复性能，不过增益的迁移并不均衡。在混合模态检索中，差距方向会按模态对候选进行排序；移除该方向可改善跨模态排序，这一点与随机方向或非差距对照不同。移除后残存的语义结构界定了秩一解释的局限。综合来看，这些结果解释了为何修改差距会在不同下游设置中提升、损害或恢复性能。通过阐明差距修改何时以及为何改变模型行为，该解释为在基于相似度的视觉-语言系统中、针对所评估的下游任务选择差距干预措施提供了有原则的依据。

## Abstract
Contrastive vision-language models learn shared embedding spaces by aligning matched image-text pairs, yet their representations remain separated by a modality gap. Prior work reports divergent effects of modifying this gap: reducing it can improve zero-shot classification and cross-modal alignment, whereas removing gap-related structure can degrade image-text retrieval. In this paper, we provide a unified geometric explanation for these task-dependent effects. Across CLIP and SigLIP encoders, we find that a single dominant direction captures 94.4-99.9% of the squared norm of the image-text mean separation, revealing that the mean-separation component is approximately rank-one. A decomposition of the similarity score then identifies three task-specific roles. In zero-shot classification, query-side fixed gap-offset subtraction is exactly equivalent to an additive class bias. In standard cross-modal retrieval, projecting out the gap direction and renormalising residuals discards candidate-specific norm information, inducing a multiplicative ranking distortion; a geometry-derived exponent tracks the grid-search optimum (Spearman rho = 0.93) and restores performance in some settings, although the gains transfer unevenly. In mixed-modal retrieval, the gap direction sorts candidates by modality; its removal can improve cross-modal ranking, unlike random or non-gap controls. Residual semantic structure after removal defines the limits of the rank-one account. Together, these results explain why gap modification can improve, degrade, or restore performance across downstream settings. By clarifying when and why gap modification changes model behavior, this account provides a principled basis for selecting gap interventions in similarity-based vision-language systems across evaluated downstream tasks.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：CLIP、SigLIP 等对比式视觉-语言模型通过对齐匹配的图像-文本对学习共享嵌入空间，但图像与文本嵌入之间存在持续的系统性分离，即"模态差距"（modality gap）。
- **核心矛盾**：既有文献对"修改模态差距"的效果报告相互冲突——缩小差距可提升零样本分类与跨模态对齐，但移除与差距相关的结构却可能损害图像-文本检索；更强对齐有时有益、有时有害。
- **问题诊断**：作者认为分歧源于两点被忽视的区分：
  1. **干预方式并非等价**：固定偏移相减、正交投影、投影+重归一化、完整模态均值中心化、分数校准，各自删除/保留的信息不同。
  2. **下游读出固定了不同量**：分类固定查询图像、变化文本原型；标准跨模态检索在异模态候选中排序；混合模态检索让图像与文本在同一索引中竞争。
- **整体含义**：论文主张模态差距既非固有缺陷也非固有优势，其效果由**几何操作 × 下游读出**共同决定；不存在任务无关的最优干预。这为在基于相似度的视觉-语言系统中选择差距干预提供了统一的原则性依据。

## 2. 方法论

### 2.1 核心思想
- 将图像-文本均值分离（centroid separation）刻画为**近似秩一**的主导分量，并用同一坐标在不同读出下推导出三种任务特定机制。
- 关键区分：**Ĝ（质心差方向）** 与 **v₁（估计划分上联合图像-文本云的主成分方向）**；实验以 v₁ 作为干预轴，并以 |ĝᵀv₁| 检验二者对齐程度。

### 2.2 方向与分解定义
- 质心差：g = μ_img − μ_txt，ĝ = g/‖g‖₂。
- 任意单位方向 v 上的坐标分解：z = z⊥ + β_z v，其中 β_z = zᵀv，z⊥ = z − β_z v（保留正交几何）。

### 2.3 四种非等价干预（表 1）
- **O1 固定单方向偏移相减**：z′_m = z_m − β̄_m v；移除模态均值沿 v 的分量，保留样本残差。
- **O2 原始正交投影**：z′ = z − (zᵀv)v = z⊥；删除完整样本坐标，改变范数且不恢复单位长度。
- **O3 投影 + L2 归一化**：z′ = z⊥/‖z⊥‖₂，单位向量下 ‖z⊥‖₂ = √(1 − (zᵀv)²)，引入样本依赖的分母。
- **O4 完整模态均值中心化**（cosine 时再归一化）：移除完整质心，一般不是秩一操作，可改变 v 正交方向的几何。
- **分数校准**：与嵌入修改本质不同，只改变读出（logits）而不改变存储嵌入。

### 2.4 统一的相似度分数分解
- 精确分解：S(x,t) = xᵀt = x⊥ᵀt⊥ + β_x β_t。
- 令 β_x = β̄_img + r_x，β_t = β̄_txt + r_t，得 S = S⊥ + A + B + C + D：
  - A = β̄_img β̄_txt（模态级常数）
  - B = β̄_img r_t（文本残差一阶项）
  - C = β̄_txt r_x（图像残差一阶项）
  - D = r_x r_t（样本坐标耦合）
  - S⊥ 保留 v 之外的相似度
- 注意：B/C 的代数标签基于模态，但在图像→文本检索中 B 随候选变化、C 为查询侧；文本→图像方向角色互换。
- O3 额外引入分母：S_proj-cos = x⊥ᵀt⊥ / (N_x N_t)，N = √(1 − β²)。

### 2.5 三种读出的机制（算法流程式说明）
- **分类（加性类别偏置）**：查询侧 O1 下，(x − β̄_img v₁)ᵀt_c = xᵀt_c − β̄_img β_tc，第二项恰为加性、类别相关的偏置。该恒等式仅对固定偏移构造成立，不适用于 O2–O4。
- **标准检索（候选特定尺度失真）**：固定查询对异模态候选排序，O3 后每个候选残差范数不同，产生乘性校准误差。采用范数幂读出 S_γ(q,c) = q⊥ᵀc⊥ / (N_q N_c^{1−γ})；几何导出一阶指数 γ_t^(1) = 1 + |β̄_img||β̄_txt| / S̄⁺_{⊥,cos}（图像/文本角色在文本→图像方向互换），预测的是配置特定的校准而非精确最优。
- **混合检索（模态依赖候选排序）**：图像与文本候选共享同一索引，标准异模态池中为常数的项在候选中系统性变化，使 v₁ 坐标先按模态排序、后按语义相关性排序。
