# AVSD-SCENES: A DATASET FOR AUDIO-VISUAL DESCRIPTION OF URBAN SCENES 

# Dhanunjaya Varma Devalraju 1,∗, Arshdeep Singh 2,∗, Mark D. Plumbley 21IIT Madras, India, 2King’s College London, United Kingdom 

ABSTRACT 

Natural language descriptions can provide rich semantic rep-resentations of audio-visual urban scenes, yet datasets that jointly describe both auditory and visual information remain limited. In this paper, we introduce AVSD-Scenes, a paired audio-visual scene description dataset for urban environments. The dataset contains 12,291 audio-visual scene descriptions generated from the TAU Urban Audio-Visual Scenes dataset. To construct the dataset, we first generate audio- and visual-based descriptions using Qwen2-Audio-7B and Qwen2.5-VL-7B, respectively. These modality-specific descriptions are then combined using large language mod-els, namely Qwen3-14B, Mistral-Small-3.2-24B-Instruct-2506, and Gemma-3-27B-it, to produce multimodal descriptions that capture complementary information from both modalities. We benchmark AVSD-Scenes using semantic alignment, cross-modal retrieval, scene classification, LLM-as-a-judge evaluation, and human sub-jective assessment. Results show that multimodal descriptions im-prove semantic alignment and cross-modal retrieval performance compared with modality-specific descriptions while preserving strong scene-discriminative information. The generated descrip-tions achieve up to 94.5% accuracy in urban scene classification, while combining audio, visual, and description embeddings further improves accuracy to 95.4%. Furthermore, the descriptions remain highly scene-discriminative even when scene labels are removed from the prompting instructions, indicating that they capture seman-tic information derived from the audio-visual content rather than merely reflecting label information. 

Index Terms — Audio-visual scene description, DCASE, dataset, multimodal. 

1. INTRODUCTION 

Urban scenes contain diverse auditory and visual cues that jointly characterize the surrounding environment. Audio conveys activi-ties and events, while visual information provides context about the scene and potential sound sources. Natural-language descriptions of urban scenes provide rich semantic context about the environment, activities, and audio-visual events beyond conventional scene labels. Such descriptions are valuable for tasks including scene understand-ing [1], retrieval [2], and multimodal language generation [3]. Audio captioning [4] aims to bridge acoustic signals and natural language by generating textual descriptions of audio content. AVSD-Scenes contains natural language descriptions generated from both audio and visual scene information. 2. DATASET CONSTRUCTION PIPELINE 

We construct AVSD-Scenes, an audio-visual scene description dataset derived from the TAU Urban Audio-Visual Scenes 2021 development dataset [15], which is collected in 10 European cities, where each sample consists of an audio recording accompanied by its corresponding visual sequence. The original dataset provides synchronized audio-visual recordings with scene-level labels. In this work, we augment these audio-visual samples with natural-language descriptions that, beyond the predefined scene la-bels, explain the acoustic and visual events occurring in the recorded scenes, thereby providing richer semantic information about the underlying audio-visual content. As shown in Fig. 2, the dataset is constructed in two stages. In the first stage, the audio and visual recordings are processed inde-pendently to identify acoustic and visual events, respectively, and to generate modality-specific descriptions. In the second stage, these modality-specific events and descriptions are jointly used to gener-ate a unified scene description using a large language model (LLM). 

2.1. Stage 1: Modality-specific description generation 

We use the instruction-tuned models Qwen2-Audio-7B-Instruct 

[19] and Qwen2.5-VL-7B-Instruct [20] to identify modality-specific events and generate corresponding descriptions. For the audio modality, Qwen2-Audio-7B-Instruct is instructed ( IA) to identify sound events in the recording, describe them in chronological or-der, including overlapping events when applicable, and generate a concise caption summarizing the recording. For the visual modality, Qwen2.5-VL-7B-Instruct is instructed (IV ) to identify visible objects, people, animals, vehicles, and ac-tions, describe them chronologically, including simultaneous actions when applicable, and generate a concise caption summarizing the visual content. The model is instructed to avoid inferring unobserv-able intentions or events and to describe visual characteristics when

3. EVALUATION FRAMEWORK 3.1. Semantic alignment and cross-modal retrieval benchmark 

To assess how well multimodal representations capture the shared semantic content between audio, visual, and textual modalities, we benchmark AVSD-Scenes by measuring semantic alignment and cross-modal scene-level retrieval performance between audio-visual clips and their corresponding scene descriptions. We measure semantic alignment between embeddings generated from audio, visual or text modality. For text modality, we use either modality-specific or multimodal description. We evaluate scene-level retrieval tasks to analyse, “Can our generated descriptions re-trieve an audio/visual belonging to the correct scene” . In the text-to-audio/visual retrieval task, the modality-specific or multimodal descriptions are used as a query to retrieve the corresponding au-dio/visual recording from the dataset. Given audio or visual clips X = {x1, . . . , x N } and scene de-scriptions T = {t1, . . . , t N }, pretrained multimodal models project both modalities into a shared embedding space. Multimodal embedding models: We use three pretrained models, CLIP [24], CLAP [25], and IMAGEBIND [26], to extract embed-dings for cross-modal retrieval and semantic similarity evaluation. CLIP learns a joint image–text representation by aligning paired im-ages and natural-language descriptions through contrastive learning, while CLAP similarly learns a joint audio–text representation from paired audio and text. IMAGEBIND learns a shared embedding space across multiple modalities, including text, audio, and vision. 

3.2. Scene classification evaluation 

To assess whether the generated multimodal descriptions preserve scene-discriminative information, we evaluate their effectiveness for downstream scene classification using the TAU Urban Audio–Visual Scenes 2021 development dataset [15]. We follow the predefined split, with 70% of the data used for training and 30% for testing. 

Feature representation: For each example, we extract modality-specific embeddings from the audio, visual, and our generated scene descriptions. Following [15], we use audio and visual embed-dings extracted using the pre-trained L3-Net [27], resulting in 512 -dimensional representations for each modality. The scene descrip-tions are encoded using the pre-trained bert-base-uncased 

model [28], and the 768 -dimensional representation of the [CLS] 

token is used as the textual embedding. Further, we employ an early feature fusion strategy, in which embeddings from different modali-ties are concatenated to form a joint feature vector for classification. 

Classification: We use a simple one-vs-rest support vector machine (SVM) with radial basis function kernel with regularization param-eter of 10 and train the SVM using the training dataset and evaluate it on test dataset. 

3.3. Description quality evaluation 

We evaluate description quality using both an LLM-as-a-judge framework and human subjective assessment. 

LLM-as-a-judge evaluation: We use an LLM-as-a-judge frame-work [29] with Qwen2.5-14B-Instruct [19] to evaluate the generated audio–visual scene descriptions. Each description is rated on a five-point scale across eight criteria: audio fidelity, visual fidelity, event coverage, hallucination, cross-modal consistency, grammar, fluency, and overall quality. For hallucination, higher scores indicate fewer unsupported details. Scores are averaged across the dataset to obtain an overall assessment for each model. 

Human evaluation: To complement the automatic evaluation, we conduct a human subjective evaluation on 100 randomly selected audio-visual samples balanced across scene classes, following eth-ical approval. 5. CONCLUSION 

We introduced AVSD-Scenes, a dataset of 12,291 audio–visual scene descriptions generated from the TAU Urban Audio–Visual Scenes dataset. The proposed pipeline combines audio and visual descriptions using LLMs to generate unified multimodal scene de-scriptions. Experimental results show that the multimodal descrip-tions improve semantic alignment and cross-modal retrieval while providing informative scene-level representations for classification. The generated descriptions achieve up to 94.5% scene classification accuracy using text embeddings alone, increasing to 95.4% when combined with audio and visual embeddings. Human evaluation further supports the quality of the generated descriptions. Moreover, experiments without scene labels in the instructions demonstrate that the descriptions capture complementary semantic information beyond conventional audio–visual representations. Future work will focus on further scaling the dataset and improving the semantic grounding of multimodal descriptions by reducing hallucinations. 6. REFERENCES
